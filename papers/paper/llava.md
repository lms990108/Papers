## 세 줄 요약

1. 이미지를 보고 대화하는 모델(LLaVA)을, 사전학습된 비전 인코더(CLIP)와 LLM(Vicuna)을 연결해서 만든다.
2. 이미지 설명을 GPT-4에게 주고 "이미지에 대한 대화"를 만들게 해서, 지시 따르기(instruction following) 데이터 158K개를 얻는다.
3. 두 단계로 학습한다. 먼저 연결부만 맞추고, 다음에 LLM까지 함께 미세조정한다.

## 내용

### 풀려던 문제

LLM은 지시를 따르도록 학습해서(instruction tuning) 대화 도구가 되었다. 하지만 이미지가 들어가는 지시 따르기 데이터는 거의 없었다. 이미지를 설명하는 데이터는 있어도 "이 그림에서 무엇이 위험해 보이나요?" 같은 질문과 답은 사람이 만들어야 했다.

### 데이터를 LLM으로 만든다

COCO 이미지의 캡션과 물체 위치 상자를 텍스트로 GPT-4에 준다. GPT-4는 이미지를 직접 보지 않고, 이 텍스트만 보고 세 종류의 질문과 답을 만든다. 사람이 쓴 예시 몇 개를 few-shot으로 준다.

| 종류 | 개수 |
| --- | --- |
| 대화 | 58K |
| 상세 설명 | 23K |
| 복잡한 추론 | 77K |
| 합계 | 158K |

### 구조와 학습

CLIP ViT-L/14가 이미지를 patch별 벡터로 바꾸고, 학습 가능한 선형 변환 하나가 그 벡터를 LLM의 token 임베딩 공간으로 옮긴다. 변환된 이미지 token은 텍스트 token과 함께 Vicuna에 들어간다. → [멀티모달](../learn/ai/deep-learning/multimodal.md)

학습은 두 단계다.

```text
단계 1  특징 정렬     CC3M에서 고른 595K 이미지-캡션 쌍
                      비전 인코더 고정, LLM 고정, 선형 변환만 학습
단계 2  지시 미세조정  앞의 158K 지시 따르기 데이터
                      비전 인코더 고정, 선형 변환과 LLM을 학습
```

단계 1은 이미지 벡터가 LLM이 읽는 token과 같은 말을 하도록 연결부만 맞추는 일이다. LLM 자체는 건드리지 않아서 값싸고 안정적이다.

### 결과

LLaVA-Bench(COCO)에서 GPT-4 대비 상대 점수 85.1%를 냈다. 과학 문제 데이터 ScienceQA에서는 GPT-4와 앙상블해서 92.53%로 당시 최고 정확도를 기록했다.

## 기억할 것

### 이미지는 token 수백 개를 차지합니다

ViT-L/14가 224×224 이미지를 14×14 patch로 자르면 16×16 = 256개가 나온다. 이미지 한 장이 context window에서 token 256개 정도를 쓴다는 뜻이다. 이미지가 여러 장이면 입력이 빠르게 불어난다. 해상도를 키우면 patch 수도 늘어서 비용이 커진다.

### 합성 데이터의 한계가 그대로 들어옵니다

답을 만든 것이 GPT-4이고 그 입력이 캡션과 상자뿐이라서, 캡션에 없는 세부는 데이터에 없다. 모델이 이미지에 없는 것을 말하는 환각이 생기는 이유 중 하나로 볼 수 있다. 논문도 이미지를 "patch 묶음"처럼 받아들여서 구조를 놓치는 사례를 보인다.

### 눈은 고정하고 입만 맞춥니다

비전 인코더는 두 단계 모두 학습하지 않는다. 그래서 인코더의 약점은 모델에도 남는다. CLIP이 세밀한 과제에 약하면 LLaVA도 약하다. → [CLIP](./clip.md)

## 리뷰

연결부 하나와 합성 데이터만으로 멀티모달 LLM을 만들 수 있다는 것을 보여 준 레시피 논문이다. 비전 인코더, 연결부, LLM 세 조각을 이어 붙이는 구조는 이후 오픈 VLM의 기본형이 되었다. 학습 데이터를 강한 LLM으로 만든다는 방식은 지금 에이전트용 데이터 만들기에서도 그대로 쓰인다.
