## 세 줄 요약

1. 순환 신경망과 합성곱 없이, 어텐션만으로 만든 모델 트랜스포머(Transformer)를 제안한다.
2. 모든 token 쌍의 관계를 한 번에 계산해서 학습을 병렬로 돌릴 수 있다.
3. 기계 번역에서 기존 최고 성능을 넘으면서 학습 비용은 훨씬 적었다.

## 내용

### 풀려던 문제

당시 번역 같은 시퀀스 모델의 표준은 LSTM이나 GRU 같은 순환 신경망으로 만든 encoder-decoder였다. 순환 신경망은 앞 token을 처리해야 다음 token을 처리할 수 있다. 그래서 한 문장 안에서는 병렬화가 안 되고, 문장이 길수록 학습이 느려지고 메모리가 모자란다. 먼 token끼리 정보가 오가려면 그 사이 단계를 모두 거쳐야 하는 것도 문제였다. 어텐션은 이미 쓰이고 있었지만 순환 신경망 위의 보조 장치였다. 이 논문은 그 보조 장치만으로 모델을 만들 수 있는지 묻는다. → [순환 신경망](../learn/ai/nlp/rnn.md)

### 순환, 합성곱, 어텐션 비교

길이 n, 표현 차원 d인 입력에서 층 하나를 비교한 표(논문 Table 1)다.

```text
                      층당 계산량     순서대로 해야 하는 단계    두 token 사이 최대 거리
셀프 어텐션            n²·d            1                          1
순환 신경망            n·d²            n                          n
합성곱 (커널 k)        k·n·d²          1                          log_k(n)
```

논문은 n이 d보다 작으면 셀프 어텐션이 순환보다 가볍다고 말한다. d = 512일 때 n = 100이면 어텐션은 100²×512 = 5.1M, 순환은 100×512² = 26.2M이다. n = 1,000이면 어텐션이 512M, 순환이 262M으로 뒤집힌다. 어텐션의 장점은 계산량이 아니라 순서대로 해야 하는 단계가 1이라는 점과, 먼 token끼리 바로 연결된다는 점이다.

### 구조

encoder와 decoder는 각각 같은 층 6개를 쌓는다. 모든 하위 층은 `LayerNorm(x + 하위층(x))` 형태의 잔차 연결로 감싸고, 차원은 512로 통일한다.

- **encoder 층**: 멀티 헤드 셀프 어텐션, 그다음 위치별 feed-forward 신경망.
- **decoder 층**: 앞 token만 보는 셀프 어텐션, encoder 출력을 읽는 어텐션, feed-forward 신경망.

그래서 어텐션은 세 가지로 쓰인다. encoder 셀프 어텐션은 query, key, value가 모두 이전 encoder 층에서 온다. decoder 셀프 어텐션은 i번째 위치가 i번째 이하만 보도록 뒤를 가린다. encoder-decoder 어텐션은 query는 decoder에서, key와 value는 encoder 출력에서 온다. 입력 token 임베딩과 출력 직전의 변환은 같은 가중치 행렬을 나눠 쓴다. → [트랜스포머](../learn/ai/nlp/transformer.md)

### 어텐션 계산

\[
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V
\]

멀티 헤드는 이 계산을 \(h = 8\)벌 두고, 헤드마다 query, key, value를 서로 다른 행렬로 \(d_k = d_v = 512/8 = 64\)칸으로 줄여서 계산한 뒤 이어 붙인다. 헤드 수를 늘려도 칸이 나뉘므로 전체 계산량은 헤드 하나일 때와 비슷하다. → [어텐션](../learn/ai/nlp/attention.md)

### 작은 예: 왜 \(\sqrt{d_k}\)로 나누나

query와 key의 각 칸이 평균 0, 분산 1인 독립된 값이면, 둘의 곱을 더한 점수의 분산은 \(d_k\)다. \(d_k = 64\)이면 점수의 표준편차가 8이고, 두 token의 점수가 8 차이 나면 소프트맥스에서 한쪽이 다른 쪽의 \(e^8 \approx 2{,}981\)배가 된다. 비율이 한 칸에 몰려서 기울기가 거의 0이 되고 학습이 멈춘다. 8로 나누면 표준편차가 1로 돌아온다. → [소프트맥스](../learn/ai/machine-learning/softmax.md)

### 위치 정보와 FFN

어텐션은 순서를 모르므로 입력 임베딩에 위치별 벡터를 더한다. 논문은 sin과 cos 함수의 주기를 칸마다 다르게 둔 고정 벡터를 썼다.

\[
PE(pos, 2i) = \sin\!\left(pos / 10000^{2i/d_{model}}\right), \quad PE(pos, 2i+1) = \cos\!\left(pos / 10000^{2i/d_{model}}\right)
\]

학습되는 위치 임베딩과 비교했을 때 BLEU가 거의 같았다(25.7 대 25.8). 고정 함수를 택한 이유는 학습 때 못 본 긴 길이로 확장될 수 있어서다. feed-forward는 \(\max(0, xW_1 + b_1)W_2 + b_2\)이고 안쪽 차원이 2048이다.

### 학습 설정

- **데이터**: WMT 2014 영어-독일어 약 450만 쌍(BPE 어휘 약 37,000), 영어-프랑스어 3,600만 문장(word-piece 32,000). 배치마다 원문과 번역문 token이 각각 약 25,000개다.
- **하드웨어**: P100 GPU 8개 한 대. 기본 모델은 한 step 0.4초, 100,000 step, 12시간. 큰 모델은 1.0초, 300,000 step, 3.5일.
- **옵티마이저**: Adam(\(\beta_1 = 0.9, \beta_2 = 0.98\)), 학습률은 처음 4,000 step 동안 선형으로 올리다가 step의 제곱근에 반비례해 줄인다(warmup).
- **정칙화**: 잔차 dropout 0.1(큰 영어-독일어 모델은 0.3)과 label smoothing 0.1. 논문은 label smoothing이 perplexity는 나쁘게 하지만 정확도와 BLEU는 올린다고 적는다.
- **추론**: beam 4, 길이 페널티 0.6, 마지막 체크포인트 5개(큰 모델은 20개)의 평균.

### 결과

| 모델 | 영어-독일어 BLEU | 영어-프랑스어 BLEU |
| --- | --- | --- |
| GNMT + RL | 24.6 | 39.92 |
| ConvS2S | 25.16 | 40.46 |
| ConvS2S 앙상블 | 26.36 | 41.29 |
| Transformer (base) | 27.3 | 38.1 |
| Transformer (big) | 28.4 | 41.8 |

영어-독일어에서는 큰 모델이 앙상블을 포함한 기존 최고를 2 BLEU 넘게 앞섰다. 학습 연산량은 큰 모델이 \(2.3 \times 10^{19}\) FLOPs로, ConvS2S 앙상블의 \(1.2 \times 10^{21}\)보다 두 자릿수 가까이 적다. 번역이 아닌 영어 구문 분석(WSJ 23절)에서도 4층 모델이 정답 라벨만으로 91.3 F1, 대량의 라벨 없는 문장을 더하면 92.7 F1을 냈다.

## 기억할 것

### 어텐션은 순서를 모릅니다

token 순서를 섞어도 각 token의 어텐션 결과는 같다. 위치 정보는 입력에 따로 더해야 한다. 이후 모델은 고정 함수 대신 학습하는 방식이나 회전 방식으로 바꿨다. → [셀프 어텐션](../learn/ai/nlp/self-attention.md)

### decoder는 뒤를 가립니다

생성할 때 아직 만들지 않은 뒤 token은 볼 수 없다. 학습 때는 정답이 이미 입력에 있으므로 뒤 token을 점수에서 가려야 학습과 생성이 같아진다. 이 가림 덕분에 앞 token의 key와 value를 저장해 두고 재사용하는 KV cache가 가능하다. → [Prefill, decode](../learn/ai/nlp/prefill-decode.md)

### 헤드는 많을수록 좋지 않습니다

헤드 1개는 기본(8개)보다 BLEU가 0.9 낮았고, 32개로 늘리면 오히려 25.4로 떨어졌다(기본 25.8). key 차원을 16이나 32로 줄이면 낮아졌고, 층 수와 차원은 클수록 좋았다. dropout을 빼면 24.6으로 크게 떨어져 정칙화가 중요했다.

## 리뷰

지금 LLM의 뼈대가 된 논문이다. 번역용 구조(encoder-decoder)로 쓰였지만 이후 decoder만 쓰는 모델과 encoder만 쓰는 모델로 갈라져 GPT와 BERT가 되었다. 어텐션 계산량이 입력 길이의 제곱으로 늘어난다는 한계도 이 논문부터 있었고, 논문이 이미 국소 어텐션을 대안으로 언급한다.
