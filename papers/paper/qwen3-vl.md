Qwen Team (Shuai Bai 외). *arXiv*, 2025. [원문 PDF](https://arxiv.org/pdf/2511.21631)

## 세 줄 요약

1. 텍스트, 이미지, 영상을 함께 읽는 Qwen 시리즈의 최신 VLM이다. dense 2B/4B/8B/32B와 MoE 30B-A3B, 235B-A22B가 있다.
2. 텍스트와 이미지, 영상이 섞인 입력을 token 256K까지 한 번에 읽는다.
3. 위치 표현, 시각 정보를 LLM에 넣는 방식, 영상 시간 표시 세 가지를 바꿔서 Qwen2.5-VL보다 긴 문맥과 영상을 더 잘 다룬다.

## 내용

### 구조

앞선 Qwen2.5-VL과 같은 세 조각이다. 비전 인코더가 이미지와 영상 frame을 token으로 바꾸고, MLP 연결부가 이를 LLM이 읽는 형태로 맞춰 넘긴다. 같은 구조에서 세 가지가 달라졌다. → [멀티모달](../learn/ai/deep-learning/multimodal.md)

- **Interleaved MRoPE**: 위치 정보를 시간, 높이, 너비 세 축으로 나눠 표현하는데, 세 축을 낮은 주파수와 높은 주파수 구간에 골고루 섞어 넣는다. 한 축이 특정 주파수에만 몰리는 것을 피한다.
- **DeepStack**: 비전 인코더의 여러 층에서 뽑은 시각 token을 LLM의 앞쪽 세 층에도 더해 준다. 마지막 층의 결과만 넣을 때 사라지는 세부 정보를 살리려는 것이다.
- **텍스트 timestamp**: 영상 frame 묶음 앞에 `<3.0 seconds>` 같은 시간 문자열을 넣는다. 절대 시간을 위치 인코딩에 섞는 대신, 모델이 시간을 글자로 읽게 한다.

### 학습

사전학습은 네 단계로, 갈수록 입력 길이를 늘린다.

```text
S0  연결부만 맞추기        약 67B token     길이 8K
S1  전체 멀티모달 학습     약 1T token      길이 8K
S2  긴 문맥 학습           약 1T token      길이 32K
S3  아주 긴 문맥 학습      약 100B token    길이 262K
```

이후 긴 사고 과정(CoT) 데이터로 SFT하고, 교사 모델에서 증류하고, 강화학습으로 마무리한다. 문서 이해를 위해 Common Crawl의 PDF 300만 건을, OCR에는 3,000만 건을 29개 언어를 더해서 썼다. → [post-training](../learn/ai/nlp/post-training.md)

### 결과

논문은 MMMU, MathVista, MathVision 같은 종합·시각 수학 평가에서 선두 수준이라고 밝힌다. 구체적인 점수는 본문 표를 확인해야 한다.

## 기억할 것

### 모델 이름의 A는 활성 파라미터입니다

`235B-A22B`는 전체 235B 중 token 하나를 처리할 때 22B만 쓰는 MoE라는 뜻이다. 계산량은 22B급이지만 가중치는 235B를 모두 메모리에 올려야 한다. 모델을 고를 때 GPU 메모리는 앞의 수, 속도는 뒤의 수를 본다. → [서빙](../learn/ai/deep-learning/serving.md)

### 256K는 입력 한도이지 활용 보장이 아닙니다

긴 문맥을 학습했어도 문맥 중간의 정보를 덜 쓰는 경향은 남아 있을 수 있다. 영상은 frame이 많을수록 token을 크게 쓴다. 긴 영상을 통째로 넣기 전에 필요한 구간만 자를 수 있는지 먼저 본다. → [어텐션](../learn/ai/nlp/attention.md)

### 기술 보고서는 구성 기록입니다

새 알고리즘 하나를 증명하는 논문이 아니라 구조, 데이터, 학습 단계, 후처리를 어떻게 쌓았는지의 기록이다. 어느 요소가 성능에 얼마나 기여했는지는 별도의 비교 실험이 있어야 안다.

## 리뷰

오픈 모델 중 가장 최근의 대표적인 VLM 기술 보고서다. 에이전트 개발에서는 256K 문맥에서 이미지와 영상을 한꺼번에 넣을 수 있다는 점, 문서와 OCR 쪽 데이터를 크게 늘렸다는 점이 눈에 띈다. 벤치마크 수치는 본문 표에서 직접 확인하지 않았다.
