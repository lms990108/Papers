## 요약

손으로 만든 특징과 손으로 짠 규칙 대신, 신경망과 기울기 학습으로 문서 인식 시스템 전체를 학습하자는 논문이다. 주장은 세 가지다.

- **합성곱 신경망(LeNet-5)**: 이미지의 국소 연결과 가중치 공유를 구조에 넣어서, 손으로 만든 특징 추출 없이 픽셀에서 바로 글자를 읽는다. → [LeNet-5](../learn/ai/deep-learning/lenet-5.md)
- **모듈 전체를 하나의 손실로 학습**: 분할, 글자 인식, 언어 모델처럼 따로 만들던 모듈을 그래프 변환 신경망(GTN)으로 이어 붙이고, 단어 단위 오류를 기준으로 함께 학습한다. 글자마다 사람이 분할과 라벨을 달아 줄 필요가 없다.
- **분할 없이 인식**: 합성곱망을 입력의 모든 위치에 훑게 하는 공간 이동 신경망(SDNN)으로 분할 휴리스틱 자체를 없앤다.

### 결과

| 실험 | 결과 |
| --- | --- |
| MNIST 숫자 인식, LeNet-5 | 시험 오류 0.95%, 변형한 데이터 540,000장을 더하면 0.8% |
| 같은 실험, 부스팅한 LeNet-4 | 0.7%로 가장 낮음 |
| 단어 수준 판별 학습 (사전 25,461단어) | 단어 오류 4.6%에서 3.2%로 감소 |
| 기계 인쇄 수표 646장 | 정답 82%, 오류 1%, 거부 17% (이전 시스템은 정답 68%, 거부 31%) |

수표 시스템은 NCR 제품에 들어가 1996년 6월부터 미국 은행에서 하루에 수백만 장을 읽었다고 한다.

## 리뷰

딥러닝의 기본 구도(입력에서 출력까지 하나의 손실로 학습)를 이미 갖춘 고전이다. 분량의 절반 이상은 문서 인식 전용 구조(GTN, SDNN)라서, 지금 읽을 부분은 서론, II-B(LeNet-5), III절(비교 실험) 정도다.
