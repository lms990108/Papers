## 세 줄 요약

1. 손으로 만든 특징 대신, 픽셀에서 바로 학습하는 합성곱 신경망(LeNet-5)으로 글자를 읽는다.
2. 분할, 글자 인식, 언어 모델을 그래프 변환 신경망(GTN)으로 이어 붙이고, 단어 오류 하나를 기준으로 함께 학습한다.
3. 이 방식으로 만든 수표 인식 시스템이 실제 은행에서 하루 수백만 장을 읽었다.

## 내용

### 풀려던 문제

문자 인식 시스템은 보통 두 부분이었다. 앞은 입력을 비교하기 쉬운 짧은 벡터로 바꾸는 특징 추출기이고, 대부분 사람이 손으로 만든다. 뒤는 범용 분류기다. 정확도가 설계자가 고른 특징에 크게 좌우되고, 과제가 바뀌면 특징을 다시 만들어야 했다. 이 논문이 나올 무렵에는 컴퓨터가 빨라졌고, 필기 인식처럼 큰 데이터베이스가 생겼고, 고차원 입력을 다루는 학습법도 나와 있었다. 손으로 만든 부분을 학습으로 바꿀 조건이 갖춰진 것이다.

논문의 논점은 두 갈래다. 낱글자를 잘 읽으려면 이미지 구조를 아는 신경망(II, III절)이 필요하고, 단어와 문서를 읽으려면 여러 모듈을 함께 학습하는 틀(IV~X절)이 필요하다.

### 완전 연결망이 이미지에서 겪는 두 가지 문제

픽셀이 수백 개인 이미지에 은닉 유닛 100개짜리 완전 연결층을 두면 가중치가 수만 개다. 파라미터가 많으면 학습 데이터가 더 필요하고 메모리도 먹는다. 더 큰 문제는 구조가 없다는 점이다. 글자가 조금 이동하거나 찌그러지면 입력이 완전히 달라 보이고, 완전 연결망은 이동에 불변인 출력을 배우려면 같은 가중치 패턴을 입력의 여러 위치에 따로 배워야 한다. 또 입력 변수의 순서를 아무렇게나 섞어도 학습 결과가 같다. 즉 가까운 픽셀끼리 상관이 높다는 이미지의 2차원 구조를 쓰지 못한다.

### LeNet-5: 구조에 사전 지식을 넣는다

세 가지 아이디어를 합친다. 한 유닛은 앞 층의 작은 이웃에서만 입력을 받고(국소 수용장), 수용장 위치만 다른 유닛들은 같은 가중치를 공유하고(가중치 공유), 해상도를 줄이는 서브샘플링 층을 둔다. 같은 가중치를 쓰는 유닛들의 출력 집합이 특징 맵이다. 입력이 이동하면 특징 맵 출력도 같은 만큼 이동하므로 이동에 강하다. 특징의 정확한 위치는 한번 검출하면 덜 중요하고(7인지는 윗부분 획의 끝과 구석의 대략적인 상대 위치로 알 수 있다), 서브샘플링이 이 정밀도를 일부러 낮춘다. → [CNN](../learn/ai/deep-learning/cnn.md)

LeNet-5는 입력을 빼고 7개 층이고, 모두 학습 파라미터를 가진다. 입력은 32×32인데, 데이터의 글자가 20×20 이하라서 가장자리 특징도 수용장 가운데에 오게 하려고 일부러 크게 잡았다.

```text
층   종류             크기                    학습 파라미터   연결 수
C1   합성곱 5×5       6장 × 28×28                  156        122,304
S2   서브샘플링 2×2   6장 × 14×14                   12          5,880
C3   합성곱 5×5       16장 × 10×10               1,516        151,600
S4   서브샘플링 2×2   16장 × 5×5                    32          2,000
C5   합성곱 5×5       120장 × 1×1               48,120         48,120
F6   완전 연결        84                        10,164         10,164
출력 RBF              10                    (고정)
```

합치면 학습 파라미터가 약 60,000개인데, 연결은 340,908개다. 같은 가중치를 되풀이해서 쓰기 때문이고, 파라미터가 적으면 과적합이 줄고 학습 데이터도 덜 든다. C3는 S2의 맵을 일부만 골라 연결한다. 연결 수를 줄이고, 더 중요하게는 서로 다른 입력을 받게 해서 서로 다른 특징을 뽑도록 대칭을 깨기 위해서다. → [LeNet-5](../learn/ai/deep-learning/lenet-5.md), [가중치 공유](../learn/ai/deep-learning/weight-sharing.md)

### 작은 예: 가중치 공유의 효과

C1은 32×32 이미지에 5×5 필터 6개를 적용한다. 필터 하나의 파라미터는 5×5+1(편향) = 26개, 6개이면 156개다. 출력 지도 하나가 28×28 = 784 위치라서 연결은 156×784 = 122,304개다. 연결은 12만 개가 넘지만 학습할 값은 156개뿐이다. 같은 필터를 784 위치에 되풀이해서 쓰기 때문이다.

### 출력층과 손실

출력층은 클래스마다 하나씩 RBF 유닛이다. F6의 84칸 상태가 그 클래스의 기준 벡터(성분이 +1 또는 −1, 7×12 비트맵으로 그린 그 글자 모양)에서 얼마나 먼지를 유클리드 거리로 낸다. 거리가 작을수록 그 클래스다. 이렇게 분산 부호로 둔 이유는 O, o, 0처럼 헷갈리는 글자가 비슷한 부호를 갖게 해서 언어 후처리기가 고르게 하고, 글자가 아닌 입력은 어떤 기준에서도 멀어서 거부하기 쉽게 하기 위해서다.

단순히 정답 클래스의 거리만 줄이는 손실에는 함정이 있다. 기준 벡터까지 학습시키면 모든 기준 벡터가 같아지고 F6 상태가 그 값으로 상수가 되어, 입력을 무시한 채 손실이 0이 되는 해가 있다. 그래서 정답의 거리는 줄이고 오답의 거리는 키우는 판별 손실(MAP 기준)을 쓴다. 이 손실이 기준 벡터를 서로 떨어뜨려 둔다. → [판별 학습](../learn/ai/machine-learning/discriminative-learning.md)

### 숫자 인식: 여러 분류기 비교

표준 필기 숫자 데이터(MNIST)에서 같은 조건으로 여러 분류기를 시험했다. 시험 오류의 불확실성은 약 0.1%다.

| 분류기 | 시험 오류 |
| --- | --- |
| 선형 분류기 | 12% |
| 클래스 쌍별 선형 | 7.6% |
| 최근접 이웃(픽셀 거리) | 5.0% |
| 은닉 300개 완전 연결망 | 4.7% |
| 은닉 1000개 완전 연결망 | 4.5% |
| RBF 망 | 3.6% |
| PCA 40차원 + 2차 다항식 | 3.3% |
| 은닉층 2개 (300-100) | 3.05% |
| LeNet-1 (파라미터 약 2,600개) | 1.7% |
| LeNet-4 | 1.1% |
| 접선 거리 최근접 이웃 | 1.1% |
| 서포트 벡터 머신 | 1.4%, 1.1% |
| LeNet-5 | 0.95% |
| 변형 데이터 540,000장 추가 LeNet-5 | 0.8% |
| 가상 서포트 벡터 SVM(V-SVM), 수정판 | 1.0%, 0.8% |
| 부스팅한 LeNet-4 | 0.7% |

변형은 이동, 확대·축소, 찌그러뜨림, 수평 전단을 조합한 아핀 변환이다. 부스팅은 분류기 세 개를 합치는 방식으로, 둘째는 첫째가 맞힌 것과 틀린 것을 반반 섞은 데이터로, 셋째는 앞의 둘이 갈리는 패턴으로 학습한다. 시험 때는 세 망의 출력을 더하지만 첫째가 확신하면 나머지를 부르지 않아서, 평균 비용은 단일 망의 약 1.75배다.

### 정확도만 보지 않는다: 거부, 연산량, 메모리

논문은 오류 0.5%를 맞추려면 시험 패턴을 얼마나 거부해야 하는지(거부 점수는 상위 두 클래스 점수의 차)를 따로 비교한다. 여기서도 부스팅 LeNet-4가 가장 좋았다. 메모리 기반 방법(최근접 이웃, SVM)은 계산과 메모리가 훨씬 크다. 학습에는 LeNet-5가 당시 SGI Origin 2000 한 개에서 2~3일 걸렸는데, 저자들은 학습 시간은 설계자에게만 중요하고 최종 사용자에게는 거의 중요하지 않다고 말한다. SVM은 문제에 대한 사전 지식을 넣지 않고도 합성곱망에 가까운 성능을 내는데, 그만큼 메모리와 계산을 더 쓴다.

### 이동과 잡음에 강하다

LeNet-5는 크기 변화 약 2배, 세로 이동은 글자 높이의 절반, 회전 약 ±30도까지 정확히 읽는 것으로 추정된다. 학습 데이터에 소금-후추 잡음(각 픽셀을 확률 0.1로 뒤집기)을 더해도 읽는다. 이것이 중요한 이유는 실제 문서에서는 분할이 완벽하지 않아서, 글자 조각이 어긋나거나 잡음이 섞인 채 인식기로 들어오기 때문이다.

### 낱글자에서 단어로

실제 문서에는 단어와 문자열이 있다. 글자를 자르고(분할), 읽고, 언어 모델로 고르는 모듈을 따로 만들면 각자는 최적이어도 전체는 최적이 아니다. 분할이 틀리면 뒤가 아무리 좋아도 소용이 없다. 해법의 첫 단계는 후보를 많이 만드는 것이다. 휴리스틱 과분할은 글자를 일부러 잘게 자른 조각들을 여러 방식으로 이어 붙인 해석을 그래프로 만들고, 어느 해석이 맞는지는 인식 결과와 언어 지식을 합쳐서 나중에 정한다. 결정을 미루는 방식이다.

### GTN: 모듈 사이에 그래프를 주고받는다

모듈 사이에 벡터 대신 호마다 점수가 붙은 유향 그래프를 주고받는 시스템을 그래프 변환 신경망(GTN)이라 한다. 그래프의 한 경로가 입력의 한 해석이고, 호에 붙은 수가 그 해석의 벌점(비용)이다. 모듈이 호의 수를 미분 가능한 함수로 만드는 한, 최종 오류의 기울기를 출력 그래프에서 입력 그래프와 모듈 내부 파라미터로 역전파할 수 있다. 일부러 확률론을 앞세우지 않고 모든 양을 벌점으로 본다.

문자열 수준에서 학습하는 방법이 네 가지다. 비터비 학습, 판별적 비터비 학습, 전방 학습, 판별적 전방 학습이다. 마지막 것은 앞의 MAP 기준을 그래프 시스템으로 일반화한 것이다. 글자마다 사람이 분할과 라벨을 달지 않아도, 정답 단어만 있으면 정답 단어와 일치하는 경로의 비용은 낮추고 틀린 경로의 비용은 올린다. → [비터비](../learn/ai/machine-learning/viterbi.md), [HMM](../learn/ai/machine-learning/hmm.md)

HMM 학습은 확률을 정규화하는 생성 모델이 필요하지만, 신경망이 들어가면 그 정규화가 유지되지 않는다. 판별 학습은 이 제약이 없다는 점이 논문의 주장이다.

### SDNN: 분할 없이 훑는다

휴리스틱 분할 대신 합성곱망을 입력 단어 이미지의 모든 위치에 복제해서 훑는 방법이 공간 이동 신경망(SDNN)이다. 이웃 인스턴스가 겹치는 부분은 한 번만 계산하면 되므로, 입력 필드를 넓힌 합성곱망 하나와 같다. LeNet-5의 C5가 1×1이어서 합성곱층이라고 부르는 이유가 이것이다. 출력은 위치마다 "여기에 이 글자가 있다"는 증거이고, 글자 사이 위치에서는 "없음"이다.

### 온라인 필기 인식

펜 궤적을 쓰는 온라인 필기 인식기는 전처리(단어 정규화), 이미지 생성, 복제된 합성곱망, 단어 수준 제약을 쓰는 GTN으로 이루어진다. 소문자 단어 881개를 시험했고 글자 수준 정규화 대신 단어 정규화를 쓰면 단어 오류가 7.3%에서 4.6%로 줄었다(사전 25,461단어). 단어 수준 판별 학습으로 사전 없이 SDNN/HMM은 단어 오류 38%에서 26%로, 과분할 시스템은 22.5%에서 17%로 줄었다. 사전을 25,461단어로 쓸 때 4.6%에서 3.2%, 350단어로 줄이면 1.6%까지 갔다.

### 수표 읽기 시스템

수표에는 금액이 두 벌이다. 숫자로 쓴 예의 금액(courtesy amount)과 글로 쓴 법정 금액(legal amount)이고, 이 시스템은 예의 금액을 읽는다. 업무용 수표는 인쇄라서 읽기는 쉽지만 레이아웃이 제각각이라 금액 위치를 찾기가 어렵고, 개인용 수표는 반대다. 은행이 정한 상용화 기준은 수표의 50%를 오류 1% 미만으로 읽고 나머지 50%는 사람에게 넘기는 것(50% 정답, 49% 거부, 1% 오류)이었다.

기계 인쇄 수표 646장에서 이 시스템은 정답 82%, 오류 1%, 거부 17%였다. 이전 시스템은 정답 68%, 오류 1%, 거부 31%였다. 개선은 인식기를 더 크고 더 많은 데이터로 학습한 것, GTN 구조 덕에 금액 문법 제약을 더 효율적으로 쓴 것, 휴리스틱을 시험하고 조정하는 유연성이 높아진 것 세 가지 때문이다. 저자들은 이 과제에서 전역 학습의 기여는 작았다고 솔직하게 적는다. 전역 학습이 파라미터의 작은 부분집합에만 적용됐기 때문이다. 이 시스템은 NCR 제품에 통합되어 1996년 6월부터 미국 은행에서 하루에 수백만 장을 읽었다.

## 기억할 것

### 정답, 오류, 거부를 따로 봅니다

수표처럼 틀리면 비용이 큰 곳에서는 오류를 1%로 고정하고 거부(사람에게 넘김)를 얼마나 줄이느냐가 성능이다. 이 논문의 82% 정답은 오류 1%를 유지하면서 거부를 31%에서 17%로 줄인 결과다. 에이전트가 "모르겠다"고 답하거나 사람에게 넘기는 기준을 정하는 일과 같은 구조다.

### 끝에서 끝까지 학습한다는 생각

모듈을 따로 최적화하지 않고 최종 결과의 오류를 모듈 전체에 흘려보내 함께 학습한다. 지금 모델은 거의 모두 이 방식이다. 에이전트 파이프라인을 평가할 때 중간 단계마다 정답을 달지 않고 최종 결과로 평가하는 것도 같은 생각이다. 다만 이 논문의 수표 시스템에서도 전역 학습의 이득은 작았다는 점을 함께 기억한다.

### 데이터를 변형해 늘립니다

변형 데이터로 오류가 0.95%에서 0.8%로 줄었다. 라벨을 더 달지 않고 같은 데이터를 조금씩 바꿔서 늘리는 증강은 지금도 쓰인다. 같은 20 에폭 동안 개별 표본을 사실상 두 번만 보는데도 효과가 있었다.

### 구조가 데이터를 대신합니다

완전 연결망은 이미지에 대한 사전 지식이 없어서 더 많은 데이터가 필요하다. 이미지 구조를 구조에 넣은 합성곱망은 파라미터가 훨씬 적고도 더 좋았다. 문제의 구조를 알면 모델에 넣는 편이 데이터를 더 모으는 것보다 싸다.

<summary>더 깊이: 학습 설정과 부록</summary>

- 학습은 확률적 기울기에 대각 헤시안 근사로 파라미터마다 학습률을 따로 정하는 방식(확률적 대각 Levenberg-Marquardt)이다. 학습률은 \(\eta / (\mu + h_{kk})\)이고 \(h_{kk}\)는 패턴 500개로 다시 추정한다. 학습 집합을 20번 통과한다. 큰 데이터에서는 배치 방식보다 확률적 방식이 자릿수 차이로 빠르다는 것이 실용적으로 중요하다고 적는다.
- 시험 오류는 10번쯤 통과한 뒤 0.95%에서 안정되고, 학습 오류(0.35%)가 계속 줄어도 시험 오류가 다시 오르지 않았다. 저자들은 큰 학습률이 가중치를 계속 흔들어 넓은 최솟값을 고르게 하는 정칙화 효과 때문일 수 있다고 본다.
- 활성 함수는 \(1.7159 \tanh(2a/3)\)이라서 입력이 ±1일 때 출력이 ±1이다. 가중치는 입력 수의 제곱근에 반비례하는 범위로 초기화한다.
- 합성곱망은 하드웨어 구현이 쉬워서 칩으로 만들면 초당 1,000글자 넘게 읽을 수 있었다고 한다.
- 일반화 변환과 HMM의 관계(VIII절), 학습하지 않는 변환기 같은 이론적 확장은 이 페이지에서 다루지 않았다.
