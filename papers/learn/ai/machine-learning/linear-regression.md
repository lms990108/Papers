선형 회귀는 입력에 가중치를 곱하고 바이어스를 더해 수 하나를 내는 모델입니다. 그 수가 정답 수에 가깝도록 가중치와 바이어스를 고릅니다.

에이전트 개발에서 선형 회귀를 직접 쓰는 일은 드뭅니다. 그래도 곳곳에 들어 있습니다.

- **신경망의 선형 층**: LLM과 임베딩 모델 안의 층은 대부분 이 곱셈과 덧셈입니다. 층을 이루는 기본 단위입니다. → [층](../deep-learning/layer.md)
- **점수를 내는 모델**: reward model, reranker, 비용·지연 예측처럼 수 하나를 출력하는 모델이 회귀입니다.
- **MSE 손실**: 평균 제곱 오차는 수를 맞히는 모든 학습의 기본 손실 함수입니다.

## 직선과 오차

좋다 횟수 \(x\)로 별점 \(y\)를 내는 식입니다. \(w\)는 기울기이고 \(b\)는 좋다가 0번일 때의 시작 별점입니다.

\[
y = wx + b
\]

리뷰 두 개로 봅니다. 좋다 1번이면 별점 4, 좋다 2번이면 별점 4입니다. \(w = 1\), \(b = 3\)이면 예측은 4와 5입니다. 오차는 예측에서 정답을 뺀 값이라 0과 1입니다.

직선을 끌어 보면 오차 선이 어떻게 달라지는지 보입니다.

<LineFitDrag />

오차를 그냥 더하면 문제가 생깁니다. 다른 직선 \(y = 2x + 1\)은 예측이 3과 5라서 오차가 -1과 +1입니다. 합은 0이라 틀린 곳이 없어 보입니다. 제곱하면 부호가 사라져 \(1 + 1 = 2\)가 남습니다. 제곱의 평균이 평균 제곱 오차(MSE)입니다.

\[
\mathrm{MSE} = \frac{1}{n}\sum (y - t)^2
\]

\(t\)는 정답 별점입니다. 세 직선의 MSE를 비교하면 \(y = x + 3\)이 0.5, \(y = 2x + 1\)이 1, \(y = 3x\)가 2.5입니다. 학습은 이 값이 가장 작은 \(w\)와 \(b\)를 찾는 일입니다. 입력이 둘이면 항이 하나 더 붙습니다.

\[
y = w_1 x_1 + w_2 x_2 + b
\]

## 기억할 것 세 가지

### 제곱은 큰 실수를 크게 벌줍니다

오차가 1, 1, 1이면 절댓값의 합과 제곱의 합이 모두 3입니다. 오차가 0, 0, 3이면 절댓값의 합은 3으로 같은데 제곱의 합은 9입니다. 한 건이 크게 빗나가면 그 건이 학습을 끌고 갑니다. 이상한 값이 섞인 데이터에서 MSE가 약한 이유입니다. 레이블이 잘못 붙은 건이 있으면 먼저 의심해야 합니다.

### 선형은 입력이 아니라 가중치에 대해서만 선형입니다

\(x\)와 \(x^2\)를 같이 넣은 \(y = w_1 x + w_2 x^2 + b\)는 곡선을 그립니다. 그래도 \(w_1,\ w_2,\ b\)에는 곱하고 더할 뿐이라 선형 회귀입니다. 특성을 어떻게 만들지에 따라 표현력이 달라집니다.

### 오차가 0이 목표는 아닙니다

점들이 한 직선 위에 있지 않으면 오차는 0이 될 수 없습니다. 쌍이 몇 개 안 되는데 특성을 많이 넣으면 학습 오차가 0이 되어도 새 입력에서 틀립니다. 그래서 학습에 쓰지 않은 데이터로 따로 잽니다. → [데이터 분리](./data-split.md), [용량과 정칙화](../deep-learning/capacity.md)

<summary>더 깊이: 한 번의 갱신과 최소제곱 해</summary>

- 오차 \(E = (y - t)^2\)의 기울기는 \(\partial E / \partial w_1 = 2(y - t)\,x_1\), \(\partial E / \partial w_2 = 2(y - t)\,x_2\), \(\partial E / \partial b = 2(y - t)\)입니다. 기울기의 반대 방향으로 학습률 \(\eta\)만큼 고칩니다. 식으로는 \(w \leftarrow w - \eta\,\partial E / \partial w\)입니다.
- 입력 \((2,\ 0)\), 정답 4, 현재 \(w_1 = 1\), \(w_2 = -1\), \(b = 3\)이면 예측은 5이고 \(y - t = 1\)입니다. 기울기는 4, 0, 2이고, 학습률 0.1이면 \(w_1 = 0.6\), \(w_2 = -1\), \(b = 2.8\)이 됩니다. 새 예측은 \(0.6 \times 2 + 2.8 = 4\)라 오차가 0이 됩니다. 한 건에 맞추면 다른 건이 틀어지므로, 실제 학습은 모든 건의 평균 오차를 보며 조금씩 고칩니다. → [경사하강법](../deep-learning/gradient-descent.md)
- 입력이 하나이고 점이 적으면 식으로 바로 구합니다. 점 \((0,\ 3)\), \((1,\ 3)\), \((2,\ 5)\)에서 \(w = \sum (x_i - \bar{x})(t_i - \bar{t}) / \sum (x_i - \bar{x})^2 = 2/2 = 1\), \(b = \bar{t} - w\bar{x} = 11/3 - 1 \approx 2.667\)입니다. 이때 오차의 제곱 합은 \(2/3\)입니다.
- 바이어스를 빼면 입력이 모두 0일 때 예측이 0에 묶입니다.
- 수 대신 칸을 고르려면 점수를 비율로 바꾸는 [로지스틱 회귀](./logistic-regression.md)를 씁니다. 이름의 유래는 [회귀](./regression.md)에 있고, 단계를 쌓은 모양이 [신경망](../deep-learning/neural-network.md)입니다.
