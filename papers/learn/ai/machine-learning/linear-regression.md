선형 회귀는 입력에 가중치를 곱하고 바이어스를 더해 수 하나를 내는 모델입니다. 그 수가 정답 수에 가깝도록 가중치와 바이어스를 고릅니다.

에이전트 개발에서 선형 회귀를 직접 쓰는 일은 드뭅니다. 그래도 곳곳에 들어 있습니다.

- **신경망의 선형 층**: LLM과 임베딩 모델 안의 층은 대부분 이 곱셈과 덧셈입니다. → [층](../deep-learning/layer.md)
- **점수를 내는 모델**: reward model, reranker, 비용 예측, 지연 예측처럼 수 하나를 출력하는 모델이 회귀입니다.
- **MSE 손실**: 평균 제곱 오차는 수를 맞히는 학습에서 가장 흔한 손실 함수입니다.

## 왜 필요한가

리뷰의 “좋다” 횟수로 별점을 맞히거나, 요청의 출력 token 수로 응답 시간을 맞히는 것처럼 입력 숫자로 수 하나를 예측해야 할 때가 있습니다. [지도 학습](./supervised-learning.md)에서 레이블이 수이면 회귀라고 했습니다. 선형 회귀는 그중 가장 단순한 모델입니다.

단순한 방법 둘이 어디서 막히는지 점 세 개로 봅니다. 입력 \(x\)와 정답 \(t\)가 \((0,\ 3)\), \((1,\ 3)\), \((2,\ 5)\)인 예입니다.

- **입력을 보지 않고 평균만 답합니다.** 정답 평균은 \(11/3 \approx 3.67\)이고, 오차를 제곱해 평균 낸 값이 0.89입니다. \(x\)가 0이든 2든 같은 답을 내니, 입력이 알려 주는 정보를 버립니다.
- **본 입력과 답을 표로 외웁니다.** 표에 있는 \(x = 1\)에는 3이라고 답합니다. \(x = 1.5\)나 3은 표에 없어서 답할 수 없습니다. 입력이 연속인 수이면 처음 보는 값이 거의 항상 나옵니다.

직선은 이 둘을 한꺼번에 풉니다. 입력이 1 늘 때 출력이 일정한 만큼 오른다는 가정 하나를 두고, 값 두 개(기울기와 시작점)만 정합니다. 처음 보는 입력에도 직선 위의 값으로 답합니다. 위 점 세 개에는 \(y = x + 2.67\)이 잘 맞고, 같은 방식으로 잰 오차가 0.22로 평균 답의 4분의 1 수준입니다. 이 직선을 어떻게 정하는지가 이 페이지의 내용입니다.

## 직선과 오차

좋다 횟수 \(x\)로 별점 \(y\)를 내는 식입니다. \(w\)는 좋다가 한 번 늘 때 별점이 얼마나 오르는지 정하는 기울기이고, 가중치라고도 부릅니다. \(b\)는 바이어스로, 좋다가 0번일 때의 시작 별점입니다.

\[
y = wx + b
\]

리뷰 두 개로 봅니다. 좋다 1번이면 별점 4, 좋다 2번이면 별점 4입니다. \(w = 1\), \(b = 3\)이면 예측은 4와 5입니다. 정답 별점을 \(t\)라고 하면 오차는 예측 \(y\)에서 정답 \(t\)를 뺀 값이라 0과 1입니다.

직선을 끌어 보면 오차 선이 어떻게 달라지는지 보입니다.

<LineFitDrag />

오차를 그냥 더하면 문제가 생깁니다. 다른 직선 \(y = 2x + 1\)은 예측이 3과 5라서 오차가 -1과 +1입니다. 합은 0이라 틀린 곳이 없어 보입니다. 제곱하면 부호가 사라져 \(1 + 1 = 2\)가 남습니다. 제곱의 평균이 평균 제곱 오차(MSE)이고, 이렇게 틀린 정도를 하나의 수로 만든 값을 손실이라고 합니다.

\[
\mathrm{MSE} = \frac{1}{n}\sum (y - t)^2
\]

\(n\)은 리뷰 수입니다. 세 직선의 MSE를 비교하면 \(y = x + 3\)이 0.5, \(y = 2x + 1\)이 1, \(y = 3x\)가 2.5입니다. 학습은 이 값이 가장 작은 \(w\)와 \(b\)를 찾는 일입니다. 직선을 하나씩 대 보는 대신 MSE가 줄어드는 쪽으로 \(w\)와 \(b\)를 조금씩 고치며 찾습니다. → [경사하강법](../deep-learning/gradient-descent.md)

입력이 둘이면 항이 하나 더 붙습니다.

\[
y = w_1 x_1 + w_2 x_2 + b
\]

## 가중치와 바이어스는 이렇게 읽습니다

선형 회귀의 장점은 파라미터를 말로 읽을 수 있다는 점입니다. 예로 출력 token 수 \(x\)로 응답 시간 \(y\)(초)를 맞춘 식이 \(y = 0.02x + 0.8\)이라고 합시다(장난감 수치입니다). 바이어스 0.8은 token이 0개여도 드는 고정 시간이고, 가중치 0.02는 token 하나가 더 늘 때마다 붙는 시간입니다. 500 token이면 \(0.02 \times 500 + 0.8 = 10.8\)초입니다. 입력이 여러 개여도 가중치 하나가 입력 하나의 영향을 맡으니, 학습된 값을 보고 어느 입력이 크게 작용하는지 짐작할 수 있습니다. 입력의 단위가 다르면 가중치의 크기를 곧바로 비교할 수 없다는 점은 조심해야 합니다.

## 기억할 것 세 가지

### 제곱은 큰 실수를 크게 벌줍니다

오차가 1, 1, 1이면 절댓값의 합과 제곱의 합이 모두 3입니다. 오차가 0, 0, 3이면 절댓값의 합은 3으로 같은데 제곱의 합은 9입니다. 한 건이 크게 빗나가면 그 건이 학습을 끌고 갑니다. 이상한 값이 섞인 데이터에서 MSE가 약한 이유입니다. 레이블이 잘못 붙은 건이 있으면 먼저 의심해야 합니다.

### 선형은 입력이 아니라 가중치에 대해서만 선형입니다

\(x\)와 \(x^2\)를 같이 넣은 \(y = w_1 x + w_2 x^2 + b\)는 곡선을 그립니다. 그래도 \(w_1,\ w_2,\ b\)에는 곱하고 더할 뿐이라 선형 회귀입니다. 특성을 어떻게 만들지에 따라 표현력이 달라집니다.

### 오차가 0이 목표는 아닙니다

점들이 한 직선 위에 있지 않으면 오차는 0이 될 수 없습니다. 쌍이 몇 개 안 되는데 특성을 많이 넣으면 학습 오차가 0이 되어도 새 입력에서 틀립니다. 그래서 학습에 쓰지 않은 데이터로 따로 잽니다. → [데이터 분리](./data-split.md), [용량과 정칙화](../deep-learning/capacity.md)

- 오차 \(E = (y - t)^2\)의 기울기는 \(\partial E / \partial w_1 = 2(y - t)\,x_1\), \(\partial E / \partial w_2 = 2(y - t)\,x_2\), \(\partial E / \partial b = 2(y - t)\)입니다. 기울기의 반대 방향으로 learning rate \(\eta\)만큼 고칩니다. 식으로는 \(w \leftarrow w - \eta\,\partial E / \partial w\)입니다.
- 입력 \((2,\ 0)\), 정답 4, 현재 \(w_1 = 1\), \(w_2 = -1\), \(b = 3\)이면 예측은 5이고 \(y - t = 1\)입니다. 기울기는 4, 0, 2이고, learning rate 0.1이면 \(w_1 = 0.6\), \(w_2 = -1\), \(b = 2.8\)이 됩니다. 새 예측은 \(0.6 \times 2 + 2.8 = 4\)라 오차가 0이 됩니다. 한 건에 맞추면 다른 건이 틀어지므로, 실제 학습은 모든 건의 평균 오차를 보며 조금씩 고칩니다. → [경사하강법](../deep-learning/gradient-descent.md)
- 입력이 하나이고 점이 적으면 식으로 바로 구합니다. 점 \((0,\ 3)\), \((1,\ 3)\), \((2,\ 5)\)에서 \(w = \sum (x_i - \bar{x})(t_i - \bar{t}) / \sum (x_i - \bar{x})^2 = 2/2 = 1\), \(b = \bar{t} - w\bar{x} = 11/3 - 1 \approx 2.667\)입니다. 이때 오차의 제곱 합은 \(2/3\)입니다.
- 바이어스를 빼면 입력이 모두 0일 때 예측이 0에 묶입니다.
- 수 대신 칸을 고르려면 점수를 비율로 바꾸는 [로지스틱 회귀](./logistic-regression.md)를 씁니다. 이름의 유래는 [회귀](./regression.md)에 있고, 단계를 쌓은 모양이 [신경망](../deep-learning/neural-network.md)입니다.
