머신러닝은 규칙을 글로 쓰는 대신, 입력과 정답이 붙은 쌍으로 함수 안의 수를 정하는 방법입니다. 그 수를 파라미터라고 부릅니다.

에이전트를 만들 때 이미 머신러닝의 결과물을 쓰고 있습니다.

- **LLM**: 다음 token을 맞히는 문제로 파라미터 수십억 개를 정한 모델입니다. API 호출은 학습이 끝난 모델을 쓰는 일입니다. → [다음 token](../nlp/next-token.md)
- **임베딩 모델과 reranker**: RAG에서 문서를 찾고 순서를 매기는 모델도 같은 방식으로 만들었습니다.
- **분류, 라우팅, guardrail**: 요청을 분류하거나 위험한 출력을 걸러 내는 작은 모델이 흔합니다. → [로지스틱 회귀](./logistic-regression.md)
- **평가**: 정답이 붙은 평가 세트로 점수를 내고 prompt를 고르는 일은 머신러닝의 검증 방법 그대로입니다. → [데이터 분리](./data-split.md)

## 규칙 대신 파라미터

영화 리뷰가 긍정인지 부정인지 맞힌다고 합시다. 규칙은 “나쁘다가 있으면 부정”처럼 씁니다. 그러면 “나쁘지 않다”와 “최고네요”(비꼼)에서 예외가 계속 늘어납니다.

머신러닝은 식의 뼈대만 사람이 정합니다. “좋다” 횟수 \(x_1\)과 “나쁘다” 횟수 \(x_2\)에 곱할 수를 비워 둡니다.

\[
s = w_1 x_1 + w_2 x_2
\]

\(w_1,\ w_2\)가 파라미터입니다. 쌍으로 학습해서 \(w_1 = 1\), \(w_2 = -1\)이 들어갔다고 합시다. \(s\)가 0보다 크면 긍정으로 읽습니다.

```text
리뷰              (x1, x2)   s = x1 - x2   읽은 답
연기가 좋다        (1, 0)         1          긍정
결말이 나쁘다      (0, 1)        -1          부정
```

파라미터가 둘뿐인 이 식을 여러 단계로 쌓은 것이 [신경망](../deep-learning/neural-network.md)이고, 파라미터를 고치는 절차가 [경사하강법](../deep-learning/gradient-descent.md)입니다. 입력이 글인 문제는 [자연어 처리](../nlp/)로 묶습니다.

## 기억할 것 세 가지

### 학습과 추론은 다른 단계입니다

파라미터를 정하는 단계가 학습(training)이고, 정한 뒤 새 입력에 답을 내는 단계가 추론(inference)입니다. 에이전트 개발자가 하는 일은 거의 추론입니다. prompt를 바꾸고 예시를 넣어도 모델의 파라미터는 바뀌지 않습니다. 파라미터를 바꾸는 일은 fine-tuning뿐입니다.

### 학습 데이터를 맞힌다고 새 입력도 맞히지 않습니다

“좋다”만 한 번 또는 두 번 나온 긍정 리뷰 둘과 “나쁘다”만 한 번 또는 두 번 나온 부정 리뷰 둘을 모두 맞히는 \((w_1,\ w_2)\)는 정수 -2부터 2까지만 봐도 여섯 쌍입니다(\(s = 0\)은 부정으로 읽습니다). 학습 데이터만 보면 여섯 쌍이 똑같이 좋습니다. 새 리뷰에서는 달라질 수 있습니다. 그래서 학습에 쓰지 않은 데이터를 따로 둡니다. → [데이터 분리](./data-split.md)

### 레이블이 틀리면 틀린 채로 배웁니다

“최고네요”라는 비꼬는 리뷰에 긍정이 붙어 있으면 모델은 그 답을 따라갑니다. 데이터 양보다 레이블 품질이 먼저입니다. fine-tuning 데이터나 평가 세트를 만들 때도 같습니다.

## 문서 구성

- [지도 학습](./supervised-learning.md): 입력과 레이블 쌍으로 배우는 학습, 분류와 회귀
- [회귀](./regression.md): 이름의 유래와 평균으로 돌아가는 현상
- [선형 회귀](./linear-regression.md): 직선과 평균 제곱 오차
- [로지스틱 회귀](./logistic-regression.md): 시그모이드와 cross entropy
- [소프트맥스](./softmax.md): 점수를 비율로 바꾸는 함수와 temperature
- [퍼셉트론](./perceptron.md): 부호만 보는 단위와 XOR
- [데이터 분리](./data-split.md): train, validation, test
- [판별 학습](./discriminative-learning.md): 오답을 같이 보는 오차
- [MNIST](./mnist.md): 비교용 데이터 집합과 오류 읽기
- [부스팅](./boosting.md): 앞 모델이 틀린 곳에 집중하는 앙상블
- [서포트 벡터 머신](./svm.md): 여백이 가장 큰 직선과 커널
- [은닉 마르코프 모델](./hmm.md): 보이지 않는 상태의 열
- [비터비](./viterbi.md): 격자에서 가장 좋은 경로 하나
- [전방 알고리즘](./forward-algorithm.md): 격자의 모든 경로 합
