퍼셉트론은 입력에 가중치를 곱해 더하고, 합이 0보다 크면 1, 아니면 0을 내는 가장 작은 신경망 단위입니다. 지금 에이전트 개발에 직접 쓰이지는 않는 배경 지식입니다. LLM 안의 뉴런도 곱하고 더한 뒤 활성화 함수를 거치는 이 구조에서 나왔습니다.

[로지스틱 회귀](./logistic-regression.md)와 점수까지는 같고, 비율을 만들지 않고 부호만 봅니다.

## 계산과 한계

가중치 \((1,\ -1)\), 바이어스 0으로 리뷰를 읽습니다. 점수 \(s\)가 0보다 크면 1(긍정), 아니면 0(부정)입니다.

\[
s = w \cdot x + b, \quad y = 1 \text{ if } s > 0, \text{ else } 0
\]

```text
리뷰         (x1, x2)   s     y
연기가 좋다   (1, 0)     1     1
결말이 나쁘다 (0, 1)    -1     0
```

1과 0의 경계는 \(s = 0\)인 직선 하나입니다. 입력이 두 칸이면 이 직선으로 갈리는 문제만 풀립니다.

두 입력이 모두 1일 때만 1인 논리곱(AND)은 풀립니다. \(w = (1,\ 1)\), \(b = -1.5\)이면 \(s = x_1 + x_2 - 1.5\)라서 \((1,\ 1)\)에서만 0.5로 양수입니다.

두 입력이 다를 때만 1인 배타적 논리합(XOR)은 직선 하나로 안 풀립니다. \((0,0)\)과 \((1,1)\)이 0이고 \((1,0)\)과 \((0,1)\)이 1이라, 1인 두 점이 대각선에 있습니다. 그 둘만 한쪽에 두는 직선이 없습니다.

두 단계로 나누면 풉니다. 첫 단계에 칸 둘을 둡니다. \(h_1 = [x_1 + x_2 - 0.5 > 0]\)은 하나라도 1이면 1이고, \(h_2 = [x_1 + x_2 - 1.5 > 0]\)는 둘 다 1일 때만 1입니다. 둘째 단계는 \(y = [h_1 - h_2 - 0.5 > 0]\)입니다.

```text
x1 x2   h1 h2   h1-h2-0.5   y
0  0    0  0     -0.5       0
1  0    1  0      0.5       1
0  1    1  0      0.5       1
1  1    1  1     -0.5       0
```

첫 단계가 네 점을 \((h_1,\ h_2)\) 평면으로 옮깁니다. 대각선에 있던 \((1,0)\)과 \((0,1)\)이 같은 점 \((1,0)\)으로 모이고, 그 점 하나를 직선이 갈라 냅니다. 입력 평면과 옮긴 평면을 나란히 보세요.

## 기억할 것 세 가지

### 활성화 함수가 없으면 층을 쌓아도 직선 하나입니다

곱하고 더하는 계산을 아무리 쌓아도 합치면 곱하고 더하는 계산 하나입니다. 가운데에 부호나 tanh 같은 비선형 함수가 있어야 단계가 의미를 가집니다. LLM의 층 사이에 활성화 함수가 있는 이유입니다. → [신경망](../deep-learning/neural-network.md), [층](../deep-learning/layer.md)

### 직선으로 안 갈리면 데이터를 더 모아도 소용없습니다

XOR은 네 건뿐이어도 못 풀고, 1000번을 돌려도 학습이 멈추지 않습니다. 건을 더하는 문제가 아니라 모델의 모양을 바꿔야 하는 문제입니다.

### 부호는 틀린 정도를 남기지 않습니다

점수 0.5도 5도 출력이 똑같이 1입니다. 얼마나 틀렸는지가 사라져서 연속적으로 줄여 가는 학습이 어렵고, 부호 함수는 거의 모든 곳에서 기울기가 0입니다. 그래서 단계를 쌓은 모델은 부호 대신 매끄러운 함수를 씁니다. → [역전파](../deep-learning/backpropagation.md)

<summary>더 깊이: 퍼셉트론 학습 규칙</summary>

- 1958년 로젠블랫이 소개한 규칙은 입력을 하나 보고, 예측 \(y\)가 정답 \(t\)와 다를 때만 고치는 것입니다. \(w \leftarrow w + \eta\,(t - y)\,x\), \(b \leftarrow b + \eta\,(t - y)\)입니다.
- 가중치와 바이어스가 0에서 시작하고 \(\eta = 1\)이면, “연기가 좋다” \((1,\ 0)\), 정답 1에서 \(s = 0\)이라 예측이 0이고 \(t - y = 1\)입니다. \(w = (1,\ 0)\), \(b = 1\)이 됩니다. 다음 “결말이 나쁘다” \((0,\ 1)\), 정답 0은 \(s = 1\)이라 예측이 1이고 \(t - y = -1\)이라 \(w = (1,\ -1)\), \(b = 0\)이 됩니다. 두 건 다 맞으므로 멈춥니다.
- 직선으로 갈리는 데이터에서는 유한 번 안에 멈추는 것이 알려져 있고, 갈리지 않으면 멈추지 않습니다. 이 한계는 1969년 민스키와 페퍼트의 책에서 정리되었습니다.
- 0에서 시작하고 부호만 보는 이 규칙에서는 \(\eta\)를 바꿔도 틀리는 순서가 같고 가중치가 \(\eta\)배가 될 뿐입니다.
- 데이터를 가르는 직선이 여럿일 때 가장 가까운 점들에서 가장 멀리 두는 직선을 고르는 방법이 [서포트 벡터 머신](./svm.md)입니다. 부호 대신 시그모이드를 쓰면 [로지스틱 회귀](./logistic-regression.md)입니다.

</details>
