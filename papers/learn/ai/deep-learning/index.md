LLM과 임베딩 모델이 어떻게 만들어지고 돌아가는지를 다루는 섹션입니다. 모델을 호출하는 에이전트 개발자가 만나는 모델 크기, 학습 설정(learning rate, epochs), 서빙 비용, 평가를 다룹니다. 앞쪽은 신경망의 기본 부품과 학습 절차, 과적합입니다. 가운데는 이미지를 다루는 합성곱 신경망과 비전 트랜스포머이고, 뒤쪽은 멀티모달, 이미지 생성(diffusion), 서빙과 병렬화, 평가입니다.
