용량은 모델이 만들 수 있는 함수의 다양함이고, 정칙화는 학습 오차에 벌점을 더해 모델이 실제로 쓰는 용량을 누르는 일입니다. 용량이 데이터에 비해 크면 모델은 학습 데이터를 외웁니다. 이것이 과적합입니다.

에이전트를 만들 때 이 문제는 자주 만납니다.

- **fine-tuning**: 데이터가 적은데 epochs를 늘리면 학습 loss만 내려가고 검증 loss는 오릅니다. 예시 문장을 외운 것입니다.
- **평가**: 같은 평가 세트를 보며 prompt를 계속 고치면 prompt가 그 평가 세트에 맞춰집니다. 같은 이유로 새 입력에서 성능이 떨어집니다. → [데이터 분리](../machine-learning/data-split.md)
- **설정 항목**: weight decay(가중치가 커지지 않게 누름), dropout(학습 중 일부 칸을 무작위로 끔), early stopping(검증 loss가 오르기 전에 멈춤)이 정칙화 방법입니다.

## 왜 필요한가

모델을 학습시키는 목적은 학습 데이터를 맞히는 것이 아니라 처음 보는 입력에서 맞히는 것입니다. 학습에 쓴 데이터에서 잰 오차가 학습 오차이고, 쓰지 않은 데이터에서 잰 오차가 시험 오차입니다. [역전파](./backpropagation.md)가 만든 기울기로 [경사하강법](./gradient-descent.md)을 돌리면 학습 오차는 내려갑니다. [기울기 소실](./gradient-vanishing.md)은 이 학습이 깊은 망에서도 되게 하는 문제였습니다. 그런데 학습 오차가 내려간다는 것만으로는 쓸 만한 모델이라는 보장이 없습니다.

가장 단순한 방법은 학습 오차가 가장 낮은 모델을 고르는 것입니다. 점 8개를 지나는 곡선을 찾는다고 합시다. 7차 다항식은 휘는 정도를 정하는 계수가 8개라서, 점의 가로 위치가 서로 다르면 8개를 모두 정확히 지나게 만들 수 있습니다. 학습 오차는 0입니다. 하지만 점에는 잡음이 섞여 있어서 이 곡선은 잡음까지 따라가고, 점과 점 사이에서 크게 출렁입니다. 맞힌 것이 아니라 외운 것이라서 새 점에서는 틀립니다. 반대로 모델을 직선처럼 단순하게 하면 학습 점조차 못 맞춥니다. 큰 모델은 학습 오차만 보면 언제나 이기므로, 학습 오차는 모델을 고르는 기준이 될 수 없습니다.

길은 둘입니다. 학습에 쓰지 않은 데이터로 따로 오차를 재서 고르는 것, 그리고 정칙화입니다. 정칙화는 모델을 크게 두되 가중치가 커지는 것에 벌점을 물려, 모델이 실제로 쓰는 용량을 누릅니다. 이 문서는 둘을 함께 다룹니다.

## 계산

점 8개에 다항식 곡선을 맞춥니다. 차수는 곡선이 얼마나 휠 수 있는지를 정하는 수이고, 차수가 곧 용량입니다. 아래 그림에서 차수를 올려 두 곡선이 어떻게 갈라지는지 보세요. 1차는 학습도 시험도 오차가 0.33 안팎인 과소적합(곡선이 너무 단순해 학습 점조차 못 맞추는 것)이고, 7차는 학습 오차가 0이지만 시험은 3차보다 나쁩니다.

<FitDegree />

정칙화는 오차에 항을 하나 더해서 용량을 누릅니다.

\[
E_{\mathrm{train}} + \lambda \sum w^2
\]

\(\lambda\)는 두 목표(학습 오차를 줄이기, 가중치를 작게 두기)의 비중입니다. 장난감 예로 보겠습니다. 학습 오차가 \((w - 3)^2\)이면 \(w = 3\)에서 오차가 0입니다. 벌점 \(\lambda w^2\)를 더한 전체의 기울기를 0으로 놓으면 \(2(w - 3) + 2\lambda w = 0\)이고, 정리하면 최솟값이 \(w = 3/(1 + \lambda)\)입니다.

```text
λ = 0     w = 3     (정칙화 없음)
λ = 0.5   w = 2
λ = 2     w = 1
```

\(\lambda\)가 클수록 가중치가 0 쪽으로 끌려갑니다. \(\lambda = 0.5\)에서 \(w = 3\)의 전체 값은 \(0 + 0.5 \times 9 = 4.5\)이고 \(w = 2\)는 \(1 + 0.5 \times 4 = 3\)이라서, 학습 오차가 1 늘어도 벌점이 더 크게 줄어 \(w = 2\)가 이깁니다. 학습 오차만 보면 \(\lambda = 0\)이 가장 낫습니다. 정칙화는 그 자리에서 일부러 벗어나는 것입니다.

### 학습 loss와 검증 loss로 읽기

실제 학습에서는 곡선을 그릴 수 없어서 loss 두 개를 나란히 봅니다. 검증 loss는 학습에 쓰지 않고 떼어 둔 데이터에서 잰 loss입니다.

```text
학습 loss   검증 loss   읽는 법
높음        높음        과소적합. 모델을 키우거나 더 오래 학습
낮음        높음        과적합. 데이터를 늘리거나 정칙화, 일찍 멈춤
낮음        낮음        간격이 작음. 정상
```

## 기억할 것 세 가지

### 학습 오차가 0이어도 좋은 모델은 아닙니다

외웠다는 뜻일 수 있습니다. 위 그림의 7차 모델은 학습 오차가 0인데 시험 오차가 3차보다 나쁩니다. 봐야 하는 것은 학습에 쓰지 않은 데이터에서의 오류입니다. 오류는 틀린 비율이고 오차는 학습이 줄이는 수여서, 둘은 다릅니다.

### 문제는 용량 자체가 아니라 용량 대비 데이터입니다

같은 모델도 데이터가 충분하면 외울 자리가 줄어듭니다. 데이터를 늘리면 학습과 시험의 간격이 줄고, 모델을 키우면 간격이 늡니다. MNIST에서 은닉 300칸 완전 연결 망은 파라미터가 \(785 \times 300 + 301 \times 10 = 238{,}510\)개로 학습 이미지 60,000장의 약 4배인데도 시험 오류가 크게 무너지지 않았습니다. 왜 그런지는 아직 정리된 이론이 아니고, 파라미터 수만으로 외웠는지는 알 수 없습니다. LLM도 데이터를 늘리면 간격이 준다는 방향은 같습니다.

### 정칙화는 학습 오차를 올리고, 검증으로 평가합니다

정칙화는 학습 오차를 조금 내주고 간격을 줄입니다. 정칙화를 넣었더니 학습 loss가 올랐다고 고장 난 것이 아닙니다. 다만 \(\lambda\)가 너무 크면 과소적합이 되므로, 값은 학습에 쓰지 않은 검증 데이터로 고릅니다. 시험 데이터로 고르면 그 데이터에 과적합한 값이 됩니다.

<summary>더 깊이: 일반화 간격과 가중치 감쇠</summary>

- 시험과 학습의 간격은 대략 \(k\,(h/P)^{\alpha}\)에 비례합니다. \(P\)는 학습 쌍의 수, \(h\)는 용량, \(\alpha\)는 0.5에서 1 사이, \(k\)는 상수입니다. 쌍이 두 배면 간격은 \(2^{-\alpha}\)배(0.707배에서 0.5배)가 되고, 용량이 두 배면 \(2^{\alpha}\)배(1.41배에서 2배)가 됩니다. 경향을 보이는 식이고 매끈한 거듭제곱으로 줄지는 않습니다.
- \(\lambda \sum w^2\)의 기울기는 \(2\lambda w\)라서 갱신이 \((1 - 2\epsilon\lambda)\,w - \epsilon\,\partial E_{\mathrm{train}}/\partial w\)가 됩니다. 매 갱신마다 가중치가 조금씩 줄어서 가중치 감쇠(weight decay)라고도 부릅니다.
- 한국어 자료는 정칙화를 정규화라고도 적습니다. 정규화는 입력 크기를 맞추는 normalization의 번역어이기도 해서 이 문서는 정칙화로 씁니다.
- 용량이 점점 큰 모델을 순서대로 두고 학습 오류와 간격을 같이 줄이는 것이 구조적 위험 최소화입니다. 실무에서는 오차에 벌점 항을 더하는 식으로 비슷하게 합니다.
- 구조를 넣어 자유 파라미터를 줄이는 방법도 있습니다. [가중치 공유](./weight-sharing.md)가 그 예입니다. [LeNet-5](./lenet-5.md)는 연결이 약 340,908개인데 자유 파라미터가 약 60,000개이고, 학습 오류 0.35%와 시험 오류 0.95%의 간격이 0.6%p입니다.
- 오차를 줄이는 절차는 [경사하강법](./gradient-descent.md), 오류를 재는 예제 데이터는 [MNIST](../machine-learning/mnist.md), 오차와 오류의 구분은 [판별 학습](../machine-learning/discriminative-learning.md)에 있습니다.

</details>
