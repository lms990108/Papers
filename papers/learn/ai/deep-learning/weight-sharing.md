가중치 공유는 서로 다른 위치(또는 시각)의 유닛이 같은 파라미터 하나를 쓰도록 묶는 제약입니다.

에이전트를 만들 때 이 말을 직접 쓰지는 않지만, 모델 구조를 읽을 때 자주 만납니다.

- **트랜스포머**: 모든 token 위치에 같은 투영 행렬과 같은 블록을 씁니다. 그래서 파라미터 수가 문장 길이와 상관없습니다.
- **입력·출력 임베딩 묶기**: 일부 작은 LLM은 두 행렬을 하나로 묶어 파라미터를 아낍니다. 모델 카드의 파라미터 수를 읽을 때 알아 둘 만합니다.
- **순환망**: 시각마다 다른 전이 행렬을 두지 않고 같은 전이를 시간 축에서 반복합니다.

## 왜 필요한가

이미지나 문장 같은 입력에는 같은 패턴이 여러 자리에 나옵니다. 숫자 "7"은 이미지의 왼쪽 위에 있든 오른쪽 아래에 있든 같은 모양입니다. 자리마다 따로 가중치를 두면 두 가지가 문제가 됩니다. 하나는 파라미터가 자리 수만큼 늘어난다는 것이고, 다른 하나는 한 자리에서 배운 것이 다른 자리에 전혀 쓰이지 않는다는 것입니다. 왼쪽 위에서 "7"을 천 번 봤어도 오른쪽 아래에서는 처음 보는 모양으로 대하니, 자리마다 충분한 예가 있어야 합니다.

가중치 공유는 여러 자리가 같은 가중치 하나를 쓰게 묶어서 둘을 한꺼번에 풉니다. 서로 다른 값의 개수가 자리 수와 상관없이 고정되고, 어느 자리에서 배우든 그 가중치를 쓰는 모든 자리가 함께 좋아집니다. 앞 문서의 [합성곱 신경망](./cnn.md)이 kernel 하나를 모든 자리에 옮겨 쓰는 것이 바로 이 공유입니다. 여기서는 그 공유가 개수와 학습에 어떻게 작용하는지 봅니다. 파라미터가 줄면 [용량](./capacity.md)이 줄어 과적합이 덜하다는 점에서 앞 문서의 주제와도 이어집니다.

## 세어 보기

먼저 두 가지 말을 정리합니다.

- **창**: 출력 칸 하나를 만들 때 입력에서 보는 이웃 칸의 범위입니다. 입력 7칸을 창 3칸으로 훑으면 창이 놓일 수 있는 자리가 \(7 - 3 + 1 = 5\)곳이라 출력이 5칸입니다.
- **바이어스(편향)**: 입력과 곱하지 않고 마지막에 그냥 더하는 값 하나입니다. 출력 칸마다 하나씩 붙고, 입력이 모두 0이어도 출력이 0이 아니게 해 주는 기준선 구실을 합니다. 식으로는 \(y = a x_1 + b x_2 + c x_3 + d\)에서 \(d\)가 바이어스(그림에서는 "편향")이고, 곱하는 값 \(a, b, c\)(가중치)와 함께 학습으로 정해집니다. 뜻은 [선형 회귀](../machine-learning/linear-regression.md)에 더 풀어 두었습니다.

그러면 출력 칸 하나를 만드는 데 필요한 학습 값은 창 3칸의 가중치 3개와 바이어스 1개, 모두 \(3 + 1 = 4\)개입니다. 이 4개를 출력 5칸에 어떻게 나눠 주느냐에 따라 세 가지 방식으로 나뉩니다.

| 방식 | 출력 칸이 보는 입력 | 서로 다른 학습 값 |
| --- | --- | --- |
| 완전 연결 | 입력 7칸 전부 | \((7 + 1) \times 5 = 40\)개 |
| 이웃 3칸만, 자리마다 따로 | 창 3칸 | \((3 + 1) \times 5 = 20\)개 |
| 이웃 3칸만, 같은 값을 공유 | 창 3칸 | \(3 + 1 = 4\)개 |

아래 그림에서 창을 한 칸씩 옮겨 가며 공유와 따로의 차이를 봅니다. 두 방식을 번갈아 눌러 보면, 아래쪽 "지금까지 쓴 서로 다른 학습 값" 칸이 공유에서는 4개로 머물고 따로에서는 자리마다 4개씩 늘어납니다.

<FilterSlide />

입력이 100칸이면 출력이 98칸이 됩니다. 이때 완전 연결은 \((100 + 1) \times 98 = 9{,}898\)개, 자리마다 따로는 \((3 + 1) \times 98 = 392\)개이고, 공유는 여전히 4개입니다. 공유는 학습할 값의 개수가 입력 길이와 상관없습니다.

## 계산

같은 검출기 \(w\)가 두 자리를 봅니다. 입력은 \(x = (2, 3)\), 출력은 \(y_k = w x_k\), 목표는 \(t = (3, 0)\)이고 \(w = 0.5\)에서 시작합니다. 오차는 \(L = \tfrac12 \sum_k (y_k - t_k)^2\)입니다.

```text
자리   입력   출력 y   오차 y-t   기울기 (y-t)·x
1      2      1.0      -2.0       -4.0
2      3      1.5      +1.5       +4.5
```

기울기 열은 \(L\)을 \(w\)로 미분한 값입니다. \(y_k = w x_k\)이므로 자리 \(k\)가 \(L\)에 주는 기울기는 \((y_k - t_k) \cdot x_k\)입니다.

자리 1은 출력이 목표보다 작으니 \(w\)를 키우라고, 자리 2는 목표보다 크니 줄이라고 합니다. \(w\) 하나가 두 자리의 출력에 모두 쓰이므로 \(w\)가 오차에 미치는 영향은 두 길의 합입니다. 값이 갈라지면 길마다 더한다는 [역전파](./backpropagation.md)의 규칙 그대로입니다. 공유된 \(w\)가 받는 기울기는 \(-4.0 + 4.5 = 0.5\)입니다. learning rate \(\epsilon = 0.1\)이면 \(w = 0.5 - 0.1 \times 0.5 = 0.45\)가 됩니다.

한 \(w\)로 두 자리를 모두 맞출 수는 없습니다. 자리 1을 맞추려면 \(w = 1.5\)여야 하는데 그러면 자리 2의 출력이 4.5가 됩니다. 그래서 두 요구의 타협점으로 갑니다. 이 예에서 \(L\)이 가장 작은 \(w\)는 \(6/13 \approx 0.46\)이라 0.45는 그 근처입니다. 자리마다 따로 갱신했다면 \(0.9\)와 \(0.05\)로 갈라져, 같은 검출기라는 전제가 깨집니다.

## 코드에서는

PyTorch에서는 같은 층 객체를 여러 번 호출하거나, `lm_head.weight = embed.weight`처럼 두 층이 같은 파라미터 객체를 가리키게 하면 공유가 됩니다. 후자가 입력·출력 임베딩 묶기입니다. 공유된 파라미터가 쓰인 자리마다의 기울기는 autograd가 `.grad`에 자동으로 더해 줍니다. 위 계산의 합산을 직접 코딩할 일은 없습니다.

## 기억할 것 세 가지

### 기울기는 합산합니다

그 파라미터를 쓰는 모든 연결의 기울기를 더해서 한 번에 갱신해야 값이 계속 같습니다. 평균을 쓰면 합을 연결 수로 나눈 것이라 갱신 폭이 그만큼 작아집니다. 맵이 28×28이면 784배 차이이므로, 어느 쪽을 쓰든 learning rate를 거기에 맞춰야 합니다.

### 줄어드는 것은 값의 개수이고 연결 수가 아닙니다

[합성곱 신경망](./cnn.md)의 첫 층(28×28 맵 6장)은 연결이 \(156 \times 784 = 122{,}304\)개인데 값은 156개입니다. 파라미터를 저장하고 학습하는 부담만 줄고, 계산량과 활성값 메모리는 그대로입니다. 위의 예처럼 위치마다 따로 갱신하면 훈련 오차는 더 빨리 내려갑니다. 공유가 이기는 곳은 훈련 오차가 아니라, 한 자리에서 배운 것이 다른 자리에서도 통하는 일반화입니다.

### 같은 초기값이 곧 공유는 아닙니다

같은 값으로 시작해도 연결마다 기울기가 다르면 따로 갱신되어 갈라집니다. 공유는 값이 같게 유지되는 제약이고, 연결들이 같은 변수 하나를 가리키는 것입니다. 입력의 자리마다 의미가 다른 문제에서는 공유가 맞지 않을 수 있고, 이웃만 보되 위치마다 가중치가 따로인 층을 국소 연결(locally connected) 층이라 부릅니다.

- 층마다 연결 수를 파라미터 수로 나눈 값은 C1이 784, S2가 490, C3가 100, S4가 62.5이고 C5와 F6은 1입니다. 맵이 클수록 공유 효과가 크고, 맵이 1×1이거나 완전 연결인 층에는 공유할 상대가 없습니다. 합계는 파라미터 60,000개, 연결 340,908개입니다([LeNet-5](./lenet-5.md)).
- 공유된 합성곱은 이동 동변입니다. 필터 \((1, 0, -1)\)을 입력에 쓰고, 입력을 두 칸 민 것에도 쓰면 출력 모양이 그대로 두 칸 밀려 나옵니다. 위치마다 가중치가 다른 층에서는 이런 일이 생기지 않습니다.
- 학습이 오차를 줄이는 방식은 [역전파](./backpropagation.md)와 [확률적 경사하강법](./sgd.md)에 있고, 파라미터 수가 줄면 [용량](./capacity.md)이 줄어듭니다. 정칙화가 가중치 크기를 줄이는 것과 달리, 공유는 자유도 자체를 줄입니다.
- 공유와 [서브샘플링](./subsampling.md)은 서로 독립입니다. 공유는 같은 가중치를 여러 위치에 다시 쓰는 것이고, 서브샘플링은 출력 칸 수를 줄이는 것입니다. 적용 대상은 [합성곱 신경망](./cnn.md)입니다.
