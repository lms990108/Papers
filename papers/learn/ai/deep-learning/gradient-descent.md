경사하강법은 오차의 기울기를 구해, 오차가 줄어드는 쪽으로 파라미터를 조금씩 옮기는 학습 절차입니다.

모델을 fine-tuning하거나 학습 코드를 돌릴 때 설정 화면에서 만납니다. learning rate, epochs, batch size가 이 절차의 설정값이고, loss가 내려가지 않거나 `NaN`이 뜨는 문제의 첫 용의자가 learning rate입니다. API로 호출만 하는 경우에는 직접 쓰지 않습니다.

## 계산

맞는 파라미터가 3이고 오차를 \(E(w) = (w - 3)^2\)으로 둡니다. 시작은 \(w = 0\), 한 번에 옮기는 비율인 학습률은 \(\epsilon = 0.1\)입니다. 기울기는 \(2(w - 3)\)이라 \(w = 0\)에서 \(-6\)입니다. 기울기가 음수이므로 \(w\)를 키워야 오차가 줄고, 그래서 기울기를 뺍니다.

\[
w \leftarrow w - \epsilon\, \frac{\partial E}{\partial w}
\]

```text
단계   w      기울기
0     0.000   -6.0
1     0.600   -4.8     0 - 0.1 × (-6)   = 0.6
2     1.080   -3.84    0.6 - 0.1 × (-4.8) = 1.08
3     1.464   -3.072
```

\(w\)가 3에 다가가지만 한 번에 도착하지는 않습니다. 기울기가 줄어서 걸음도 짧아집니다. 갱신 한 번은 \(w - 3\)에 \(1 - 2\epsilon = 0.8\)을 곱하는 일이기도 합니다.

## 기억할 것 세 가지

### 학습률이 크면 최솟값을 지나쳐 발산합니다

같은 곡선에서 학습률을 바꿔 다섯 걸음씩 달려 보면 다음과 같습니다.

| \(\epsilon\) | 5걸음 동안의 \(w\) |
| --- | --- |
| 0.01 | 0.06, 0.119, 0.176, 0.233, 0.288 |
| 0.1 | 0.6, 1.08, 1.464, 1.771, 2.017 |
| 0.5 | 3 (한 번에 도착) |
| 1.0 | 6, 0, 6, 0, 6 (왕복) |
| 1.1 | 6.6, -1.32, 8.184, -3.221, 10.465 (멀어짐) |

기울기 방향은 맞았고 틀린 것은 얼마나 갈지입니다. 아래 그림에서 걸음 수를 늘려 어느 선이 3에 닿고 어느 선이 튀는지 보세요. 실제 학습에서 loss가 오르거나 `NaN`이 되면 이 모양입니다.

### 작다고 항상 좋은 것은 아닙니다

\(\epsilon = 0.01\)은 안전하지만 다섯 걸음에 0.288밖에 못 갑니다. 한계 안에서는 큰 값이 빠릅니다. 데이터가 많은 학습에서는 느린 만큼 시간과 GPU 비용이 듭니다.

### 학습 오차의 최솟값이 새 입력에서의 최선은 아닙니다

경사하강법은 지금 자리에서 내리막을 따라갈 뿐이어서, 가장 낮은 곳을 찾아 주지도 않고 시작이 다르면 다른 골짜기에 도착합니다. 또 절차는 학습에 넣은 데이터만 봅니다. 넣지 않은 입력에서 얼마나 틀리는지는 [용량과 정칙화](./capacity.md)에서 따로 다룹니다.

<summary>더 깊이: 학습률의 한계와 국소 최솟값</summary>

- \(E = \tfrac{c}{2}(w - w^*)^2\) 꼴이면 갱신마다 거리에 \(1 - \epsilon c\)가 곱해집니다. \(0 < \epsilon < 2/c\)일 때 수렴하고, 이 \(2/c\)가 학습률의 한계입니다. 곡선이 가파를수록 한계가 작습니다. \((w - 3)^2\)은 \(c = 2\)라 한계가 1입니다.
- 기울기가 0인 점은 가장 낮은 곳이 아닐 수 있습니다. \(E(w) = w^4 - 3w^2 + w\)는 골짜기가 둘이라, 2.0에서 시작하면 오차 -1.070인 얕은 골짜기(\(w \approx 1.131\))에, -2.0에서 시작하면 -3.514인 깊은 골짜기(\(w \approx -1.301\))에 닿습니다. \(E = w_1^2 - w_2^2\)의 원점은 기울기가 0인 안장점입니다.
- 다층망에서 국소 최솟값이 실무에서 자주 문제가 되지 않는다는 관찰은 있지만, 이론은 아직 열려 있습니다.
- 파라미터가 \(W\)로 여럿이면 \(w\)마다 같은 식을 적용합니다. 층이 여럿일 때 기울기를 구하는 법은 [역전파](./backpropagation.md), 표본 하나나 미니배치로 고치는 법은 [확률적 경사하강법](./sgd.md)입니다. 오차의 종류는 [지도 학습](../machine-learning/supervised-learning.md)에 있습니다.

</details>
