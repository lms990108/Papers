멀티모달 모델은 이미지나 소리를 언어 모델이 읽을 수 있는 token 벡터로 바꿔 글 token 옆에 세웁니다. 언어 모델 블록은 벡터를 더하고 곱할 뿐이어서, 벡터가 단어에서 왔는지 픽셀에서 왔는지 구분하지 않습니다.

에이전트를 만들 때는 이런 곳에서 만납니다.

- **이미지 입력을 받는 LLM API**: 이미지 한 장이 몇 개의 token이 되는지가 비용과 지연을 정합니다.
- **스크린샷 기반 에이전트와 문서 읽기**: 화면과 PDF 페이지를 이미지로 넣습니다. 작은 글자를 읽으려면 해상도를 유지해야 합니다.
- **파이프라인 선택**: 이미지를 OCR이나 캡션으로 먼저 글로 바꿔 넘길지, 이미지를 그대로 넣을지 고릅니다.

## 계산

글 token이 길이 2인 \([1, 0]\)이라고 합시다. 이미지는 2×2 밝기 네 칸 \([1, 0, 1, 0]\)입니다. 더하려면 같은 길이여야 하므로, 네 칸을 길이 2로 줄이는 행렬이 필요합니다. 이 행렬이 projector입니다. 줄마다 픽셀과 곱해 더합니다(가중치는 계산이 보이게 고른 수입니다).

```text
줄   가중치             밝기와의 곱         합
1    [0.5, 0, 0, 0]     0.5 × 1, 나머지 0   0.5
2    [0, 0, 0.5, 0]     0.5 × 1, 나머지 0   0.5
```

이미지 token은 \([0.5, 0.5]\)이고, 글 token 옆에서 같은 prefill을 탑니다. 픽셀을 token으로 만드는 앞 망이 vision encoder입니다. 이 표는 그 앞 망과 projector를 합쳐 행렬 하나로 줄인 모양입니다. → [비전 트랜스포머](./vision-transformer.md)

큰 이미지는 한 번에 줄이면 위치가 사라집니다. 4×4 이미지의 사분면 평균 밝기가 1, 0, 0, 0이라고 합시다(왼쪽 위만 밝습니다). 통째로 평균내면 \(1/4 = 0.25\) 한 수가 되어 어느 사분면이 밝았는지 알 수 없습니다. 아래 그림에서 한 칸으로 줄일 때와 조각을 유지할 때의 token 수를 비교해 보세요.

2×2 조각 4개를 각각 projector에 통과시키면 token 4개가 prefill에 서고, 첫째 조각만 밝습니다. 이렇게 이미지 크기에 맞춰 조각 수를 늘리는 방식이 AnyRes입니다.

## 기억할 것 세 가지

### 이미지 token 수가 비용입니다

token이 1개에서 4개로 늘면 prefill 연산도 그만큼 커집니다. 해상도를 높이거나 조각을 늘리면 품질은 오르고 비용도 오릅니다. 이미지 token은 픽셀 한 칸이 아니라 여러 칸을 곱해 만든 벡터 하나입니다.

### 줄이면 내용이 사라질 수 있습니다

한 칸으로 평균내면 위치가 사라지고, 해상도를 낮추면 작은 글자가 지워집니다. 읽혀야 하는 세부가 있는 이미지는 조각을 유지해야 합니다.

### 글로 바꿔 넘기면 글이 담은 만큼만 남습니다

이미지 전용 모델이 "왼쪽이 밝다"라는 문장을 만들고 언어 모델은 그 문장만 읽는 연결(late fusion)에서는 픽셀의 위치가 문장이 담은 만큼만 남습니다. 소리도 같아서, 말을 먼저 글자로 바꾸면 억양과 길이는 글자가 담은 만큼만 남습니다. 반대로 여러 modality를 처음부터 같은 residual 위에서 함께 학습하는 모델을 native multimodal이라 합니다.

<summary>더 깊이: 대조 학습과 CLIP</summary>

- 이미지 벡터와 문장 벡터의 길이가 같으면 [코사인 유사도](../nlp/cosine-similarity.md)를 셀 수 있습니다. 이미지 \([1, 0]\), 맞는 문장 \([1, 0]\)의 코사인은 1이고, 다른 문장 \([0, 1]\)과는 0입니다. 학습은 맞는 쌍의 코사인을 키우고 다른 쌍을 줄입니다. 이 짝 맞추기가 대조 학습(contrastive learning)이고, CLIP과 SigLIP이 이 목적으로 이미지 인코더와 문장 인코더를 함께 학습합니다. 이런 이미지 벡터를 언어 모델의 입력으로 쓰면 VLM(vision-language model)이 됩니다.
- 이미지 token 수 계산, 학습 단계, 문서·GUI 활용과 실패 패턴은 [VLM](./vlm.md)에서 다룹니다.
- 대조 학습이 줄이는 것은 맞는 쌍과 다른 쌍의 코사인 차이이고, 언어 모델의 다음 token 오차와 다릅니다.
- 소리는 파형을 짧은 조각으로 잘라 각각 벡터로 만들어 글 token 옆에 세웁니다.
- token이 늘면 [Prefill, decode](../nlp/prefill-decode.md)의 연산도 token 수에 비례해 늡니다. 글을 읽는 residual의 구조는 [Decoder block](../nlp/block.md)에 있습니다.
- [Diffusion, flow](./generation.md)의 latent도 같은 발상으로 픽셀 벡터를 줄입니다.
