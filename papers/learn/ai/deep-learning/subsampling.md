서브샘플링은 이웃한 몇 칸을 수 하나로 요약해서 좌표의 정밀도를 버리고 해상도를 낮추는 층입니다. 지금은 pooling이라 부릅니다. 에이전트 개발에서 직접 쓸 일은 없는 배경 지식입니다. 다만 일부 멀티모달 모델이 이미지 token 수를 줄이려고 이웃 패치를 합치는 것과 같은 발상이라, 이미지 입력의 비용을 이해할 때 도움이 됩니다.

## 계산

4×4 칸을 겹치지 않는 2×2 네 덩어리로 나누고, 덩어리마다 수 하나를 냅니다. 아래 그림에서 칸의 값과 평균, 최대를 바꿔 가며 덩어리 안의 위치가 출력에서 사라지는지 보세요.

<PoolGrid />

그림의 기본값에서 덩어리별 평균과 최대는 이렇습니다.

```text
평균  0.475   0.0625      최대  1.00   0.25
      0.425   0.1625            1.00   0.45
```

가로세로가 절반, 칸 수는 4분의 1입니다. 입력 한 변 \(N\), 창 \(K\), 보폭 \(S\)이면 출력 한 변은 [합성곱](./cnn.md)과 같은 식입니다. \(N = 7\)이면 마지막 줄이 버려져 3이 됩니다.

\[
\left\lfloor \frac{N - K}{S} \right\rfloor + 1
\]

## 기억할 것 세 가지

### 완전한 이동 불변을 주지는 않습니다

덩어리 안에서 움직인 것만 가려 줍니다. 획이 0번 칸에서 1번 칸으로 가면 첫 덩어리의 평균이 같지만, 2번 칸으로 가면 둘째 덩어리로 넘어가 출력이 바뀝니다.

### 평균과 최대는 다른 것을 말합니다

왼쪽 위 덩어리는 평균 0.475, 최대 1.00입니다. 평균은 덩어리가 전체적으로 얼마나 짙은지, 최대는 센 반응이 하나라도 있는지를 알려 줍니다. 검출기는 특징이 "있는지"만 알면 되는 경우가 많아서 최대(max pooling)를 많이 씁니다.

### 줄이는 것은 파라미터가 아니라 칸 수입니다

LeNet-5의 S2와 S4가 가진 파라미터는 \(12 + 32 = 44\)개로, 전체 60,000개에 비하면 거의 없습니다. 칸 수가 줄어서 뒤 층의 연결과 계산이 줄어듭니다. 요즘 max pooling과 average pooling에는 파라미터가 없습니다. 같은 역할을 stride가 있는 합성곱이나 패치 임베딩이 하기도 합니다.

<summary>더 깊이: LeNet-5의 서브샘플링 유닛</summary>

- 초기 합성곱망은 덩어리의 합 \(s\)에 학습되는 계수 \(c\)를 곱하고 바이어스 \(b\)를 더해 비선형 \(f\)를 통과시켰습니다. 출력은 \(f(cs + b)\)입니다. 계수가 작으면 평균에 가까운 흐림이고, 계수가 크고 바이어스가 음수이면 덩어리 안에 특징이 있는지를 가르는 문턱이 됩니다.
- \(f = \tanh\)에서 \(c = 3, b = -2\)이면 합이 \(2/3\)보다 클 때 양수입니다. 위 덩어리의 합 1.90은 0.9988, 0.25는 −0.8483입니다.
- LeNet-5의 S2는 28×28 맵 6장을 14×14로 줄여 유닛 1,176개, 파라미터 12개(맵마다 계수와 바이어스), 연결 5,880개입니다. 연결은 유닛마다 입력 4개와 바이어스 1개로 5개입니다. S4는 유닛 400개, 파라미터 32개, 연결 2,000개입니다. 층별 표는 [LeNet-5](./lenet-5.md)에 있습니다.
- 언어 모델의 token은 픽셀보다 이미 거친 단위여서, 이 층이 하던 일을 문장을 token으로 나누는 단계가 미리 해 둔 셈입니다.
- 이 페이지는 [합성곱 신경망](./cnn.md)과 [가중치 공유](./weight-sharing.md)를 먼저 보면 읽기 쉽습니다.
