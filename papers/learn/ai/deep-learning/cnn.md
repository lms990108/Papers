합성곱 신경망은 작은 가중치 묶음(kernel) 하나를 이미지 위에서 한 칸씩 옮기며, 같은 가중치로 곱하고 더하는 망입니다.

에이전트를 만들 때 CNN을 직접 짤 일은 많지 않습니다. 이미지를 다루는 곳에서 이름을 만납니다.

- **스크린샷과 문서 이미지 읽기**: 멀티모달 LLM이나 컴퓨터 사용 에이전트가 화면을 볼 때, 이미지 인코더가 이미지를 token으로 바꿉니다. 요즘은 ViT가 많지만 합성곱을 쓰는 인코더도 있습니다. → [비전 트랜스포머](./vision-transformer.md)
- **OCR, 검출, 분류 모델**: 에이전트가 도구로 부르는 가벼운 이미지 모델에 지금도 많이 쓰입니다.
- **이미지 모델 논문과 코드**: kernel, stride, padding, feature map이 그대로 나옵니다.

## 왜 필요한가

이미지는 수가 많고 구조가 있는 입력입니다. 32×32 흑백 이미지는 수 1,024개이고, 이웃한 칸끼리 관련이 있습니다. [신경망](./neural-network.md)의 기본 층은 완전 연결이라서, 이미지를 한 줄로 펴서 넣고 출력 칸마다 입력 칸 전부와 선을 잇습니다. 은닉 1,000칸만 두어도 \((1{,}024 + 1) \times 1{,}000 = 1{,}025{,}000\)개의 가중치입니다. 입력이 커지면 이 수는 입력 크기에 비례해 늘어납니다. [용량과 정칙화](./capacity.md)에서 본 대로 파라미터가 많으면 외우기도 쉬워집니다.

문제는 개수만이 아닙니다. 펴는 순간 어느 칸이 이웃인지가 사라집니다. 입력이 7칸이고 획이 칸 1에 있다가 오른쪽으로 두 칸 밀려 칸 3으로 가면, 완전 연결층에서 칸 1에 곱하는 가중치와 칸 3에 곱하는 가중치는 서로 다른 값입니다. "획이 있다"는 판단을 위치마다 따로 배워야 하고, 학습 데이터에 그 위치의 글자가 없으면 배울 수 없습니다.

합성곱은 이 두 가지를 구조로 풉니다. 작은 가중치 묶음 하나를 이미지의 모든 자리에 같이 씁니다. 파라미터는 묶음의 크기로만 정해지고, 창 안의 이웃만 보며, 같은 모양이 다른 자리로 가도 같은 검출기가 반응합니다. 한 자리에서 배운 것이 모든 자리에 통하는 셈입니다.

## 계산

kernel은 가중치 묶음이고, 창은 kernel이 한 번에 덮는 구간입니다. 한 자리의 출력은 창 안의 입력과 kernel 가중치를 짝지어 곱한 뒤 더한 값입니다. 가중치 값은 사람이 적지 않고 [역전파](./backpropagation.md)로 배웁니다.

가중치 \(a, b, c = 1, 0, -1\)이 입력 \(x = (1, 2, 0, 1, 3, 1, 0)\) 위를 한 칸씩 옮겨 갑니다. 첫 창 \((1, 2, 0)\)이면 \(1 \times 1 + 2 \times 0 + 0 \times (-1) = 1\)입니다. 아래 표는 같은 계산을 창마다 적은 것입니다.

```text
창 안의 입력   계산            출력
1, 2, 0        1 + 0 - 0       1
2, 0, 1        2 + 0 - 1       1
0, 1, 3        0 + 0 - 3      -3
1, 3, 1        1 + 0 - 1       0
3, 1, 0        3 + 0 - 0       3
```

창마다 나온 출력의 모음을 feature map이라 부릅니다. 입력 7칸이 출력 5칸이 되는 것은 창이 놓일 수 있는 자리가 다섯 곳이기 때문입니다. 이 가중치에서 출력은 창의 왼쪽 값에서 오른쪽 값을 뺀 것입니다. 그래서 값이 오른쪽으로 갈수록 줄어드는 곳에서 큰 값이 나오고, 늘어나는 곳에서 음수가 나옵니다. 이 가중치는 변화를 찾는 검출기입니다.

kernel은 한 장이 아니라 여러 장을 씁니다. 장마다 다른 모양(예를 들어 가로 모서리, 세로 모서리)에 반응하도록 따로 배우고, 장 수만큼 feature map이 나옵니다. 아래에서 말하는 "kernel 6장"은 이 뜻입니다.

2차원도 같습니다. 창이 3×3이면 곱을 9개 더합니다. 아래 그림에서 3×3 창을 한 자리씩 옮기며, 같은 kernel이 곱해져 출력 칸이 하나씩 채워지는 모습을 보세요.

출력 한 변의 크기는 입력 \(N\), kernel \(K\), stride \(S\), padding \(P\)로 정해집니다. stride는 창을 옮기는 칸 수이고, padding은 가장자리에 두르는 0의 겹 수입니다.

\[
O = \left\lfloor \frac{N + 2P - K}{S} \right\rfloor + 1
\]

\(N + 2P - K\)는 창이 첫 자리에서 마지막 자리까지 갈 수 있는 거리이고, \(S\)로 나누면 옮길 수 있는 횟수, 첫 자리를 세려고 1을 더합니다. 위 1차원 예는 \(N = 7, K = 3, S = 1, P = 0\)이라 \(4 + 1 = 5\)입니다.

## 코드에서는

PyTorch에서는 `nn.Conv2d(in_channels=1, out_channels=6, kernel_size=5)`가 위의 첫 층(흑백 입력, 5×5 kernel 6장)입니다. 가중치 모양은 `(6, 1, 5, 5)`이고 바이어스가 6개라서 파라미터는 \(6 \times 25 + 6 = 156\)개입니다. `stride`와 `padding` 인자가 위 식의 \(S\), \(P\)입니다. 모델 코드나 논문에서 이 인자들이 보이면 출력 크기를 위 식으로 계산하면 됩니다.

## 기억할 것 세 가지

### 파라미터는 입력 크기와 상관없습니다

32×32 흑백 이미지에 5×5 kernel 6장을 쓰면 파라미터는 \((25 + 1) \times 6 = 156\)개입니다. 같은 크기의 출력(28×28 맵 6장, 출력 칸 곧 유닛 4,704개)을 완전 연결로 만들면 \((1{,}024 + 1) \times 4{,}704 = 4{,}821{,}600\)개입니다. 입력이 320×320이 되어도 합성곱은 156개 그대로입니다. 늘어나는 것은 계산량입니다.

### 이동 불변이 아니라 이동 동변입니다

입력이 오른쪽으로 한 칸 가면 feature map도 한 칸 갑니다(동변). 맵이 그대로인 것(불변)이 아닙니다. 위치와 상관없이 같은 답을 내는 성질은 [서브샘플링](./subsampling.md)이나 마지막 분류층이 더해 줍니다. 한 맵 안에서 같은 가중치를 쓰는 이유는 [가중치 공유](./weight-sharing.md)에 있습니다.

### 출력 크기는 내림으로 정해집니다

\(N = 32, K = 5, S = 1, P = 0\)이면 \(O = 28\)이고, \(P = 2\)로 두르면 \(O = 32\)로 크기가 유지됩니다. \(K = 3, S = 2, P = 0\)에서 \(N = 7\)이면 3이고, \(N = 8\)이어도 3입니다. 마지막 한 칸은 창에 들어가지 못해 버려집니다. padding으로 넣은 0은 크기를 맞추려는 것이고 새 정보를 주지 않습니다.

<summary>더 깊이: 채널, 쌓는 구조, 구현 세부</summary>

- 입력 채널 \(C_{in}\), 출력 맵 \(C_{out}\)장, kernel \(K \times K\)이면 파라미터는 \((K^2 C_{in} + 1) C_{out}\)입니다. RGB에 3×3 kernel로 64장이면 \((27 + 1) \times 64 = 1{,}792\)개입니다. 바이어스 1은 입력과 상관없이 더하는 상수입니다.
- 합성곱과 서브샘플링을 번갈아 쌓으면 깊어질수록 한 유닛이 보는 원본 범위가 넓어지고 좌표는 거칠어집니다. 앞층은 획과 모서리를, 뒷층은 그 조합을 봅니다. 층별 크기는 [LeNet-5](./lenet-5.md)에 있습니다.
- 딥러닝 구현은 kernel을 뒤집지 않고 그대로 겹쳐 곱합니다. 엄밀히는 cross-correlation입니다. kernel은 학습되는 값이라 뒤집었는지는 결과에서 구분되지 않습니다.
- 합성곱 대신 어텐션으로 이미지를 읽는 방식이 [비전 트랜스포머](./vision-transformer.md)입니다. 입력의 규칙(가까운 것이 관련 있다, 같은 검출기를 여러 자리에 쓴다)을 구조에 넣을지, 데이터로 배우게 둘지가 다릅니다.
- 시간 축으로만 가중치를 공유하는 합성곱망은 TDNN(time-delay neural network)이라 불렸고 음소 인식에 쓰였습니다.
- [신경망](./neural-network.md)과 [층](./layer.md)을 먼저 보면 읽기 쉽습니다.
