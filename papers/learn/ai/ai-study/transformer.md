문장을 넣는 언어 모델의 가운데는 같은 모양의 블록을 쌓은 것이다. 그 블록이 트랜스포머의 한 층이다. transformer와 같은 말이다. [신경망의 구조](./structure.md)에서 블록이라고 부른 상자가 여기 그림이다. 모양은 블록마다 같고, 빈칸은 블록마다 따로다. 한 블록 안에서는 토큰 자리가 달라도 질문, 열쇠, 값, 그리고 뒤의 층이 같은 가중치를 쓴다.

:::tip[한눈에 보기]
트랜스포머는 [어텐션](./attention.md)과 토큰마다 따로 계산하는 [층](./layer.md)을 잔차 연결과 층 정규화로 감싼 블록을 여러 개 쌓은 구조다.

- 한 블록은 (여러 헤드의) 어텐션, 더하기와 정규화, 칸마다의 층, 더하기와 정규화로 이루어진다.
- 어텐션에는 순서 정보가 없어서, 입력에 자리 목록(위치 인코딩)을 더해 순서를 넣는다.
- 다음 토큰을 맞히는 용도에서는 어텐션에 마스크를 걸어 뒤 토큰을 가린다.

먼저 읽을 것: [어텐션](./attention.md), [임베딩](./embedding.md), [기울기 소실](./gradient-vanishing.md). 이어지는 것: [다음 토큰](./next-token.md), [버트](./bert.md).
:::

## 왜 이런 구조인가

[순환 신경망](./rnn.md)과 [장단기 메모리](./lstm.md)는 자리를 한 칸씩 밟아야 해서 병렬 계산이 어렵고, 먼 토큰은 여러 번 가공된 뒤에야 닿는다. 2017년의 논문 "Attention Is All You Need"는 순환 없이 어텐션과 칸마다의 층만 쌓은 구조를 제안했다. 모든 자리를 한 번에 계산하고, 어느 자리든 다른 모든 자리를 한 번의 곱으로 본다. 대신 어텐션은 순서를 모르므로 자리를 따로 넣어야 하고, 층을 깊이 쌓아도 학습이 되도록 잔차와 정규화가 필요하다.

## 블록 하나

블록은 두 번 더한다. 한 번은 [어텐션](./attention.md)의 출력을 원래 목록에 더하고, 한 번은 토큰마다 따로 계산한 [층](./layer.md)의 출력을 그 결과에 더한다. 더하는 길을 잔차 연결이라고 한다. residual connection과 같은 말이다. 블록이 목록 전체를 다시 쓰지 않아도, 이전 목록이 다음 블록으로 지나간다. 블록이 배우는 것은 새 목록이 아니라 원래 목록에 더할 변화량이다. [기울기 소실](./gradient-vanishing.md)에서 본 대로 더해진 길은 기울기 1이 그대로 앞으로 가서, 층을 깊게 쌓아도 앞 층이 움직인다.

## 한 토큰의 수

어텐션 페이지의 오늘을 이어서 계산한다. 그 페이지에서 마스크를 걸지 않고 구한 오늘의 출력은 \([0.670,\ 0.330]\)이고 입력은 \([1,\ 0]\)이다. 더하면 \([1.670,\ 0.330]\)이다. 다음 토큰을 맞히는 용도에서는 오늘 자리가 날씨를 보지 않으므로 어텐션 출력이 \([1,\ 0]\)이 되고, 더한 목록은 \([2,\ 0]\)이다. 이 경우도 평균 1, 표준편차 1이라 아래 정규화 결과는 같은 \([1,\ -1]\)이다. 이 페이지는 마스크를 걸지 않은 쪽으로 계속한다.

더한 목록의 평균은 1이다. 평균을 빼면 \([0.670,\ -0.670]\)이고, 이 편차의 표준편차도 0.670이라 나누면 \([1,\ -1]\)이다. 이 맞춤을 층 정규화라고 한다. layer normalization과 같은 말이다. 목록마다 평균과 퍼짐을 맞춘 뒤, 칸마다 배율 \(\gamma\)를 곱하고 이동 \(\beta\)를 더한다. 둘 다 파라미터다. 이 예는 \(\gamma = 1\), \(\beta = 0\)이라 결과가 \([1,\ -1]\) 그대로다. 나눗셈이 0이 되지 않게 표준편차 제곱에 아주 작은 수를 더하는데, 이 예는 그 수를 0으로 둔다.

\[
\hat{z} = \frac{z - \mu}{\sqrt{\sigma^2 + \epsilon}}, \quad \mathrm{LN}(z) = \gamma \hat{z} + \beta
\]

그다음은 토큰마다 따로 두는 층이다. 자리는 가중치를 공유한다. 수로는 이렇게 쓴다. 구부러지는 함수로 이 예는 ReLU를 쓴다. 0보다 작으면 0으로 둔다.

\[
u = \mathrm{ReLU}(z W_1 + b_1), \quad y = u W_2 + b_2
\]

\(z = [1,\ -1]\)이고, 첫째 곱이 \([0,\ 3]\), 바이어스는 0, \(W_2\)는 단위행렬이라고 두자. ReLU는 0 이상을 그대로 두므로 층의 출력은 \([0,\ 3]\)이다. 쓰는 블록은 가운데 칸 수를 입력의 네 배 정도로 늘렸다가 줄인다. 이 예는 칸 수를 2로 유지해 더하기가 보이게 했다. ReLU 자리에 더 매끈한 함수를 넣는 망도 있다. 음수 쪽을 그대로 통과시키지 않는 역할은 같다.

잔차로 더하면 \([1,\ -1] + [0,\ 3] = [1,\ 2]\)다. 평균 1.5를 빼고 표준편차 0.5로 나누면 \([-1,\ 1]\)이다. 어텐션 직후의 \([1,\ -1]\)과 방향이 뒤집힌 목록이 다음 블록으로 간다.

```python
import math

def layer_norm(z, gamma=1.0, beta=0.0):
    mu = sum(z) / len(z)
    var = sum((v - mu) ** 2 for v in z) / len(z)
    return [gamma * (v - mu) / math.sqrt(var) + beta for v in z]

x = [1, 0]                                   # 오늘 (가리지 않은 어텐션)
attn = [0.67, 0.33]
z = [a + b for a, b in zip(x, attn)]         # 잔차: 어텐션 출력 + 원래 목록
n1 = layer_norm(z)
print("더한 목록", [round(v, 3) for v in z], "-> 층 정규화", [round(v, 3) for v in n1])

ffn = [max(0, v) for v in [0, 3]]            # 칸마다의 층: 첫째 곱이 [0, 3], ReLU, W_2 = I
z2 = [a + b for a, b in zip(n1, ffn)]        # 잔차
n2 = layer_norm(z2)
print("더한 목록", [round(v, 3) for v in z2], "-> 층 정규화", [round(v, 3) for v in n2])
```

```text
더한 목록 [1.67, 0.33] -> 층 정규화 [1.0, -1.0]
더한 목록 [1.0, 2.0] -> 층 정규화 [-1.0, 1.0]
```

2017년의 블록은 이렇게 더한 뒤에 정규화했다. 지금 문장을 잇는 모델은 보통 어텐션 전에 한 번, 칸마다의 층 전에 한 번, 정규화를 먼저 한다. 순서는 구조의 선택이다. 정규화 식이 평균을 빼고 표준편차로 나누는 일은 같다.

## 멀티헤드

[어텐션](./attention.md)의 한 벌이 헤드다. 블록은 이를 여러 벌 두고, 헤드마다 질문, 열쇠, 값의 가중치를 따로 학습한다. 헤드의 출력을 이어 붙인 뒤 \(W_O\)를 곱해 입력과 같은 길이로 맞춘다.

\[
\mathrm{MultiHead} = [\,\mathrm{head}_1,\ \dots,\ \mathrm{head}_h\,]\, W_O
\]

헤드 하나의 길이는 보통 입력 길이를 \(h\)로 나눈 값이다. 2017년의 논문은 입력 길이 512, 헤드 8개, 헤드마다 64였다. 그러면 헤드를 늘려도 계산 총량은 크게 달라지지 않는다.

앞의 셋짜리 예(오늘 \([1,\ 0]\), 날씨 \([0,\ 1]\), 좋다 \([1,\ 1]\))로 좋다 자리를 계산한다. 헤드를 둘, 헤드 하나의 길이를 1로 두자. 헤드 1은 입력의 첫 칸만 질문, 열쇠, 값으로 쓰고, 헤드 2는 둘째 칸을 질문과 열쇠로 쓰되 값은 2배로 쓴다. 길이가 1이라 \(\sqrt{d} = 1\)이다.

헤드 1에서 좋다의 질문은 1이고 열쇠는 오늘 1, 날씨 0, 좋다 1이므로 점수가 \([1,\ 0,\ 1]\), 비율이 약 \([0.422,\ 0.155,\ 0.422]\)이다. 값이 \([1,\ 0,\ 1]\)이라 출력은 \(0.422 + 0.422 = 0.845\)다. 헤드 2는 점수가 \([0,\ 1,\ 1]\), 비율이 \([0.155,\ 0.422,\ 0.422]\)이고 값이 \([0,\ 2,\ 2]\)라 출력은 \(0.844 + 0.844 = 1.689\)다. 이어 붙이면 \([0.845,\ 1.689]\)이고, \(W_O = \begin{bmatrix} 1 & 0 \\ 1 & 1 \end{bmatrix}\)을 곱하면 \([0.845 + 1.689,\ 1.689] = [2.534,\ 1.689]\)이다.

```python
import math

def softmax(s):
    e = [math.exp(v) for v in s]
    return [v / sum(e) for v in e]

X = [[1, 0], [0, 1], [1, 1]]                 # 오늘, 날씨, 좋다
# 헤드 2개, 헤드 하나의 길이 d_k = 1. 헤드마다 (W_Q, W_K, W_V) 는 길이 2 의 열
heads = [([1, 0], [1, 0], [1, 0]),           # 헤드 1: 첫 칸을 본다
         ([0, 1], [0, 1], [0, 2])]           # 헤드 2: 둘째 칸을 보고 값은 2배
WO = [[1, 0], [1, 1]]                        # 이어 붙인 길이 2 -> 2

def head_out(i, WQ, WK, WV):
    dot = lambda x, w: sum(a * b for a, b in zip(x, w))
    q = dot(X[i], WQ)
    s = [q * dot(x, WK) / math.sqrt(1) for x in X]
    a = softmax(s)
    return sum(a[j] * dot(X[j], WV) for j in range(3)), [round(v, 3) for v in a]

i = 2                                        # 좋다 자리
outs = []
for n, (WQ, WK, WV) in enumerate(heads, 1):
    y, a = head_out(i, WQ, WK, WV)
    print("헤드", n, "비율", a, "출력", round(y, 3))
    outs.append(y)
y = [sum(outs[r] * WO[r][c] for r in range(2)) for c in range(2)]
print("이어 붙임", [round(v, 3) for v in outs], "-> W_O 뒤", [round(v, 3) for v in y])
```

```text
헤드 1 비율 [0.422, 0.155, 0.422] 출력 0.845
헤드 2 비율 [0.155, 0.422, 0.422] 출력 1.689
이어 붙임 [0.845, 1.689] -> W_O 뒤 [2.534, 1.689]
```

두 헤드가 같은 토큰 셋을 보고도 서로 다른 비율을 낸다. 헤드 1은 오늘과 좋다를, 헤드 2는 날씨와 좋다를 더 본다.

## 위치 인코딩

어텐션은 토큰의 순서를 모른다. "날씨 오늘"로 입력해도 각 토큰이 내는 출력은 같고 순서만 따라 바뀔 뿐이다. 그래서 [임베딩](./embedding.md)에서 본 대로 자리마다 목록을 토큰 목록에 더한다. 자리 목록을 파라미터로 학습할 수도 있고, 2017년의 논문처럼 자리 번호로 정한 식을 쓸 수도 있다.

\[
\mathrm{PE}(pos,\ 2i) = \sin\!\left(\frac{pos}{10000^{2i/d}}\right), \quad
\mathrm{PE}(pos,\ 2i+1) = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)
\]

\(pos\)는 자리 번호이고 \(d\)는 목록의 길이다. 칸 두 개가 한 쌍으로 사인과 코사인을 이루고, 쌍마다 각도가 변하는 속도(주기)가 다르다. 앞쪽 쌍은 자리가 하나 바뀔 때마다 빨리 변하고, 뒤쪽 쌍은 천천히 변한다. \(d = 4\)로 계산하면 이렇다.

```python
import math

d = 4                                        # 위치 목록의 길이 (예시용)
for pos in range(3):
    pe = []
    for i in range(d // 2):
        angle = pos / 10000 ** (2 * i / d)   # 칸 쌍마다 주기가 다르다
        pe += [math.sin(angle), math.cos(angle)]
    print("pos", pos, [round(v, 4) for v in pe])
```

```text
pos 0 [0.0, 1.0, 0.0, 1.0]
pos 1 [0.8415, 0.5403, 0.01, 1.0]
pos 2 [0.9093, -0.4161, 0.02, 0.9998]
```

첫 쌍은 자리마다 크게 달라지고, 둘째 쌍은 0, 0.01, 0.02로 천천히 변한다. 사인과 코사인의 덧셈 정리 때문에, 자리가 \(k\)칸 떨어진 목록은 원래 목록의 일차식으로 쓸 수 있다. 이것이 상대적인 거리를 배우기 쉽게 한다는 것이 논문의 설명이다.

## 앞만 보는 쌓기

다음 토큰을 맞힐 때 블록 안의 어텐션은 뒤 토큰을 가린다. 마스크를 걸어 두면 한 문장을 한 번 계산해 모든 자리의 다음 토큰 손실을 동시에 구할 수 있다. 자리마다 따로 문장을 잘라 계산하지 않아도, 각 자리가 앞만 본다는 조건이 이미 걸려 있어서다. 2017년 논문의 그림에는 문장 전체를 보는 블록 더미와, 앞만 보는 블록 더미가 둘 다 있다. 문장을 이어 쓰는 모델은 앞만 보는 더미만 쌓는다. 마지막 토큰의 목록으로 다음 토큰의 점수를 만드는 손실은 [다음 토큰](./next-token.md)에 있다. 문장 전체를 보는 더미만 쌓아 가린 칸을 맞히게 한 모델이 [버트](./bert.md)다.

## 파라미터는 어디에 있나

입력 길이가 \(d\)이고 가운데 칸 수가 \(4d\)이면, 블록 하나의 파라미터는 어텐션의 \(W_Q\), \(W_K\), \(W_V\), \(W_O\)가 \(4d^2\), 칸마다의 층의 \(W_1\), \(W_2\)가 \(2 \times d \times 4d = 8d^2\)이다. 바이어스와 정규화의 \(\gamma\), \(\beta\)는 작아서 뺐다. 합이 \(12d^2\)이다. \(d = 512\)이면 \(12 \times 512^2 = 3{,}145{,}728\)이고, 이 중 어텐션이 1,048,576, 칸마다의 층이 2,097,152이다. 칸마다의 층이 블록 파라미터의 \(2/3\)를 차지한다. 문장 길이는 이 수에 들어가지 않는다.

## 자주 헷갈리는 점

잔차 연결이 입력을 그대로 복사하는 일이라 배울 것이 없다고 생각하기 쉽지만, 복사는 길이 하나일 뿐이다. 어텐션과 칸마다의 층이 만든 변화량이 거기에 더해진다. 위 예에서 \([1,\ -1]\)에 \([0,\ 3]\)이 더해져 \([1,\ 2]\)가 되었다.

층 정규화가 배치 정규화와 같다고 생각하기 쉽지만, 층 정규화는 한 토큰의 목록 하나 안에서 평균과 표준편차를 구한다. 위 예의 \([1.670,\ 0.330]\)에서 평균 1과 표준편차 0.670은 이 목록의 두 칸에서 나왔다. 다른 토큰이나 다른 문장을 보지 않는다.

위치 인코딩이 없어도 순서를 안다고 생각하기 쉽지만, 어텐션은 순서를 구분하지 못한다. 마스크가 앞뒤를 가르는 용도에서만 순서 정보가 새어 들어온다.

마스크가 학습할 때만 쓰이고 글을 이어 쓸 때는 필요 없다고 생각하기 쉽지만, 이어 쓸 때는 뒤 토큰이 아직 없어서 자연히 안 보인다. 학습 때는 정답 문장 전체가 이미 있어서 일부러 가려야 한다. 학습에서 안 가리고 쓰면 모델이 정답을 보고 베낀다.

헤드가 많을수록 계산이 헤드 수만큼 늘 것 같지만, 헤드 하나의 길이를 \(d/h\)로 두므로 총량은 비슷하다.

## 정리

트랜스포머의 블록은 어텐션과 칸마다의 층을 잔차 연결과 층 정규화로 감싼 것이다. 멀티헤드는 어텐션을 여러 벌 두고 이어 붙여 \(W_O\)로 섞고, 위치 인코딩은 순서를 목록에 더해 넣는다. 다음 토큰을 맞히는 모델은 마스크로 뒤를 가려 앞만 보는 블록을 쌓는다. 이 블록 위에서 정답을 다음 토큰으로 두고 손실을 계산하는 것이 [다음 토큰](./next-token.md)이고, 가린 칸을 앞뒤로 보고 맞히는 것이 [버트](./bert.md)다.
