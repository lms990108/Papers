[경사하강법](./gradient-descent.md)이 줄이는 것은 학습에 넣은 쌍의 손실입니다. 그 손실이 0에 가깝다고 해서, 넣지 않은 그림에서도 맞힌다는 뜻은 아닙니다. 파라미터를 충분히 많이 주면, 학습 쌍의 답을 그냥 외우는 함수도 만들 수 있습니다. 그 함수는 학습 손실이 작지만, 새 그림의 픽셀이 조금 다르면 답이 없습니다.

보고 싶은 오류는 학습에 쓰지 않은 입력에서의 오류입니다. 오류는 틀린 개수의 비율이어서, 백 장 중 한 장을 틀리면 1%입니다. 손실이 작다는 말과는 다릅니다. 손실은 오차를 제곱하거나 정답 비율의 로그를 씌워, 학습이 줄이는 수입니다. 시험 집합으로 오류를 추정하는데, 시험 오류와 학습 오류 사이에는 간격이 있습니다. 그 간격이 크면, 학습 손실을 줄인 것이 외우기에 가깝습니다.

:::tip[한눈에 보기]
**정의**: 용량(capacity)은 모델이 만들 수 있는 함수의 다양함이고, 정칙화(regularization)는 학습 손실에 벌점을 더해 실제로 쓰는 용량을 누르는 일입니다.

- 용량을 키우면 학습 오류는 계속 내려가지만, 시험 오류는 어느 용량 뒤부터 다시 올라갑니다.
- 시험과 학습의 간격은 대략 \((h/P)^{\alpha}\)에 비례합니다. 학습 쌍 \(P\)가 늘면 줄고, 용량 \(h\)가 늘면 늡니다.
- 가중치 제곱합 같은 항을 손실에 더하면, 학습 오류를 조금 내주고 간격을 줄입니다.
- 파라미터가 많아도 시험 오류가 무너지지 않는 이유는 아직 정리된 이론이 아닙니다.

먼저 읽으면 좋은 글은 [경사하강법](./gradient-descent.md)과 [역전파](./backpropagation.md)이고, 이어지는 글은 [데이터 분리](./data-split.md)와 [판별 학습](./discriminative-learning.md)입니다.
:::

## 학습 손실만으로는 부족한 이유

별점이나 숫자 맞히기에서 학습은 가진 쌍의 평균 손실을 내립니다. 쌍이 8개이고 모델이 파라미터를 8개 이상 가지면, 8개 점을 모두 정확히 지나가는 함수가 대개 존재합니다. 학습 손실은 0입니다. 그런데 그 함수는 점 사이에서 크게 출렁일 수 있습니다. 8개 점 사이의 어떤 값에서 맞히는지는 손실에 들어가 있지 않습니다.

반대로 파라미터가 너무 적으면 학습 쌍조차 맞히지 못합니다. 직선 하나로 휘어지는 곡선을 맞히는 경우가 그렇습니다. 앞의 것을 **과적합**(overfitting), 뒤의 것을 **과소적합**(underfitting)이라고 합니다. 두 경우를 가르는 것이 용량입니다.

용량을 키우면 학습 쌍은 더 잘 맞힐 수 있습니다. 아래 그림에서 학습 오류는 오른쪽으로 갈수록 내려갑니다. 시험 오류는 중간까지는 같이 내려가다가, 용량이 더 커지면 다시 올라갑니다. 학습 곡선만 보면 오른쪽 끝이 나아 보이지만, 보고 싶은 것은 시험 곡선의 가장 낮은 자리입니다.

## 간격의 식

간격은 대략 다음과 같이 적습니다.

\[
E_{\mathrm{test}} - E_{\mathrm{train}} \approx k \left(\frac{h}{P}\right)^{\alpha}
\]

\(P\)는 학습 쌍의 수입니다. \(h\)는 그 모델이 만들 수 있는 함수가 얼마나 다양한지이고, 이것을 용량이라고 부릅니다. 이론에서는 VC 차원(Vapnik–Chervonenkis dimension) 같은 수로 잽니다. 용량이 크다는 것은, 같은 입력들에 대해 서로 다른 답을 내도록 파라미터를 고를 여지가 많다는 뜻입니다. \(\alpha\)는 0.5에서 1 사이이고 \(k\)는 상수입니다. 식을 말로 읽으면, 용량 대비 쌍이 적을수록 간격이 크고, 그 정도는 비율의 거듭제곱으로 변한다는 것입니다.

쌍을 두 배로 늘리면 \(h/P\)가 줄어서 간격이 줍니다. 외울 자리보다 볼 예가 많아지기 때문입니다. \(k\)를 몰라도 비율은 계산됩니다. 간격은 \(P\)가 두 배가 되면 \(2^{-\alpha}\)배가 됩니다. \(\alpha = 0.5\)이면 \(2^{-0.5} \approx 0.707\)배, \(\alpha = 1\)이면 0.5배입니다. \(P\)를 네 배로 늘리면 \(\alpha = 0.5\)에서 간격이 절반입니다. 반대로 용량 \(h\)를 두 배로 키우면 간격은 \(2^{\alpha}\)배가 되어 1.41배에서 2배로 커집니다.

용량을 키우면 학습 오류는 보통 더 내려갑니다. 더 많은 함수 중에서 학습 쌍에 맞는 것을 고를 수 있어서입니다. 대신 간격은 커질 수 있습니다. 그래서 시험 오류가 가장 낮은 용량이 따로 있습니다. 너무 작으면 학습 쌍조차 맞히지 못하고, 너무 크면 학습 쌍의 우연까지 따라갑니다.

## 파이썬으로 확인

간격이 실제로 이렇게 움직이는지 아주 작은 모델로 봅니다. \(y = \sin(\pi x)\)에 표준편차 0.2의 잡음을 더한 점 8개로 다항식을 맞춥니다. 차수가 높을수록 용량이 큽니다. 1차는 직선이고, 7차는 점 8개를 모두 지납니다. 시험은 같은 분포에서 새로 뽑은 200개이고, 오류는 평균 제곱 오차, MSE입니다. 잡음 때문에 시험 오차는 어떤 모델도 평균적으로 0.04(= 0.2²) 아래로 내려가지 못합니다.

```python
import math, random

def fit(xs, ys, deg, lam=0.0):
    """다항식 계수를 정규방정식 (A^T A + lam*I) w = A^T y 로 푼다."""
    n = deg + 1
    A = [[x ** k for k in range(n)] for x in xs]
    M = [[sum(r[i] * r[j] for r in A) + (lam if i == j else 0.0) for j in range(n)]
         + [sum(r[i] * y for r, y in zip(A, ys))] for i in range(n)]
    for i in range(n):                       # 가우스 소거
        p = max(range(i, n), key=lambda r: abs(M[r][i]))
        M[i], M[p] = M[p], M[i]
        for r in range(n):
            if r != i:
                f = M[r][i] / M[i][i]
                M[r] = [a - f * b for a, b in zip(M[r], M[i])]
    return [M[i][n] / M[i][i] for i in range(n)]

def mse(w, xs, ys):
    return sum((sum(c * x ** k for k, c in enumerate(w)) - y) ** 2 for x, y in zip(xs, ys)) / len(xs)

random.seed(1)
f = lambda x: math.sin(math.pi * x)
xs = [-1 + 2 * i / 7 for i in range(8)]                   # 학습 8개
ys = [f(x) + random.gauss(0, 0.2) for x in xs]
tx = [random.uniform(-1, 1) for _ in range(200)]          # 시험 200개
ty = [f(x) + random.gauss(0, 0.2) for x in tx]

print("차수  lam    학습 오차   시험 오차")
for deg, lam in [(1, 0), (3, 0), (7, 0), (7, 0.01), (7, 0.1)]:
    w = fit(xs, ys, deg, lam)
    print(f"{deg:>4}  {lam:<5}  {mse(w, xs, ys):<10.4f} {mse(w, tx, ty):.4f}")
```

```text
차수  lam    학습 오차   시험 오차
   1  0      0.3244     0.3386
   3  0      0.0224     0.0531
   7  0      0.0000     0.0947
   7  0.01   0.0125     0.0604
   7  0.1    0.0537     0.0911
```

1차는 학습도 시험도 0.33 안팎이라 과소적합입니다. 3차는 학습 0.0224, 시험 0.0531로 시험이 가장 낮습니다. 7차는 학습 오차가 0.0000으로 점 8개를 외웠지만 시험은 0.0947로 3차보다 나쁩니다. 그림의 곡선과 같은 모양입니다. 아래 세 줄은 같은 7차에 정칙화 계수 \(\lambda\)를 준 결과이고, 이 항은 다음 절에서 설명합니다. \(\lambda = 0.01\)에서 학습 오차는 0.0125로 올랐고 시험 오차는 0.0947에서 0.0604로 내려갔습니다. \(\lambda = 0.1\)은 너무 세서 시험이 다시 0.0911로 올랐습니다. 학습 오차를 내주는 정도에도 적당한 값이 있습니다.

이어서 쌍의 수 \(P\)를 늘려 봅시다. 같은 7차 모델에 \(P\)를 8에서 128까지 키우고, 매번 새 잡음으로 20번 학습한 평균입니다. 앞 코드의 `fit`, `mse`, `f`, `tx`, `ty`를 그대로 씁니다.

```python
print("P     학습 오차   시험 오차   간격   (20번 평균)")
for P in [8, 16, 32, 64, 128]:
    xs_ = [-1 + 2 * i / (P - 1) for i in range(P)]
    a = b = 0.0
    for _ in range(20):
        sy = [f(x) + random.gauss(0, 0.2) for x in xs_]
        w = fit(xs_, sy, 7)
        a += mse(w, xs_, sy) / 20
        b += mse(w, tx, ty) / 20
    print(f"{P:<5} {a:<11.4f} {b:<11.4f} {b - a:.4f}")
```

```text
P     학습 오차   시험 오차   간격   (20번 평균)
8     0.0000      0.1295      0.1295
16    0.0201      0.0546      0.0345
32    0.0336      0.0427      0.0091
64    0.0325      0.0393      0.0068
128   0.0369      0.0363      -0.0006
```

\(P = 8\)에서 간격은 0.1295이고 \(P = 128\)에서는 0에 가깝습니다. 학습 오차는 오히려 올라가고 시험 오차는 내려가서 둘이 0.04 근처에서 만납니다. 쌍이 용량에 비해 충분해지면 외울 자리가 사라집니다. 간격이 위 식처럼 매끈한 거듭제곱으로 줄지는 않고, 식은 경향입니다. 마지막 줄의 \(-0.0006\)은 시험이 학습보다 낮은 게 아니라 20번 평균에 남은 잡음입니다.

## 정칙화

구조적 위험 최소화는 학습 오류와 이 간격을 같이 줄이려는 형식입니다. 용량이 커지는 모델의 열을 두고, 앞 단계가 만들 수 있는 함수는 다음 단계도 만들 수 있게 쌓습니다. 작은 용량으로 설명되는 해는 큰 모델에서도 후보로 남고, 데이터가 그 이상의 용량을 받쳐 줄 때만 더 큰 쪽으로 갑니다. 위 코드의 1차, 3차, 7차가 이런 열입니다. 1차 직선은 3차 다항식의 특수한 경우이고 3차는 7차의 특수한 경우입니다.

실무에서는 손실에 항을 하나 더해서 비슷하게 만듭니다.

\[
E_{\mathrm{train}} + \lambda H(W)
\]

\(H(W)\)는 용량이 큰 영역의 파라미터에서 값이 커지도록 고릅니다. 가중치 제곱의 합이 대표적입니다. 가중치가 크면 시그모이드가 포화하고, 포화된 유닛은 더 급하게 꺾인 함수를 만듭니다. 가중치를 작게 누르는 항을 손실에 넣으면, 학습 오류를 조금 희생하더라도 그 용량을 피합니다. 이 항을 **정칙화**(regularization)라고 부릅니다. 한국어 자료는 정규화라고도 적는데, 정규화는 입력의 크기를 맞추는 normalization의 번역어이기도 해서 여기서는 정칙화로 둡니다.

\(\lambda\)는 두 목표의 비중을 정하는 수입니다. 0이면 정칙화가 없고, 커지면 가중치를 작게 두는 쪽이 이깁니다. \(H(W) = \sum w^2\)이면 그 기울기는 \(2\lambda w\)라서, 갱신은 \(w \leftarrow w - \epsilon(\partial E_{\mathrm{train}}/\partial w + 2\lambda w)\)가 됩니다. 정리하면 \((1 - 2\epsilon\lambda)w - \epsilon\,\partial E_{\mathrm{train}}/\partial w\)이고, 매 갱신마다 가중치가 조금씩 줄어듭니다. **가중치 감쇠**(weight decay)라고도 부르는 까닭입니다.

[경사하강법](./gradient-descent.md)의 예 \(E(w) = (w - 3)^2\)에 \(\lambda w^2\)를 더하면 최솟값이 3에서 \(3/(1+\lambda)\)로 당겨집니다. \(2(w-3) + 2\lambda w = 0\)을 풀면 나옵니다. 학습률 0.1로 직접 확인해 봅시다.

```python
# E(w) = (w - 3)^2 + lam * w^2 를 경사하강법으로 줄인다
eps = 0.1
for lam in [0.0, 0.5, 2.0]:
    w = 0.0
    for _ in range(200):
        grad = 2 * (w - 3) + 2 * lam * w      # 학습 손실의 기울기 + 정칙화 항의 기울기
        w -= eps * grad
    print(f"lam={lam}: w={w:.4f}  (이론값 {3 / (1 + lam):.4f})")
```

```text
lam=0.0: w=3.0000  (이론값 3.0000)
lam=0.5: w=2.0000  (이론값 2.0000)
lam=2.0: w=1.0000  (이론값 1.0000)
```

\(\lambda = 0\)이면 학습 손실의 최솟값 3에 도착하고, \(\lambda = 0.5\)이면 2, \(\lambda = 2\)이면 1에서 멈춥니다. 학습 손실만 보면 3이 제일 낫습니다. 정칙화는 그 자리에서 일부러 벗어나게 하는 것입니다.

드롭아웃, 조기 종료, 입력에 변형을 넣는 일도 모델이 실제로 쓰는 용량을 제한하는 쪽에 가깝습니다. 1998년의 정칙화 항 그 자체는 아니고, 나중에 같은 목적으로 쓴 방법입니다.

## 파라미터가 많은 모델

완전 연결망으로 은닉 유닛 300개를 두고 [MNIST](./mnist.md)를 학습하면 자유 파라미터가 매우 많은데, 시험 오류는 4.7%였습니다. 입력을 28×28 = 784 픽셀로 두면 은닉 300개와 출력 10개를 잇는 가중치와 편향이 \(785 \times 300 + 301 \times 10 = 238{,}510\)개입니다. 학습 영상은 60,000장이니 파라미터가 영상 수의 4배 가까이 됩니다. 파라미터가 이만큼인데 시험 오류가 바로 무너지지 않은 이유는 정리된 이론이 아닙니다. 당시의 추측은 경사 하강 자체에 정칙화처럼 보이는 움직임이 있다는 것입니다.

가중치가 전부 0인 곳은 안장점이지만 거의 모든 방향에서 끌립니다. 학습 초반에 가중치가 줄어들고, 가중치가 작으면 시그모이드가 거의 직선처럼 동작해서 망이 용량이 낮은 단층망처럼 보입니다. 학습이 진행되며 가중치가 커지고, 망이 실제로 쓰는 용량이 늘어납니다. 용량이 커지는 모델의 열을 학습 절차가 우연히 따라간다는 그림입니다. 가설이지 증명된 메커니즘이 아닙니다.

언어 모델은 파라미터가 매우 많고, 위 간격은 사라지지 않습니다. 다만 최적화가 그 용량을 한 번에 다 쓰지 않는 경우가 많아서, 파라미터 개수만으로 외웠는지 말할 수는 없습니다. 데이터를 늘리면 간격이 준다는 쪽은 그대로입니다. 같은 MNIST에서 학습 영상을 15,000장, 30,000장, 60,000장으로 늘리면, 구조를 넣은 합성곱망에서도 정확도가 올랐습니다.

간격을 줄이는 다른 방법은 구조를 넣어, 연결 수에 비해 자유 파라미터 수를 작게 만드는 것입니다. [가중치 공유](./weight-sharing.md)가 그 예입니다. [LeNet-5](./lenet-5.md)는 연결이 약 340,908개인데 공유 덕에 자유 파라미터가 약 60,000개이고, 학습 오류 0.35%와 시험 오류 0.95%의 간격은 0.6%p입니다. 어느 쌍으로 가중치를 움직이고, 어느 쌍으로 학습률을 고르고, 어느 쌍으로 오류를 적는지는 [데이터 분리](./data-split.md)에서 리뷰 열 개로 나눕니다.

## 헷갈리기 쉬운 점

**학습 오류가 0이라고 잘 학습된 것은 아닙니다.** 외웠다는 뜻일 수도 있습니다. 위 7차 모델은 학습 오류가 0.0000인데 시험 오류가 3차보다 나빴습니다.

**용량이 크다고 항상 과적합하는 것은 아닙니다.** 쌍이 충분하면 그렇지 않습니다. 같은 7차 모델이 \(P = 8\)에서는 간격 0.13이었지만 \(P = 128\)에서는 사실상 0이었습니다. 문제는 용량 그 자체가 아니라 용량 대비 쌍의 수입니다.

**정칙화는 학습 오류를 줄이는 방법이 아닙니다.** 오히려 학습 오류를 올립니다. 위 표에서 \(\lambda = 0.01\)은 학습 오차를 0.0000에서 0.0125로 올리고 시험 오차를 내렸습니다. 정칙화의 성패는 학습이 아니라 시험으로 판단합니다.

**\(\lambda\)를 크게 준다고 좋은 것은 아닙니다.** 너무 크면 과소적합입니다. \(\lambda = 0.1\)에서 시험이 다시 올랐고, 위 가중치 감쇠 예에서는 \(\lambda = 2\)가 최솟값을 3에서 1로 끌어당겼습니다. \(\lambda\)도 학습 전에 사람이 정하는 수라서 시험이 아니라 검증으로 고릅니다.

**손실이 작은 것과 오류가 작은 것은 다릅니다.** 손실은 학습이 줄이는 수이고, 오류는 틀린 비율입니다. 같은 오류 1%라도 손실은 모델마다 다릅니다.

## 연습 문제

**문제 1.** 간격이 \(P\)에 \(\alpha = 0.5\)로 반비례한다고 합시다. 학습 쌍이 1,000개일 때 간격이 0.08이면, 4,000개에서는 얼마로 예상하나요? \(\alpha = 1\)이면 얼마인가요?

**문제 2.** \(E(w) = (w - 3)^2 + \lambda w^2\)에서 \(\lambda = 1\)이면 최솟값은 어디인가요? \(w = 0\)에서 학습률 0.1로 한 번 갱신하면 \(w\)는 얼마가 되나요?

**문제 3.** 입력 100개, 은닉 20개, 출력 5개의 완전 연결망의 파라미터는 편향까지 몇 개인가요? 학습 쌍이 500개라면 파라미터와 쌍 중 어느 쪽이 많은가요?

<details>
<summary>정답</summary>

**문제 1.** \(P\)가 4배이면 \(4^{-\alpha}\)배입니다. \(\alpha = 0.5\)이면 \(4^{-0.5} = 0.5\)배라서 0.04입니다. \(\alpha = 1\)이면 \(1/4\)배라서 0.02입니다. 실제 간격이 식대로 줄지는 않습니다.

**문제 2.** 기울기가 \(2(w-3) + 2w = 4w - 6\)입니다. 0이 되는 \(w = 1.5\)가 최솟값이고 \(3/(1+1)\)과 같습니다. \(w = 0\)에서 기울기는 \(-6\)입니다. 갱신은 \(0 - 0.1 \times (-6) = 0.6\)입니다.

**문제 3.** 첫 층은 \(100 \times 20 + 20 = 2020\)개이고, 둘째 층은 \(20 \times 5 + 5 = 105\)개입니다. 합이 2,125개입니다. 학습 쌍 500개보다 파라미터가 4배 넘게 많습니다. 이런 경우 학습 오류만으로는 외웠는지 알 수 없어서 따로 둔 검증과 시험이 필요합니다.

## 정리

학습 오류는 가진 쌍에서 잰 값이라, 새 입력에서의 오류와 간격이 있습니다. 간격은 모델의 용량이 클수록 늘고, 학습 쌍이 많을수록 줍니다. 시험 오류가 가장 낮은 용량이 따로 있어서 학습 곡선이 아니라 시험 곡선으로 고릅니다. 손실에 가중치 제곱합 같은 항을 더하는 정칙화는 학습 오류를 내주고 간격을 줄입니다. 이 계수 \(\lambda\)나 용량을 어떤 쌍으로 고르는지는 [데이터 분리](./data-split.md)에서 이어집니다.
