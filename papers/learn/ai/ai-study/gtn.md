여기의 GTN은 어텐션 트랜스포머가 아닙니다.

수표나 단어는 모듈을 여러 개 거쳐 읽힙니다. 금액을 찾을 영역을 고르고, 그 안을 글자 후보로 자르고, 후보를 읽고, 금액으로 말이 되는 열만 남깁니다. 보통은 각 모듈을 따로 맞춥니다. 문자 인식기는 미리 잘린 글자로 학습하고, 전체를 붙인 뒤 일부 수만 손으로 돌려 수표 단위 오류를 낮춥니다. 그 마지막 조정은 오래 걸리고, 문서 전체의 손실에 대해 최적이라는 보장이 없습니다.

줄이고 싶은 것은 글자 하나의 손실이 아니라, 금액 전체를 틀릴 확률 같은 시스템 손실입니다. 그 손실로 모든 모듈의 파라미터를 움직이려면, 모듈 사이로 오가는 것이 미분 가능해야 합니다. 고정 길이 벡터는 여기에 잘 맞지 않습니다. 글자 수가 매번 다르고, 한 입력에 해석이 여러 개입니다. 벡터 하나로 누르면 어느 절단이 어느 해석이었는지가 사라집니다.

**GTN**은 그 상태를 그래프로 둡니다. 가중치가 달린 유향 그래프를 받아 또 다른 그래프를 내는 모듈을 이어 붙입니다. 경로 하나가 해석 하나입니다. 호에는 후보 라벨과 벌점이 붙습니다. 아래는 그 모듈 사슬입니다. 각 상자가 그래프를 받아 그래프를 내며, 마지막에 가장 싼 경로를 읽습니다. 트랜스포머의 층과는 다른 그림입니다.

:::tip[한눈에 보기]
**정의**: 모듈이 가중치 달린 유향 그래프를 입력받아 그래프를 출력하도록 이어 붙이고, 마지막 문자열 전체의 손실을 그래프의 호 벌점까지 역전파해 모든 모듈을 같이 학습하는 구조입니다. 1998년 LeCun 등의 논문 "Gradient-Based Learning Applied to Document Recognition"에서 제안했습니다.

- 모듈 사이로 오가는 것은 벡터가 아니라 그래프입니다. 경로 하나가 해석 하나이고, 호에는 라벨과 벌점이 붙습니다.
- 손실은 두 비용의 차입니다. 정답 라벨과 맞는 경로만 남긴 제약 그래프의 비용에서, 제약 없는 그래프의 비용을 뺍니다.
- 비용은 비터비(최소)나 전방(logadd)으로 정합니다. 기울기는 그 비용에 들어간 호의 벌점으로 흐르고, 거기서 인식기로 이어집니다.
- 학습되는 것은 호의 벌점을 만드는 모듈의 파라미터입니다. 그래프의 뼈대(어느 호가 있는가)는 규칙이 만듭니다.

먼저 알면 좋은 것: [휴리스틱 과분할](./over-segmentation.md), [비터비](./viterbi.md), [전방 알고리즘](./forward-algorithm.md), [역전파](./backpropagation.md). 이어지는 것: [공간 이동 신경망](./sdnn.md).
:::

## 모듈이 그래프를 바꿉니다

분할 모듈은 후보 절단으로 그래프를 만듭니다. 노드는 절단 위치, 호는 그 사이의 잉크입니다. 인식 모듈은 각 호에 문자 후보와 벌점을 붙입니다. 문법 모듈은 금액처럼 허용된 라벨열만 남깁니다. 마지막에 비용이 가장 작은 경로를 읽으면 인식 결과입니다. 그 경로는 [비터비](./viterbi.md)로 고릅니다. 경로를 전부 더한 점수가 필요하면 [전방 알고리즘](./forward-algorithm.md)입니다.

[휴리스틱 과분할](./over-segmentation.md) 페이지의 “41” 예를 이 사슬에 넣어 보겠습니다. 조각이 세 개이고, 조각 하나짜리 호 셋과 두 조각을 건너뛰는 호 둘이 있습니다. 인식 모듈은 호 하나에 클래스 세 개(1, 4, 쓰레기)의 벌점을 붙입니다. 문법은 숫자만 허용하므로 쓰레기 호를 지웁니다. 학습 때는 정답 라벨이 “11”이라면 그 라벨을 내는 호만 남긴 그래프를 하나 더 만듭니다. 단계마다 그래프의 크기가 달라집니다.

| 단계 | 호 수 | 경로 수 | 내용 |
| --- | --- | --- | --- |
| 분할 그래프 | 5 | 3 | 조각 단위 분할 3가지 |
| 인식 그래프 | 15 | 45 | 호마다 클래스 3개의 벌점 |
| 문법 뒤(제약 없음) | 10 | 16 | 쓰레기 호 제거 |
| 정답 “11”만 남김(제약) | 4 | 2 | 라벨이 1, 1인 경로만 |

입력마다 그래프 모양이 달라도 됩니다. 글자 수가 다르면 노드 수가 다릅니다. 이 점이 고정 길이 벡터와 다릅니다. 비터비 손실에서는 학습 때 그 입력에서 실제로 선택된 경로의 호만 기울기를 받습니다. 쓰이지 않은 해석의 호를 고쳐도 이 입력의 손실은 변하지 않기 때문입니다. 전방 손실에서는 모든 호가 기울기를 받되, 쓰일 확률에 비례합니다.

## 두 비용의 차

그래프를 입력받는 모듈이 마지막에 내는 값이 손실입니다. 같은 격자에서 그래프를 둘 만듭니다. 하나는 문법까지만 거친 제약 없는 그래프로, 모든 해석이 들어 있습니다. 다른 하나는 정답 라벨과 맞는 경로만 남긴 제약 그래프입니다. 제약 그래프의 경로는 제약 없는 그래프에 모두 들어 있으므로, 전자가 후자의 부분집합입니다. 각 그래프에서 비용을 하나씩 뽑습니다.

\[
E = C_c - C_u
\]

\(C_c\)는 정답 라벨의 제약 그래프에서 읽은 비용이고, \(C_u\)는 제약 없는 그래프에서 읽은 비용입니다. 비터비로 읽으면 각각 그 그래프의 최소 경로 비용입니다. 전방으로 읽으면 각 그래프에 있는 모든 경로의 \(\mathrm{logadd}\)입니다. 논문은 이 두 가지를 판별적 비터비 학습과 판별적 전방 학습으로 다룹니다. \(C_c\)만 쓰고 \(C_u\)를 빼지 않으면 인식기가 입력과 상관없이 모든 출력을 작게 만들어 손실을 줄이는 붕괴가 생깁니다. 부분집합 관계 덕분에 \(E \ge 0\)이고, 정답 경로가 이미 가장 싸면 비터비 손실은 0이 됩니다.

\(E\)를 호 \(i\)의 벌점 \(c_i\)로 미분하면 경로 선택이 그대로 기울기가 됩니다. 비터비에서는 선택된 최소 경로에 호 \(i\)가 있으면 1, 아니면 0입니다. 그래서 다음과 같습니다.

\[
\frac{\partial E}{\partial c_i} = [\, i \in p_c^* \,] - [\, i \in p_u^* \,]
\]

\(p_c^*\)는 제약 그래프의 최소 경로, \(p_u^*\)는 제약 없는 그래프의 최소 경로이고, 대괄호는 참이면 1입니다. 전방에서는 호가 쓰일 확률의 차가 됩니다. 한 그래프에서 경로 \(p\)의 비용이 \(C_p\)일 때, 호 \(i\)를 지나는 경로들의 \(e^{-C_p}\) 합을 전체 합으로 나눈 값을 \(P(i)\)라 하면 다음과 같습니다.

\[
\frac{\partial E}{\partial c_i} = P_c(i) - P_u(i)
\]

두 식을 말로 읽으면 같습니다. 정답 쪽에서 쓰인 호는 벌점을 내리고, 제약 없는 쪽에서 쓰인 호는 벌점을 올립니다. 양쪽에서 똑같이 쓰인 호는 서로 상쇄되어 변하지 않습니다.

### 숫자로 보기

같은 격자에서 정답 라벨이 “11”이라고 합시다. 문법을 거친 호 열 개의 벌점은 과분할 페이지의 표에서 쓰레기 열을 뺀 것입니다.

| 호 | 1 | 4 |
| --- | --- | --- |
| 0→1 | 2.4 | 3.5 |
| 1→2 | 1.8 | 4.0 |
| 2→3 | 0.4 | 5.0 |
| 0→2 | 3.5 | 0.5 |
| 1→3 | 3.2 | 4.5 |

제약 없는 그래프의 최소 경로는 0→2의 4와 2→3의 1로, 비용은 0.5 + 0.4 = 0.9이고 읽으면 “41”입니다. 정답 “11”을 내는 경로는 둘입니다. 0→2의 1과 2→3의 1은 3.5 + 0.4 = 3.9이고, 0→1의 1과 1→3의 1은 2.4 + 3.2 = 5.6입니다. 제약 그래프의 최소는 3.9입니다. 비터비 손실은 3.9 − 0.9 = 3.0입니다.

기울기는 두 최소 경로의 호로만 생깁니다. 제약 쪽 최소 경로는 (0→2, 1)과 (2→3, 1)이고, 제약 없는 쪽 최소 경로는 (0→2, 4)와 (2→3, 1)입니다.

| 호 | 제약 쪽 | 제약 없는 쪽 | 기울기 | 학습이 하는 일 |
| --- | --- | --- | --- | --- |
| 0→2, 1 | 쓰임 | 안 쓰임 | +1 | 벌점을 내린다 |
| 0→2, 4 | 안 쓰임 | 쓰임 | −1 | 벌점을 올린다 |
| 2→3, 1 | 쓰임 | 쓰임 | 0 | 그대로 둔다 |

조각 3을 1로 읽는 호는 정답 경로에도 오답 경로에도 들어 있어서 건드리지 않습니다. 틀린 것은 조각 1+2를 4로 읽은 판단뿐이고, 그 호만 올리고 같은 조각을 1로 읽는 호는 내립니다. 사람이 경계도, 어느 호가 틀렸는지도 알려 주지 않았습니다. 정답 문자열만 주었는데 틀린 호가 가려졌습니다.

전방으로 읽으면 같은 격자에서 손실이 조금 달라집니다. 제약 그래프의 전방 비용은 \(-\log(e^{-3.9} + e^{-5.6})\)로 3.732이고, 제약 없는 쪽은 0.793입니다. 손실은 2.939입니다. 기울기는 호가 쓰일 확률의 차라서 최소 경로 밖의 호도 조금씩 받습니다. 코드로 확인합니다.

```python
import math
# 문법을 거친 격자의 호: (시작, 끝, 라벨) -> 벌점 (쓰레기 호는 이미 빠졌다)
cost = {
    (0, 1, "1"): 2.4, (0, 1, "4"): 3.5, (1, 2, "1"): 1.8, (1, 2, "4"): 4.0,
    (2, 3, "1"): 0.4, (2, 3, "4"): 5.0, (0, 2, "1"): 3.5, (0, 2, "4"): 0.5,
    (1, 3, "1"): 3.2, (1, 3, "4"): 4.5,
}

def paths(node=0):
    if node == 3:
        yield []
    for arc in cost:
        if arc[0] == node:
            for rest in paths(arc[1]):
                yield [arc] + rest

def total(p):
    return sum(cost[a] for a in p)

def logadd(xs):
    m = min(xs)
    return m - math.log(sum(math.exp(-(x - m)) for x in xs))

target = "11"
every = list(paths())
right = [p for p in every if "".join(a[2] for a in p) == target]
print("경로", len(every), "정답 라벨 경로", len(right))

vit_c, vit_u = min(map(total, right)), min(map(total, every))
fwd_c, fwd_u = logadd([total(p) for p in right]), logadd([total(p) for p in every])
print(f"비터비 {vit_c:.1f} - {vit_u:.1f} = {vit_c - vit_u:.3f}")
print(f"전방   {fwd_c:.3f} - {fwd_u:.3f} = {fwd_c - fwd_u:.3f}")
```

```text
경로 16 정답 라벨 경로 2
비터비 3.9 - 0.9 = 3.000
전방   3.732 - 0.793 = 2.939
```

이어서 기울기를 계산합니다. 위 코드에 붙여 실행합니다. 전방 기울기는 두 그래프에서 호가 쓰일 확률의 차이고, 절댓값이 0.1보다 큰 호만 출력합니다.

```python
def use_prob(group):
    """그 경로 모음 안에서 호가 쓰일 확률(경로 확률의 합)."""
    w = [math.exp(-total(p)) for p in group]
    prob = dict.fromkeys(cost, 0.0)
    for wi, p in zip(w, group):
        for a in p:
            prob[a] += wi / sum(w)
    return prob

pc, pu = use_prob(right), use_prob(every)
for a in cost:
    g = pc[a] - pu[a]
    if abs(g) > 0.1:
        print(a, f"{g:+.3f}")

# 비터비 쪽: 정답 최소 경로는 +1, 전체 최소 경로는 -1
best_c, best_u = min(right, key=total), min(every, key=total)
print("정답 최소", best_c, "전체 최소", best_u)
```

```text
(0, 1, '1') +0.119
(2, 3, '1') -0.131
(0, 2, '1') +0.800
(0, 2, '4') -0.908
(1, 3, '1') +0.144
정답 최소 [(0, 2, '1'), (2, 3, '1')] 전체 최소 [(0, 2, '4'), (2, 3, '1')]
```

부호는 “이 벌점을 올리면 손실이 늘어난다”는 뜻입니다. 양수인 호는 내려가고 음수인 호는 올라갑니다. (0→2, 1)이 +0.800, (0→2, 4)가 −0.908이어서 비터비 때와 같은 방향입니다. 비터비에서 0이던 (2→3, 1)은 −0.131입니다. 제약 없는 쪽에서 그 호가 쓰일 확률이 정답 라벨 쪽보다 높아서 조금 올라갑니다. 0→1이나 1→3처럼 비터비에서 아예 선택되지 않았던 정답 경로의 호도, 정답 쪽에서 쓰일 확률이 더 높은 만큼 벌점이 내려갑니다.

## 기울기가 호를 타고 돌아갑니다

호의 벌점을 파라미터로 미분할 수 있으면 학습이 됩니다. 손실이 정답 경로의 벌점 합이면, 그 경로에 들어온 호의 편미분은 1이고 나머지 호는 0입니다. 최솟값과 덧셈으로 이루어진 선택도, 선택된 호와 아닌 호로 기울기가 갈리기 때문에 뒤로 보낼 수 있습니다. 그래프가 이산적인 물체처럼 보여도, 학습이 보는 것은 호에 적힌 벌점이라는 실수입니다.

그 호 벌점이 문자 인식기의 출력이면, 기울기가 그 인식기 인스턴스로 들어갑니다. 인식기는 호마다 다른 조각 영상에 같은 가중치로 적용됩니다. 위의 예에서 전방 기준으로는 조각 1+2의 영상에 대한 4와 1의 벌점이 각각 −0.908과 +0.800의 기울기를 받습니다. 이 값들을 인식기 출력의 기울기로 보고 [합성곱 신경망](./cnn.md) 안으로 [역전파](./backpropagation.md)하면, 같은 영상을 4가 아닌 1로 읽도록 가중치가 움직입니다. 인스턴스들은 파라미터를 공유하므로, 인식기 파라미터의 기울기는 인스턴스별 기울기의 합입니다. [LeNet-5](./lenet-5.md)를 고립된 숫자에 학습하던 것이, 그래프 안에서 경계가 불확실한 조각에 학습되는 것입니다. [가중치 공유](./weight-sharing.md)를 고정된 층 밖으로 늘린 형태입니다.

정답 경로의 비용만 내리면 붕괴가 있습니다. 인식기가 입력을 무시하고 모든 출력을 작게 내도 손실이 줄어들 수 있습니다. 정답 경로 비용에서 전체 최소 경로 비용, 또는 전방 비용을 빼는 [판별 학습](./discriminative-learning.md)을 쓰면 오답 쪽 벌점이 올라갑니다. 생성 모델인 [은닉 마르코프 모델](./hmm.md)은 확률 합이 1이라 이 붕괴가 구조적으로 막혀 있지만, 신경망 출력을 그래프에 붙이면 그 정규화가 자동으로 유지되지 않습니다.

트랜스포머도 모듈을 쌓아 시퀀스를 다루지만, 격자 위에서 최단 경로로 해석을 고르지는 않습니다. 모든 위치를 어텐션으로 섞습니다. 가설을 그래프로 들고 가고 문자열 전체의 손실로 앞 모듈을 같이 학습하는 방식은 음성 트랜스듀서와 격자 학습에 남아 있습니다.

## 헷갈리기 쉬운 점

**GTN은 트랜스포머의 한 종류가 아닙니다.** 이름만 겹칩니다. 트랜스포머는 토큰 벡터를 어텐션으로 섞는 구조고, GTN은 가중치 달린 그래프를 주고받는 모듈의 사슬입니다. 이 페이지의 “transformer”는 변환기(graph transformer, 그래프를 다른 그래프로 바꾸는 모듈)라는 뜻입니다.

**그래프의 구조까지 학습되는 것은 아닙니다.** 학습되는 것은 호에 붙는 벌점을 만드는 모듈의 파라미터입니다. 어느 호가 있는지(절단 후보, 문법)는 규칙이 만듭니다. 위 예에서 노드 2가 아예 없었다면 어느 벌점을 바꿔도 “41”이 나올 수 없습니다. 기울기는 그래프에 있는 호에만 흐릅니다.

**최솟값에도 기울기는 있습니다.** 최솟값은 미분이 안 되는 것처럼 보이지만, 선택된 호로는 기울기가 1로 흐릅니다. 비교하는 값이 정확히 같은 경우만 불연속이고, 그 밖에는 조각별로 선형입니다. ReLU와 같은 사정입니다. 그 대신 선택에서 밀려난 호는 이번 입력에서 기울기를 받지 못합니다. 전방은 모든 호에 매끄러운 기울기를 주는 쪽입니다.

**손실이 0이어도 정답 확률이 1인 것은 아닙니다.** 비터비 차이는 정답 라벨이 최소 경로에 들어 있기만 하면 0입니다. 위의 정답이 “41”이면 비터비 손실도 0이고 모든 호의 기울기가 상쇄되어 0입니다. 그때도 전방 손실은 0.104로 남습니다(연습 문제 1번). 비터비 차이에는 정답과 오답 사이를 벌려 놓는 여유 폭이 없어서, 손실이 0이 되면 학습이 거기서 멈춥니다. 전방 손실은 정답 쪽 경로가 전체 확률을 독점하기 전까지 기울기를 줍니다.

**문법은 추론 때만 쓰는 후처리가 아닙니다.** 문법을 합성한 그래프가 손실 계산에도 들어갑니다. 제약 없는 그래프도 문법을 거친 그래프이고, 문법이 허용하지 않는 해석(위의 쓰레기만으로 이뤄진 경로)은 오답 쪽에서도 빠집니다. 학습과 추론이 같은 그래프 위에서 일어납니다.

## 변형과 관련 개념

비터비와 전방은 같은 틀에서 최소 대신 logadd를 쓰는 차이일 뿐입니다. 계산량은 둘 다 호 수에 비례합니다. 비터비는 구현이 쉽고, 전방은 같은 라벨을 내는 분할이 여러 개일 때 그 증거를 모읍니다. CTC 손실은 정답 전사와 맞는 정렬을 전부 더하는 전방 학습의 한 형태로 볼 수 있고, 그 격자는 시간 축으로 정해진 모양입니다. GTN은 격자의 모양까지 입력마다 달라도 되는 일반형입니다.

격자를 만드는 쪽의 선택지는 둘입니다. [과분할](./over-segmentation.md)은 후보 절단을 규칙으로 만들고, [공간 이동 신경망](./sdnn.md)은 같은 CNN을 입력 전체에 밀어 위치마다 클래스 벌점 벡터를 내고 그 열을 격자로 씁니다. 뒤쪽 처리인 문법과 손실은 똑같이 GTN입니다.

## 연습 문제

**1.** 위 격자에서 정답 라벨이 “41”이면 비터비 손실과 기울기는 얼마인가요? 전방 손실은 0보다 큰가요?

<details>
<summary>정답</summary>

제약 그래프의 경로는 둘이고 비용은 0.9(0→2의 4와 2→3의 1)와 6.7(0→1의 4와 1→3의 1)입니다. 최소는 0.9로 제약 없는 최소와 같은 경로라서 비터비 손실은 0.9 − 0.9 = 0이고, 두 경로의 호가 같으므로 기울기는 모두 상쇄되어 0입니다. 전방은 \(-\log(e^{-0.9} + e^{-6.7}) = 0.897\)이고 제약 없는 쪽이 0.793이어서 손실은 0.104입니다. 0.9 말고 다른 해석(예: “111”)도 비용이 낮아 전체 확률을 일부 가져가므로 0보다 큽니다. 코드의 `target`을 `"41"`로 바꿔 실행해 확인했습니다.

</details>

**2.** 정답 라벨이 “111”이면 비터비 손실과, 0이 아닌 기울기를 받는 호는 무엇인가요?

<details>
<summary>정답</summary>

“111”을 내는 경로는 0→1, 1→2, 2→3을 모두 1로 읽는 경로 하나이고 비용은 2.4 + 1.8 + 0.4 = 4.6입니다. 제약 없는 최소는 0.9이므로 손실은 3.7입니다. 제약 쪽 호 (0→1, 1), (1→2, 1), (2→3, 1)이 +1, 제약 없는 쪽 호 (0→2, 4), (2→3, 1)이 −1입니다. (2→3, 1)이 양쪽에 있어 상쇄되므로, 0이 아닌 호는 (0→1, 1) +1, (1→2, 1) +1, (0→2, 4) −1 셋입니다. 전방으로 계산하면 같은 호가 +0.965, +0.970, −0.908로 거의 같은 값을 받습니다.

</details>

**3.** \(E = C_c - C_u\)가 비터비, 전방 어느 쪽으로 읽어도 0 이상임을 보여 보세요.

<details>
<summary>정답</summary>

제약 그래프의 경로 집합은 제약 없는 그래프의 부분집합입니다. 비터비에서는 부분집합 안의 최솟값이 전체의 최솟값 이상입니다. 전방에서는 \(\sum e^{-C_p}\)가 부분집합일 때 전체보다 작거나 같으므로 \(-\log\)를 취한 값은 반대로 이상이 됩니다. 위의 세 가지 정답 라벨에서 손실이 3.000, 0.000, 3.700(비터비)과 2.939, 0.104, 3.807(전방)로 모두 0 이상이었습니다.

</details>

## 정리

GTN은 모듈 사이로 고정 길이 벡터 대신 가중치 달린 그래프를 보내고, 문자열 전체의 손실을 호의 벌점을 거쳐 모든 모듈로 돌려보냅니다. 손실은 정답 라벨의 제약 그래프 비용에서 제약 없는 그래프 비용을 뺀 값이고, 비터비로 읽으면 두 최소 경로의 호만, 전방으로 읽으면 쓰일 확률의 차만큼 기울기를 받습니다. 양쪽에서 똑같이 쓰인 호는 상쇄됩니다. 이 구조는 후보 절단을 만드는 [과분할](./over-segmentation.md)에도, 절단 없이 입력을 훑는 [공간 이동 신경망](./sdnn.md)에도 같은 손실로 붙습니다.
