왼쪽에서 가로획을 알아보는 검출기가 쓸모 있으면, 오른쪽의 가로획에도 같은 검출기가 쓸모 있을 가능성이 크다. 위치마다 파라미터를 따로 두면 그 사실이 구조에 들어가지 않는다. 왼쪽 검출기와 오른쪽 검출기는 다른 수가 되고, 학습이 둘을 같게 만들려면 양쪽 위치의 예가 모두 필요하다. 자유 파라미터도 위치 수만큼 늘어 [용량](./capacity.md)이 커진다.

:::tip[한눈에 보기]
가중치 공유는 서로 다른 위치(또는 시각)의 유닛이 같은 파라미터 하나를 쓰도록 묶는 제약이다.

- 순방향에서는 같은 값을 여러 연결에 쓴다. 연결 수는 그대로고 서로 다른 값의 수만 줄어든다.
- 역방향에서는 그 파라미터를 쓰는 모든 연결의 기울기를 더해서 한 번에 갱신한다.
- 입력이 이동하면 출력도 같은 만큼 이동한다(이동 동변).
- LeNet-5는 연결이 340,908개인데 학습 파라미터는 60,000개다.

이전에 알아야 할 것: [역전파](./backpropagation.md), [용량](./capacity.md). 다음에 이어지는 것: [합성곱 신경망](./cnn.md), [서브샘플링](./subsampling.md).
:::

가중치 공유는 그 검출기를 하나의 파라미터로 고정하는 일이다. 수용장 위치만 다르고, 그 안의 가중치는 같다. 입력이 이동하면 검출 결과도 같은 만큼 이동한다. 이동했을 때의 반응을, 데이터가 그 위치의 예를 보여줄 때까지 기다리지 않는다.

왼쪽은 자리마다 가중치가 따로다. 같은 가로획이라도 왼쪽 칸의 \(w\)와 오른쪽 칸의 \(w\)가 다른 수라, 한쪽에서 배운 것이 다른 쪽으로 옮겨 가지 않는다. 오른쪽은 두 자리가 상자 하나를 같이 본다. 그 상자를 고치면 두 자리가 같이 바뀐다.

[합성곱 신경망](./cnn.md)의 특징 맵 하나가 이 제약이다. 맵 안의 유닛은 모두 같은 가중치 벡터를 쓴다. 맵이 여러 장이면 검출기 종류는 여러 개지만, 각 검출기는 여전히 모든 위치에서 같다.

## 연결 수와 파라미터 수

LeNet-5는 연결이 340,908개다. 공유가 없으면 학습할 수도 그만큼이다. 맵 안에서는 같은 가중치를 쓰므로 자유 파라미터는 약 60,000개다. 첫 합성곱만 보면, 5×5 커널과 바이어스를 맵 6장이 쓰면 학습 파라미터는 156개다. 그 맵들이 만드는 연결은 122,304개다.

파라미터가 줄면, 구조가 허용하지 않는 함수는 처음부터 후보에서 빠진다. 왼쪽 모서리와 오른쪽 모서리에 전혀 다른 필터를 쓰는 함수는 이 망이 표현할 수 없다. 그것이 용량을 줄이는 방식이다. 손실에 가중치 제곱을 더하는 정칙화와 달리, 여기는 파라미터의 자유도 자체를 줄인다.

공유로 줄어드는 정도는 층마다 다르다. 한 맵 안의 위치 수가 곧 그 층에서 연결 수를 파라미터 수로 나눈 값이다. C1은 맵이 28×28이라 784, S2는 14×14 맵의 유닛마다 입력 4개와 바이어스를 쓰고 맵마다 계수 2개이므로 \(196 \times 5 / 2 = 490\)이다. C3는 10×10이라 100, S4는 5×5라 62.5다. C5는 맵이 1×1이라 위치가 하나뿐이고, F6도 완전 연결이라 둘 다 1이다. 그 층에서는 공유할 상대가 없으므로 연결 수와 파라미터 수가 같다. 이 비는 아래 코드로 확인했다. 앞의 층일수록 공유 효과가 크고, 뒤로 갈수록 공유할 위치가 사라진다.

```python
# (층, 학습 파라미터, 연결 수)
layers = [("C1", 156, 122304), ("S2", 12, 5880), ("C3", 1516, 151600),
          ("S4", 32, 2000), ("C5", 48120, 48120), ("F6", 10164, 10164)]
for name, p, c in layers:
    print(f"{name}: 연결 {c:>7,} / 파라미터 {p:>6,} = {c/p:g}배")
print("합계 파라미터", sum(p for _, p, _ in layers))
print("합계 연결(출력 RBF 840 포함)", sum(c for _, _, c in layers) + 840)
```

```text
C1: 연결 122,304 / 파라미터    156 = 784배
S2: 연결   5,880 / 파라미터     12 = 490배
C3: 연결 151,600 / 파라미터  1,516 = 100배
S4: 연결   2,000 / 파라미터     32 = 62.5배
C5: 연결  48,120 / 파라미터 48,120 = 1배
F6: 연결  10,164 / 파라미터 10,164 = 1배
합계 파라미터 60000
합계 연결(출력 RBF 840 포함) 340908
```

학습 파라미터의 합은 정확히 60,000이고, 연결의 합은 출력층의 RBF 연결 840개(\(84 \times 10\))를 더해야 340,908이 된다. 출력 RBF의 기준 벡터는 고정이라 학습 파라미터에는 들어가지 않는다.

## 학습할 때 기울기를 더한다

순방향에서 같은 값을 쓰는 것만으로는 부족하다. [역전파](./backpropagation.md)에서 그 파라미터를 쓰는 연결마다 변화율을 구한 뒤 더해야 한다. 파라미터를 조금 바꾸면 그 연결들이 전부 변하므로, 손실의 변화는 연결별 변화의 합이다. 더하지 않으면 다음 갱신에서 연결마다 다른 값이 되어 공유가 풀린다.

구현은 공유가 없는 망인 것처럼 연결별 편미분을 먼저 구하고, 같은 파라미터에 묶인 것을 합치면 된다. 합성곱망의 앞층은 파라미터 하나가 출력의 많은 위치에 영향을 준다. 그 파라미터의 2차 미분은 매우 클 수 있고, 뒤층 파라미터의 2차 미분은 작을 수 있다. 보폭을 파라미터마다 나누는 이유는 [확률적 경사하강법](./sgd.md)에 있다.

## 숫자로 보는 기울기 합산

가장 작은 경우로 확인한다. 같은 검출기 \(w\)가 두 자리를 본다. 자리 1의 입력은 \(x_1 = 2\), 자리 2의 입력은 \(x_2 = 3\)이다. 출력은 \(y_k = w x_k\)이고, 목표는 \(t_1 = 3\), \(t_2 = 0\)이다. 손실은 \(L = \tfrac12 \sum_k (y_k - t_k)^2\)이다. \(w = 0.5\)에서 시작한다.

| 자리 | 입력 \(x_k\) | 출력 \(y_k = w x_k\) | 오차 \(y_k - t_k\) | 기울기 \((y_k - t_k)\, x_k\) |
| --- | --- | --- | --- | --- |
| 1 | 2 | 1.0 | −2.0 | −4.0 |
| 2 | 3 | 1.5 | +1.5 | +4.5 |

자리 1은 \(w\)를 키우라고, 자리 2는 줄이라고 한다. 공유된 \(w\)가 받는 기울기는 둘의 합 \(-4.0 + 4.5 = 0.5\)다. 보폭 \(\eta = 0.1\)이면 \(w\)는 \(0.5 - 0.1 \times 0.5 = 0.45\)가 된다. 두 자리의 요구가 서로 당겨서 한 값이 타협한 것이다. 같은 값이 아니라 위치마다 따로 갱신했다면 자리 1의 값은 \(0.5 + 0.4 = 0.9\), 자리 2의 값은 \(0.5 - 0.45 = 0.05\)가 되어 두 값은 갈라진다. 그 순간 같은 검출기라는 전제가 깨진다.

```python
x1, x2 = 2.0, 3.0          # 같은 검출기가 보는 두 자리의 입력
t1, t2 = 3.0, 0.0          # 두 자리의 목표값
eta = 0.1

def loss(w1, w2):
    return 0.5 * ((w1*x1 - t1)**2 + (w2*x2 - t2)**2)

w = 0.5
e1, e2 = w*x1 - t1, w*x2 - t2          # 각 자리의 오차
g1, g2 = e1*x1, e2*x2                  # 자리별 기울기
g = g1 + g2                            # 공유: 더한다
print("자리별 기울기", g1, g2, "합", g)

h = 1e-6                               # 수치 미분으로 검산
num = (loss(w + h, w + h) - loss(w - h, w - h)) / (2*h)
print("수치 미분", round(num, 4))

print("공유 갱신 w =", w - eta*g, "손실", loss(w - eta*g, w - eta*g))
w1, w2 = w - eta*g1, w - eta*g2        # 각자 갱신하면 공유가 풀린다
print("따로 갱신 w1, w2 =", w1, w2, "손실", loss(w1, w2))

# 이동 동변: 입력을 2칸 밀면 출력도 2칸 밀린다
a, b, c = 1, 0, -1
conv = lambda x: [a*x[i] + b*x[i+1] + c*x[i+2] for i in range(len(x) - 2)]
x = [0, 0, 1, 3, 1, 0, 0, 0, 0, 0]
s = [0, 0] + x[:-2]
print(conv(x))
print(conv(s))
```

```text
자리별 기울기 -4.0 4.5 합 0.5
수치 미분 0.5
공유 갱신 w = 0.45 손실 3.11625
따로 갱신 w1, w2 = 0.9 0.04999999999999999 손실 0.73125
[-1, -3, 0, 3, 1, 0, 0, 0]
[0, 0, -1, -3, 0, 3, 1, 0]
```

수치 미분이 손으로 더한 0.5와 맞으므로, 공유 파라미터의 기울기가 연결별 기울기의 합이라는 것이 확인된다. 처음 손실은 \(\tfrac12(4 + 2.25) = 3.125\)이고 공유 갱신 뒤는 3.11625다. 따로 갱신한 쪽은 손실이 0.73125로 훨씬 빨리 내려간다. 자유도가 두 배라 훈련 데이터를 더 잘 맞추는 것이다. 공유가 이기는 곳은 훈련 손실이 아니라, 한 자리에서 배운 것이 다른 자리에서도 통하는 일반화다.

코드의 뒤쪽 두 줄은 이동 동변을 보인다. 필터 \((1, 0, -1)\)을 입력과 입력을 두 칸 민 것에 적용하면, 출력의 모양 \((-1, -3, 0, 3, 1)\)이 그대로 두 칸 밀려 나온다. 위치마다 가중치가 다른 층이라면 밀린 입력에 다른 가중치가 걸려서 이런 일이 생기지 않는다.

## 합성곱 밖의 공유

합성곱이라는 이름을 쓰지 않아도 같은 제약이 있다. 트랜스포머는 모든 토큰 위치에 같은 투영 행렬과 같은 블록을 쓴다. 입력 임베딩과 출력 임베딩을 하나의 행렬로 묶는 것도 공유다. 순환망은 시각마다 다른 전이 행렬을 두지 않고, 같은 전이를 시간 축에서 반복한다. 공통점은 한 파라미터를 여러 자리에 쓰고, 학습할 때 그 자리들의 기울기를 합친다는 것이다.

## 자주 헷갈리는 점

공유가 연결 수를 줄인다고 생각하기 쉽지만, 연결은 그대로다. 줄어드는 것은 서로 다른 값의 개수다. C1은 연결이 122,304개이고 값은 156개다. 계산량과 활성값 저장은 그대로이고, 파라미터를 저장하고 학습하는 부담만 줄어든다.

기울기를 평균해도 된다고 생각하기 쉽지만, 기본은 합이다. 손실이 파라미터를 거쳐 여러 연결을 지나므로 연쇄 법칙이 합으로 나온다. 평균은 합을 연결 수로 나눈 것이라 보폭이 그만큼 작아지는 것과 같다. 맵이 28×28이면 784배 차이이므로, 어느 쪽을 쓰든 보폭을 거기에 맞춰야 한다.

초기값을 같게 두면 공유라고 생각하기 쉽지만, 같은 값으로 시작해도 연결마다 기울기가 달라 따로 갱신하면 갈라진다. 위의 예에서 0.9와 0.05가 그렇다. 공유는 값이 같게 유지되는 제약, 곧 같은 변수 하나를 가리키는 것이다.

공유가 항상 표현력을 해쳐서 손해라고 생각하기 쉽지만, 입력에서 위치를 바꿔도 같은 검출기가 필요한 문제에서는 맞는 제약이다. 숫자 영상은 그렇다. 반대로 입력이 항상 같은 자리에 정렬되어 있고 자리마다 의미가 다른 문제에서는 맞지 않을 수 있다. 공유를 일부러 푼 변형도 있다. 이웃만 보되 위치마다 가중치가 따로인 층을 국소 연결(locally connected) 층이라 부른다. [합성곱 신경망](./cnn.md)의 파라미터 비교표에서 두 번째 줄의 방식이다.

공유와 서브샘플링은 다르다. 공유는 같은 가중치를 여러 위치에서 다시 쓰는 것이고, [서브샘플링](./subsampling.md)은 출력의 칸 수를 줄이는 것이다. 한 층이 둘 다 하기도 하지만 서로 독립이다.

## 직접 풀어 보기

1. 두 자리가 공유 파라미터 \(w\)를 쓴다. 입력은 \(x = (1, 4)\)이고 두 자리의 \((y_k - t_k)\)는 \((0.5, -0.25)\)다. \(w\)의 기울기와, \(\eta = 0.2\)일 때 \(w\)의 변화량을 구하라.
2. 입력 100칸에서 출력 98칸을 만든다. 커널은 3칸이다. 공유하지 않는 방식에서는 바이어스가 출력마다 하나, 공유하면 하나뿐이다. 완전 연결, 국소 수용장(공유 없음), 국소 수용장(공유)의 파라미터 수는?
3. S2에서 6장의 맵은 14×14다. 연결 수 5,880과 파라미터 수 12의 비가 490인 이유를 설명하라.

<details>
<summary>정답</summary>

1. 기울기는 \(0.5 \times 1 + (-0.25) \times 4 = 0.5 - 1 = -0.5\)다. 변화량은 \(-\eta \times (-0.5) = +0.1\)이다. 두 자리의 요구가 상쇄되어 값이 조금만 커진다.
2. 완전 연결은 \(100 \times 98 + 98 = 9{,}898\)개, 공유 없는 국소는 \(3 \times 98 + 98 = 392\)개, 공유하면 \(3 + 1 = 4\)개다.
3. 한 맵에 유닛이 \(14 \times 14 = 196\)개이고, 유닛마다 입력 4개와 바이어스를 쓰므로 연결이 5개다. 맵 하나의 연결은 980개이고 여섯 장이면 5,880개다. 학습 값은 맵마다 계수와 바이어스 하나씩 2개, 여섯 장이면 12개다. 5,880 / 12 = 490이다.

</details>

## 정리

가중치 공유는 같은 검출기를 여러 위치에 쓰도록 파라미터를 하나로 묶는 제약이다. 순방향은 같은 값을 쓰고, 역방향은 연결별 기울기를 합친다. 연결 수는 그대로이고 값의 수가 줄어서, LeNet-5의 연결 340,908개가 학습 파라미터 60,000개가 된다. 앞 층일수록 맵이 커서 줄어드는 폭이 크고, C5와 F6에서는 공유할 위치가 없다. 이 구조에서 이동 동변이 나오고, 거기에 좌표를 버리는 [서브샘플링](./subsampling.md)이 붙어 [LeNet-5](./lenet-5.md)가 된다.
