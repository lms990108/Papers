손으로 쓴 숫자를 맞히는 함수를 사람이 계수까지 적어 만들기는 어렵다. 픽셀이 수백 개이고, 그 픽셀을 어떻게 조합해야 7이 되는지를 규칙으로 다 적으면 예외가 남는다. 그래서 함수의 뼈대만 정해 두고, 그 안의 수 \(W\)는 비워 둔다. 뼈대, 곧 어떤 수가 어떤 수에 곱해지는지가 [신경망의 구조](./structure.md)다. \(W\)를 파라미터라고 부른다. 입력 \(Z\)와 \(W\)가 있으면 출력 \(Y = F(Z, W)\)가 나온다. \(W\)가 바뀌면 같은 그림이라도 출력이 바뀐다.

학습은 그 \(W\)를 데이터로 정하는 일이다. 입력과, 그 입력에서 나왔으면 하는 출력을 쌍으로 가지고 있다. 7이라는 그림에는 7이라는 답이 붙어 있다. \(W\)를 아무 값이나 넣으면 출력은 그 답과 다르다. [지도 학습](./supervised-learning.md)에서 그 차이를 오차라고 했다. 오차를 하나의 수로 만든 것이 손실 \(E\)다. 별점에서는 오차를 제곱한 값이 손실이고, 칸을 고르면 정답 칸 비율에 마이너스 로그를 붙인 값이 손실이다. 출력이 답과 멀면 \(E\)가 크고, 가까우면 작다. 학습 손실은 이런 쌍 여러 개에서 \(E\)를 평균한 값이다. \(W\)를 고쳐 이 평균을 줄이면, 적어도 가지고 있는 쌍에서는 출력이 답에 가까워진다.

새 그림에서도 맞기를 바라서 이 평균을 줄이는 것이다. 절차 자체는 학습에 넣은 쌍만 본다. 넣지 않은 입력에서 얼마나 틀리는지는 손실을 줄이는 도중에 자동으로 좋아지지 않는다. 그 차이는 [용량과 정칙화](./capacity.md)에서 다룬다.

:::tip[한눈에 보기]
경사하강법은 손실의 기울기를 구해, 손실이 줄어드는 쪽으로 파라미터를 조금씩 옮기는 절차다.

- 기울기는 파라미터를 조금 키웠을 때 손실이 변하는 비율이다. 갱신은 \(W \leftarrow W - \epsilon\, \partial E / \partial W\)로, 기울기를 더하지 않고 뺀다.
- 한 번에 옮기는 비율 \(\epsilon\)(학습률)이 너무 작으면 느리고, 너무 크면 최솟값을 넘어 왕복하거나 멀어진다.
- 기울기가 0인 점에서 멈추지만, 그 점이 가장 낮은 곳이라는 보장은 없다.

앞에서 빈칸의 자리를 정하는 [신경망의 구조](./structure.md)를 봤다. 뒤에서는 표본 하나로 고치는 [확률적 경사하강법](./sgd.md)과, 층이 여럿일 때 기울기를 구하는 [역전파](./backpropagation.md)를 본다.
:::

기울기가 양수면 오른쪽으로 갈수록 손실이 커진다. 손실을 줄이려면 왼쪽으로 가야 한다. 기울기가 음수면 오른쪽으로 갈수록 손실이 작아진다. 그때는 오른쪽으로 간다. 그래서 갱신은 기울기를 더하지 않고 뺀다. 올라가는 방향의 반대로 움직인다. 이 절차를 경사하강법이라고 한다. gradient descent와 같은 말이다.

수로는 이렇게 쓴다. \(w\)를 \(\delta\)만큼만 키웠을 때 손실이 얼마나 변하는지를 \(\delta\)로 나눈 값이, \(\delta\)를 0에 가깝게 보낸 극한이다.

\[
\frac{dE}{dw} = \lim_{\delta \to 0} \frac{E(w+\delta) - E(w)}{\delta}
\]

파라미터가 여러 개면 이 변화율을 파라미터마다 하나씩 구한다. \(w_1\)만 조금 바꿨을 때의 변화율, \(w_2\)만 조금 바꿨을 때의 변화율. 그 수의 묶음이 기울기 \(\partial E / \partial W\)다. 각 성분의 부호가 그 파라미터를 키울지 줄일지를 정하고, 절댓값이 그 방향에서 손실이 얼마나 급한지를 정한다.

곡선이 매끄러워 이 극한이 거의 모든 곳에서 존재하면, 파라미터를 이리저리 넣어 보며 손실이 줄어드는 곳을 찾을 필요가 없다. 지금 위치의 기울기만으로 어느 쪽이 내리막인지 알 수 있다. 파라미터가 수만 개면 넣어 보는 조합은 감당이 되지 않으므로, 학습이 성립하려면 이 매끄러움이 필요하다. 함수를 단계로 나눈 것이 [층](./layer.md)이다. 층이 여러 개일 때 이 변화율을 출력에서부터 앞으로 계산하는 절차가 [역전파](./backpropagation.md)다.

극한이 기울기에 가까워지는 모습을 \(E(w) = (w - 3)^2\), \(w = 0\)에서 보자. \(E(0) = 9\)이고 \(E(\delta) = (\delta - 3)^2\)이므로 변화율은 \(\dfrac{(\delta - 3)^2 - 9}{\delta} = \delta - 6\)이다. \(\delta\)를 줄일수록 -6에 붙는다.

```python
def E(w):
    return (w - 3) ** 2

w = 0.0
for delta in (1.0, 0.1, 0.01, 0.001, 0.000001):
    slope = (E(w + delta) - E(w)) / delta
    print(f"delta={delta:<8} 변화율={slope:.6f}")
```

```text
delta=1.0      변화율=-5.000000
delta=0.1      변화율=-5.900000
delta=0.01     변화율=-5.990000
delta=0.001    변화율=-5.999000
delta=1e-06    변화율=-5.999999
```

식으로 구한 기울기 \(2(w - 3)\)이 \(w = 0\)에서 -6인 것과 같다. 이렇게 파라미터를 하나씩 흔들어 구하면 파라미터가 수만 개일 때 너무 느리다. 그래서 기울기는 [역전파](./backpropagation.md)로 구하고, 이 수치 방법은 구한 기울기가 맞는지 검산하는 데만 쓴다.

## 계산 예

맞는 파라미터가 3이고, 손실을 지금 값과 3의 차이 제곱으로 두었다고 하자. \(E(w) = (w - 3)^2\)이다. \(w = 3\)이면 손실은 0이고, 멀어질수록 커진다. 시작은 \(w = 0\), 한 번에 움직이는 비율인 학습률은 \(\epsilon = 0.1\)이다.

이 곡선의 기울기는 \(2(w - 3)\)이다. \(w = 0\)은 3보다 왼쪽이라 기울기가 \(2(0 - 3) = -6\)이다. 음수이므로 오른쪽으로 가야 손실이 줄어든다.

\[
w \leftarrow 0 - 0.1 \times (-6) = 0.6
\]

0.6에서도 아직 3의 왼쪽이다. 기울기는 \(2(0.6 - 3) = -4.8\)이고, 다음은 \(0.6 - 0.1 \times (-4.8) = 1.08\)이다. 3에 가까워지지만 한 번의 갱신으로 도착하지는 않는다.

같은 계산을 여덟 번 이어 보면 이렇다. 갱신 한 번은 \(w - 3\)에 \(1 - 2\epsilon = 0.8\)을 곱하는 일이다. \(w - 3\)이 -3, -2.4, -1.92로 줄어드는 것이 아래 표의 \(w\)와 같다.

```python
def E(w):
    return (w - 3) ** 2

def grad(w):
    return 2 * (w - 3)

w, eps = 0.0, 0.1
print("t     w      기울기    손실")
for t in range(9):
    print(f"{t}  {w:6.3f}  {grad(w):7.3f}  {E(w):7.3f}")
    w = w - eps * grad(w)
```

```text
t     w      기울기    손실
0   0.000   -6.000    9.000
1   0.600   -4.800    5.760
2   1.080   -3.840    3.686
3   1.464   -3.072    2.359
4   1.771   -2.458    1.510
5   2.017   -1.966    0.966
6   2.214   -1.573    0.618
7   2.371   -1.258    0.396
8   2.497   -1.007    0.253
```

기울기가 줄어드니 이동량 \(\epsilon \times\)기울기도 0.6, 0.48, 0.384로 줄어든다. 학습률은 그대로인데 걸음이 짧아지는 이유다. 손실은 갱신마다 줄어든다.

## 학습률에 따른 차이

이 곡선에서 \(w_{\text{새}} - 3 = (1 - 2\epsilon)(w - 3)\)이다. 갱신마다 거리 \(w - 3\)에 \(1 - 2\epsilon\)이 곱해진다. 학습률 다섯 개로 다섯 번씩 가 보자.

| \(\epsilon\) | \(1 - 2\epsilon\) | 움직임 |
| --- | --- | --- |
| 0.01 | 0.98 | 아주 천천히 간다 |
| 0.1 | 0.8 | 한쪽에서 3에 다가간다 |
| 0.5 | 0 | 한 번에 3에 도착한다 |
| 1.0 | -1 | 0과 6 사이를 왕복한다 |
| 1.1 | -1.2 | 왕복하며 매번 멀어진다 |

```python
def grad(w):
    return 2 * (w - 3)

for eps in (0.01, 0.1, 0.5, 1.0, 1.1):
    w = 0.0
    path = [w]
    for _ in range(5):
        w = w - eps * grad(w)
        path.append(round(w, 3))
    print(f"eps={eps:<4}", path)
```

```text
eps=0.01 [0.0, 0.06, 0.119, 0.176, 0.233, 0.288]
eps=0.1  [0.0, 0.6, 1.08, 1.464, 1.771, 2.017]
eps=0.5  [0.0, 3.0, 3.0, 3.0, 3.0, 3.0]
eps=1.0  [0.0, 6.0, 0.0, 6.0, 0.0, 6.0]
eps=1.1  [0.0, 6.6, -1.32, 8.184, -3.221, 10.465]
```

\(0 < \epsilon < 1\)이면 \(1 - 2\epsilon\)의 크기가 1보다 작아서, 3을 지나쳐도 왕복하며 3에 모인다. \(\epsilon = 1\)이면 6과 0을 오가며 손실이 9에서 변하지 않는다. 그림의 빈 점 \(w = 6\)이 이 왕복의 첫 걸음이다. 1을 넘으면 손실이 커진다. 기울기 방향은 \(\epsilon = 1\)에서도 맞았고, 틀린 것은 얼마나 갈지다. \(E = \tfrac{c}{2}(w - w^*)^2\)꼴이면 곱해지는 수가 \(1 - \epsilon c\)라서 \(0 < \epsilon < 2/c\)일 때 수렴한다. 곡선이 가파를수록 한계가 작다. \((w - 3)^2\)은 \(c = 2\)라 한계가 1이다.

## 파라미터가 둘일 때

한쪽은 가파르고 한쪽은 완만한 곡면을 보자.

\[
E(w_1, w_2) = (w_1 - 3)^2 + 10\,(w_2 - 1)^2
\]

기울기는 \((2(w_1 - 3),\ 20(w_2 - 1))\)이다. \(c\)는 \(w_1\) 쪽이 2, \(w_2\) 쪽이 20이라, 학습률의 한계가 \(w_1\) 쪽은 1이고 \(w_2\) 쪽은 0.1이다. 시작 \((0,\ 0)\)에서 \(\epsilon = 0.05\)이면 \(w_2\)는 \(1 - 20 \times 0.05 = 0\)이라 한 번에 1에 닿는다. \(\epsilon = 0.1\)이면 \(w_2\)가 0과 2를 왕복한다.

```python
def E(w1, w2):
    return (w1 - 3) ** 2 + 10 * (w2 - 1) ** 2

def grad(w1, w2):
    return 2 * (w1 - 3), 20 * (w2 - 1)

for eps in (0.05, 0.1):
    w1, w2 = 0.0, 0.0
    print("eps =", eps)
    for t in range(5):
        print(f"  t={t}  w1={w1:6.3f}  w2={w2:6.3f}  E={E(w1, w2):7.3f}")
        g1, g2 = grad(w1, w2)
        w1, w2 = w1 - eps * g1, w2 - eps * g2
```

```text
eps = 0.05
  t=0  w1= 0.000  w2= 0.000  E= 19.000
  t=1  w1= 0.300  w2= 1.000  E=  7.290
  t=2  w1= 0.570  w2= 1.000  E=  5.905
  t=3  w1= 0.813  w2= 1.000  E=  4.783
  t=4  w1= 1.032  w2= 1.000  E=  3.874
eps = 0.1
  t=0  w1= 0.000  w2= 0.000  E= 19.000
  t=1  w1= 0.600  w2= 2.000  E= 15.760
  t=2  w1= 1.080  w2= 0.000  E= 13.686
  t=3  w1= 1.464  w2= 2.000  E= 12.359
  t=4  w1= 1.771  w2= 0.000  E= 11.510
```

0.1로는 완만한 \(w_1\)이 0.8배씩 줄지만 가파른 \(w_2\)가 왕복한다. 0.05로 내리면 \(w_2\)는 해결되지만 \(w_1\)은 0.9배씩만 줄어서 네 번째 걸음 뒤에도 1.032에 있다. 파라미터마다 보폭을 나누는 이유는 [확률적 경사하강법](./sgd.md)에서 다시 나온다.

파라미터가 벡터이면 성분마다 같은 갱신을 한다.

\[
W \leftarrow W - \epsilon \frac{\partial E}{\partial W}
\]

\(\epsilon\)은 모든 성분에 같은 상수일 수도 있고, 성분마다 다른 값일 수도 있다. 손실을 표본 전체의 평균으로 만들지 않고 표본 하나의 기울기로 바로 갱신하는 방식은 [확률적 경사하강법](./sgd.md)이다.

## 신경망 한 걸음

[층](./layer.md)의 두 층 예를 한 번 갱신해 보자. 입력 \(x = 1\), 정답 \(t = 0\), \(w_1 = 0.5\), \(w_2 = 1\), \(h = \tanh(w_1 x)\), \(y = w_2 h\), 손실 \(E = (y - t)^2\)이다. [역전파](./backpropagation.md)에서 구한 기울기는 \(w_1\)이 약 0.727, \(w_2\)가 약 0.427이다. 학습률 0.1이면 \(w_1 \leftarrow 0.5 - 0.1 \times 0.727 \approx 0.427\), \(w_2 \leftarrow 1 - 0.1 \times 0.427 \approx 0.957\)이다. 아래 코드는 이 기울기를 위의 극한(\(\delta = 10^{-6}\))으로 검산하고 한 번 갱신한다.

```python
import math

x, t = 1.0, 0.0                       # 입력과 정답
w1, w2, eps = 0.5, 1.0, 0.1

def loss(w1, w2):
    return (w2 * math.tanh(w1 * x) - t) ** 2

h = math.tanh(w1 * x)
y = w2 * h
g_w2 = 2 * (y - t) * h                          # 역전파로 구한 기울기
g_w1 = 2 * (y - t) * w2 * (1 - h ** 2) * x
d = 1e-6                                        # 아주 작은 델타로 확인
n_w1 = (loss(w1 + d, w2) - loss(w1, w2)) / d
n_w2 = (loss(w1, w2 + d) - loss(w1, w2)) / d
print(f"w1 기울기 {g_w1:.4f} (수치 {n_w1:.4f})")
print(f"w2 기울기 {g_w2:.4f} (수치 {n_w2:.4f})")
print(f"갱신 전 손실 {loss(w1, w2):.4f}")
w1, w2 = w1 - eps * g_w1, w2 - eps * g_w2
print(f"갱신 후 w1={w1:.4f} w2={w2:.4f} 손실 {loss(w1, w2):.4f}")
```

```text
w1 기울기 0.7269 (수치 0.7269)
w2 기울기 0.4271 (수치 0.4271)
갱신 전 손실 0.2136
갱신 후 w1=0.4273 w2=0.9573 손실 0.1489
```

식과 수치가 소수점 넷째 자리까지 같고, 손실은 0.2136에서 0.1489로 내려간다.

## 국소 최솟값

기울기가 0이면, 어느 파라미터를 조금 움직여도 손실이 바로 줄어들지 않는다. 그 점이 전체에서 가장 낮은 곳이라는 뜻은 아니다. 다른 \(W\)에서는 손실이 더 작을 수 있다. 지금 위치 근처만 보면 더 이상 내리막이 없어서, 이 갱신은 거기서 멈춘다. 그런 점을 국소 최솟값이라고 한다.

다층망에서 이 국소 최솟값이 실무에서 자주 치명적이지 않다는 관찰은 오래됐지만, 이론은 아직 열려 있다. 많이 드는 추측은, 망이 과제보다 크면 파라미터 공간에 남는 차원이 있어서 도달할 수 없는 영역이 줄어든다는 것이다. 확정된 정리로 읽으면 안 된다.

기울기가 0인 점이 가장 낮은 곳이 아닌 경우를 둘 보자. 하나는 골짜기가 둘인 곡선이다. \(E(w) = w^4 - 3w^2 + w\)는 기울기 \(4w^3 - 6w + 1\)이 0인 점이 약 -1.301, 0.170, 1.131이고, 0.170은 두 골짜기 사이의 봉우리다. 같은 학습률로도 시작에 따라 도착하는 골짜기가 다르다. 다른 하나는 안장점이다. \(E = w_1^2 - w_2^2\)의 원점은 기울기가 \((0,\ 0)\)이지만, \(w_1\) 방향으로는 손실이 오르고 \(w_2\) 방향으로는 내린다.

```python
def E(w):                          # w**4 - 3*w**2 + w
    return w ** 4 - 3 * w ** 2 + w

def grad(w):
    return 4 * w ** 3 - 6 * w + 1

for start in (2.0, -2.0):
    w = start
    for _ in range(200):
        w -= 0.01 * grad(w)
    print(f"시작 {start:5.1f} -> w={w:6.3f}  손실={E(w):6.3f}  기울기={grad(w):.4f}")

# 기울기가 0인 점이 최솟값이 아닌 예: E = w1**2 - w2**2, 원점
f = lambda w1, w2: w1 ** 2 - w2 ** 2
print("원점:", f(0, 0), " w1 쪽 0.1:", round(f(0.1, 0), 3), " w2 쪽 0.1:", round(f(0, 0.1), 3))
```

```text
시작   2.0 -> w= 1.131  손실=-1.070  기울기=0.0000
시작  -2.0 -> w=-1.301  손실=-3.514  기울기=-0.0000
원점: 0  w1 쪽 0.1: 0.01  w2 쪽 0.1: -0.01
```

시작 2.0은 손실 -1.070인 얕은 골짜기에, 시작 -2.0은 -3.514인 깊은 골짜기에 닿는다. 기울기만 보는 이 절차는 어느 쪽이 깊은지 모른다.

## 자주 헷갈리는 점

기울기를 빼는 이유가 헷갈리기 쉽다. 기울기는 손실이 올라가는 방향이므로, 줄이려면 반대로 간다. \(w = 0\)에서 기울기가 -6이면 오른쪽으로 갈수록 손실이 준다는 뜻이고, \(0 - 0.1 \times (-6) = 0.6\)으로 오른쪽에 간다.

학습률은 작을수록 안전하고 좋다고 생각하기 쉽지만, 작으면 느릴 뿐이다. \(\epsilon = 0.01\)은 다섯 번 갱신해도 \(w = 0.288\)이다. 한계 안에서는 큰 값이 빠르다. 이 곡선에서는 0.5가 가장 빨랐다.

손실이 갱신마다 항상 줄어든다고 생각하기 쉽지만, 학습률이 한계를 넘으면 늘어난다. \(\epsilon = 1.1\)에서 \(w\)는 6.6, -1.32, 8.184로 오가며 손실이 커진다.

경사하강법이 가장 낮은 곳을 찾는다고 생각하기 쉽지만, 지금 자리에서 내리막을 따라갈 뿐이다. 시작이 다르면 다른 골짜기에 도착한다. 학습 손실이 가장 낮은 곳이 새 입력에서 가장 잘 맞히는 곳이라는 보장도 없다.

## 직접 풀어 보기

**문제 1.** \(E(w) = (w - 3)^2\), 시작 \(w = 5\), 학습률 0.25일 때 두 번 갱신한 뒤의 \(w\)를 구해라.

**문제 2.** 같은 곡선에서 시작 \(w = 0\), 학습률 0.75일 때 두 번 갱신한 뒤의 \(w\)를 구해라. 3의 어느 쪽에 있는가.

**문제 3.** \(E(w) = 5(w - 2)^2\)이다. 학습률이 어떤 범위여야 \(w\)가 2에 모이는가.

<details>
<summary>정답</summary>

**1.** 기울기는 \(2(5 - 3) = 4\)이므로 \(w = 5 - 0.25 \times 4 = 4\)이다. 다시 기울기가 2이므로 \(w = 4 - 0.25 \times 2 = 3.5\)이다.

**2.** 첫 갱신은 \(0 - 0.75 \times (-6) = 4.5\)이다. 기울기가 \(2(4.5 - 3) = 3\)이므로 둘째는 \(4.5 - 0.75 \times 3 = 2.25\)이다. 3의 왼쪽이다. 3을 지나쳤다가 돌아와 다시 반대편에 있는 것이고, 곱해지는 수가 \(1 - 1.5 = -0.5\)라서 거리가 -3, 1.5, -0.75로 부호를 바꾸며 줄어든다.

**3.** 기울기가 \(10(w - 2)\)이므로 \(w_{\text{새}} - 2 = (1 - 10\epsilon)(w - 2)\)이다. \(|1 - 10\epsilon| < 1\)이면 되고, \(0 < \epsilon < 0.2\)이다. \(\epsilon = 0.2\)이면 -1이라 왕복한다.

</details>

## 정리

경사하강법은 손실의 기울기를 구해 반대 방향으로 \(\epsilon\)만큼 옮기는 절차다. 최솟값에 가까워지면 기울기가 작아져 걸음도 줄어든다. 학습률이 한계(곡선이 가파를수록 작다)보다 크면 왕복하거나 멀어지고, 축마다 가파른 정도가 다르면 한 학습률로 모두 맞추기 어렵다. 기울기가 0인 점은 국소 최솟값이나 안장점일 수 있어서 시작점에 따라 결과가 달라진다. 표본 하나나 몇 개로 갱신하는 방법이 [확률적 경사하강법](./sgd.md)이고, 층이 여럿일 때 기울기를 구하는 절차가 [역전파](./backpropagation.md)다.
