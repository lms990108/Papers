[순환 신경망](./rnn.md)의 상태는 매 자리 가중치가 곱해진 뒤 \(\tanh\)를 지난다. 긴 문장에서 앞 단어의 수가 사라진다. 장단기 메모리는 상태 옆에 통로를 하나 더 두고, 그 통로에서는 곱하는 값이 0과 1 사이의 문만 연다. Long Short-Term Memory, LSTM과 같은 말이다.

:::tip[한눈에 보기]
장단기 메모리는 숨은 상태 \(h\) 옆에 통로 \(c\)를 두고, 세 개의 문(잊는 문, 넣는 문, 내보내는 문)으로 통로를 읽고 쓰는 순환 신경망이다.

- 통로는 행렬을 통째로 곱하지 않고 "이전 값에 문을 곱한 것 + 새 내용"으로 갱신된다. \(c_t = f_t c_{t-1} + i_t g_t\)에서 \(f_t\)가 1에 가까우면 앞의 수가 그대로 남는다.
- 문은 시그모이드가 낸 0과 1 사이의 수이고, 넣을 내용 \(g\)는 \(\tanh\)가 낸 \(-1\)과 1 사이의 수다. 이 넷이 각자의 가중치를 가진다.
- 통로를 따라가는 기울기는 \(f\)를 곱한 만큼만 줄어, 순환 신경망의 \(w^k\)보다 훨씬 천천히 사라진다.

먼저 읽을 것: [순환 신경망](./rnn.md), [기울기 소실](./gradient-vanishing.md). 이어지는 것: [어텐션](./attention.md), [트랜스포머](./transformer.md).
:::

## 왜 통로를 따로 두는가

[순환 신경망](./rnn.md)에서 앞 토큰의 기울기는 한 자리 거슬러 갈 때마다 \(w(1-h^2)\)가 곱해졌다. \(w = 0.5\)이면 열 자리 앞은 약 0.001배다. 곱하는 값을 1에 가깝게 학습할 수는 있지만, 같은 행렬이 "지금 토큰을 어떻게 섞을지"와 "과거를 얼마나 남길지"를 동시에 정해야 해서 어렵다. 장단기 메모리는 이 둘을 갈라 놓았다. 과거를 남기는 일은 통로 \(c\)와 잊는 문이 맡고, 지금 토큰을 해석하는 일은 넣을 내용 \(g\)가 맡는다.

처음 제안된 1997년의 장단기 메모리에는 잊는 문이 없었고, 통로에 넣는 문과 내보내는 문만 있었다. 잊는 문은 그 뒤에 추가되어 지금은 기본 구성이 되었다. 이 페이지는 잊는 문까지 포함한 형태를 다룬다.

## 통로 갱신

통로의 값을 \(c\)라고 하자. 잊는 문 \(f\), 넣는 문 \(i\), 넣을 내용 \(g\)가 있으면 다음 통로는 이렇게 갱신한다.

\[
c_t = f_t c_{t-1} + i_t g_t
\]

\(f\), \(i\)는 시그모이드라 0과 1 사이다. \(f = 1\), \(i = 0\)이면 \(c\)는 이전 값 그대로다. 앞 단어가 남는다. \(f = 0\)이면 이전 통로가 지워지고, \(i\)와 \(g\)만 들어온다.

오늘을 읽고 통로가 2였다고 하자. 다음 자리에서 \(f = 0.5\), \(i = 1\), \(g = 0\)이면 \(c = 0.5 \times 2 + 0 = 1\)이다. 절반이 남는다. \(f = 1\), \(i = 0\)이면 날씨를 읽어도 통로는 2다. 순환 신경망처럼 0.5를 상태 전부에 행렬로 곱하는 것과 달리, 문을 1로 두면 그 자리의 기울기가 통로를 따라 1로 앞으로 간다.

밖으로 내보낼 때도 문이 하나 더 있다. 그 문이 \(o\)이면 숨은 상태는 \(h = o \tanh(c)\)다. 문은 잊는 문, 넣는 문, 내보내는 문 세 개이고, 넣을 내용 \(g\)는 문과 따로 자기 가중치를 가진다. \(c = 1\), \(o = 1\)이면 \(h = \tanh(1) \approx 0.762\)다. [순환 신경망](./rnn.md)이 오늘을 읽고 만든 상태의 첫 칸과 같은 수다.

## 문을 닫으면

통로가 2인 자리에서 \(f = 0\), \(i = 1\), \(g = 1\)이면 \(c = 0 \times 2 + 1 \times 1 = 1\)이다. 오늘에서 온 2는 사라진다. \(o = 1\)이면 \(h = \tanh(1) \approx 0.762\)라, 통로에 남은 1만 밖으로 나간다. \(f = 0.5\)일 때 남기던 절반과 달리, 잊는 문을 닫으면 앞 단어의 계수가 0이다.

\(f = 1\), \(i = 0\)이면 \(c = 2\)가 유지된다. 여기에 \(o = 0\)을 두면 \(h = 0\)이다. 통로 안에는 2가 있는데 밖으로는 나가지 않는다. 다음 자리에서 \(o = 1\)로 열면 \(h = \tanh(2) \approx 0.964\)다. 순환 신경망은 상태를 매 자리 \(\tanh\)와 0.5로 통과시켜, 이렇게 닫아 두었다가 나중에 여는 칸이 없다.

## 한 스텝 전체 계산

위에서는 문의 값을 정해 놓고 썼다. 실제로는 문의 값도 직전 상태 \(h_{t-1}\)과 지금 토큰 \(x_t\)에서 계산된다. 네 가지(\(f\), \(i\), \(g\), \(o\))가 각자 \(W\), \(U\), \(b\)를 가진다.

\[
\begin{aligned}
f_t &= \sigma(W_f x_t + U_f h_{t-1} + b_f), \quad i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \\
g_t &= \tanh(W_g x_t + U_g h_{t-1} + b_g), \quad o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \\
c_t &= f_t c_{t-1} + i_t g_t, \quad h_t = o_t \tanh(c_t)
\end{aligned}
\]

\(\sigma\)는 시그모이드 \(1/(1+e^{-z})\)다. 순환 신경망의 한 줄 \(h_t = \tanh(W_h h_{t-1} + W_x x_t)\)가 네 줄로 늘어난 셈이라, 파라미터 수도 네 배다. 토큰 목록과 상태의 길이가 모두 \(d\)이면 바이어스까지 \(4(2d^2 + d)\)개다.

상태의 크기를 1로 하면 손으로 따라갈 수 있다. 직전 \(h_{t-1} = 0.5\), \(c_{t-1} = 2\), 지금 입력 \(x_t = 1\)이고, 가중치는 이렇게 둔다. 표의 숫자는 \((W,\ U,\ b)\)다.

| 문 | \((W,\ U,\ b)\) | \(z = W x_t + U h_{t-1} + b\) | 활성화 | 값 |
| --- | --- | --- | --- | --- |
| \(f\) | \((1,\ 1,\ 0)\) | \(1 + 0.5 + 0 = 1.5\) | \(\sigma(1.5)\) | 0.8176 |
| \(i\) | \((2,\ 0,\ -1)\) | \(2 + 0 - 1 = 1\) | \(\sigma(1)\) | 0.7311 |
| \(g\) | \((1,\ -1,\ 0)\) | \(1 - 0.5 + 0 = 0.5\) | \(\tanh(0.5)\) | 0.4621 |
| \(o\) | \((0,\ 2,\ 0)\) | \(0 + 1 + 0 = 1\) | \(\sigma(1)\) | 0.7311 |

통로는 \(c_t = 0.8176 \times 2 + 0.7311 \times 0.4621 = 1.6352 + 0.3379 \approx 1.973\)이다. 이전 통로 2에서 82%가 남고, 새 내용이 0.338 더해졌다. 내보내는 값은 \(\tanh(1.973) \approx 0.9621\)이므로 \(h_t = 0.7311 \times 0.9621 \approx 0.7033\)이다.

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

# 상태 크기 1 인 LSTM 한 스텝. 문마다 (W: x 에 곱, U: h 에 곱, b: 바이어스)
P = {"f": (1.0, 1.0, 0.0), "i": (2.0, 0.0, -1.0),
     "g": (1.0, -1.0, 0.0), "o": (0.0, 2.0, 0.0)}

def step(x, h_prev, c_prev):
    z = {k: W * x + U * h_prev + b for k, (W, U, b) in P.items()}
    f, i, o = sigmoid(z["f"]), sigmoid(z["i"]), sigmoid(z["o"])
    g = math.tanh(z["g"])
    c = f * c_prev + i * g
    h = o * math.tanh(c)
    print("z =", {k: round(v, 3) for k, v in z.items()})
    print("f, i, g, o =", [round(v, 4) for v in (f, i, g, o)])
    print("c =", round(c, 4), " tanh(c) =", round(math.tanh(c), 4), " h =", round(h, 4))
    return h, c

h, c = step(x=1.0, h_prev=0.5, c_prev=2.0)
print("--- 다음 자리, x = 0")
h, c = step(x=0.0, h_prev=h, c_prev=c)
```

```text
z = {'f': 1.5, 'i': 1.0, 'g': 0.5, 'o': 1.0}
f, i, g, o = [0.8176, 0.7311, 0.4621, 0.7311]
c = 1.973  tanh(c) = 0.9621  h = 0.7033
--- 다음 자리, x = 0
z = {'f': 0.703, 'i': -1.0, 'g': -0.703, 'o': 1.407}
f, i, g, o = [0.6689, 0.2689, -0.6065, 0.8032]
c = 1.1567  tanh(c) = 0.82  h = 0.6586
```

둘째 자리에서는 입력이 0인데도 \(h\)가 바뀌었다. 직전 \(h\)가 문에 들어가기 때문이다. \(g\)는 \(-0.6065\)로 음수라, 통로에 음수가 더해져 \(c\)가 1.973에서 1.157로 줄었다. 넣을 내용은 \(\tanh\)가 낸 값이라 음수도 된다.

## 통로를 따라가는 기울기

\(c_t = f_t c_{t-1} + i_t g_t\)를 \(c_{t-1}\)로 미분하면, 통로를 직접 지나는 몫은 \(f_t\)다. \(c_{t-1}\)이 \(h_{t-1}\)을 거쳐 문에 영향을 주는 간접 경로도 있지만, 앞 토큰에서 오는 주된 길은 이 곱이다. \(T\)자리를 거슬러 가면 기울기는 대략 \(f\)를 \(T\)번 곱한 값이다. [순환 신경망](./rnn.md)에서는 \(w(1-h^2)\)가 곱해졌다. 같은 스무 자리를 비교해 보자.

```python
# 통로를 따라가는 기울기: dc_T / dc_0 = f 를 T 번 곱한 값
for f in (0.5, 0.9, 0.99):
    print("f =", f, " 20 자리 뒤:", round(f ** 20, 6))
```

```text
f = 0.5  20 자리 뒤: 1e-06
f = 0.9  20 자리 뒤: 0.121577
f = 0.99  20 자리 뒤: 0.817907
```

\(f\)가 0.5이면 스무 자리 뒤에는 약 0.000001로 사라진다. 그러나 문이 0.9나 0.99를 낼 수 있으면 신호가 살아남는다. 순환 신경망은 \(\tanh\)의 기울기(1 이하)가 항상 함께 곱해져 이 값보다 더 빨리 줄어든다. 장단기 메모리에서는 필요할 때 \(f\)가 1 근처가 되도록 학습한다.

## 자주 헷갈리는 점

장단기 메모리가 기울기 소실을 없앤다고 생각하기 쉽지만, 줄일 뿐이다. 통로에서 \(f\)가 1보다 작으면 거리에 따라 곱이 줄고, 위 코드에서 \(f = 0.9\)는 스무 자리에 0.12배다. 다만 \(f\)를 1에 가깝게 학습할 수 있어서 순환 신경망보다 훨씬 먼 거리를 잇는다.

통로 \(c\)와 숨은 상태 \(h\)가 같은 것이라고 생각하기 쉽지만 다르다. \(c = 2\), \(o = 0\)이면 \(h = 0\)이다. \(c\)는 안에 쌓아 두는 값이고, \(h\)는 \(o\)가 열어 준 만큼 밖으로 내보내는 값이다. 다음 층과 다음 자리의 문에 쓰이는 것은 \(h\)이고, \(c\)는 오직 통로로만 이어진다.

문이 0 또는 1의 스위치라고 생각하기 쉽지만, 시그모이드가 낸 연속된 수다. 표의 \(f\)는 0.8176이었다. 완전히 닫히거나 열리는 일은 거의 없고, 학습이 이 수를 움직인다.

넣을 내용 \(g\)도 문의 하나라고 생각하기 쉽지만, 문은 곱해지는 비율이고 \(g\)는 더해지는 내용이다. \(g\)는 \(\tanh\)를 쓰므로 \(-1\)과 1 사이이고 음수도 된다. 문은 \(f\), \(i\), \(o\) 셋이다.

## 변형과 한계

문을 둘로 줄인 것이 게이트 순환 유닛이다. gated recurrent unit, GRU와 같은 말이다. 2014년에 제안되었다. 문은 갱신 문 \(z\)와 리셋 문 \(r\)이다. 리셋 문은 새 후보를 만들 때 이전 상태를 얼마나 볼지 정하고, 갱신 문은 이전 상태와 새 후보를 섞는 비율을 정한다. 갱신 문을 \(z\)라고 하면 상태는 \((1 - z) \times\) 이전 상태에 \(z \times\) 새 후보를 더한 꼴이다. 이전 상태가 1, 새 후보가 0.5, \(z = 0.25\)이면 \(0.75 \times 1 + 0.25 \times 0.5 = 0.875\)다. \(z = 0\)이면 이 페이지의 \(f = 1\), \(i = 0\)처럼 이전이 남고, \(z = 1\)이면 새 후보로 바뀐다. 통로와 숨은 상태를 따로 두지 않는다. 라이브러리에 따라 \(z\)가 새 후보에 곱해지는지, 이전 상태에 곱해지는지의 규약이 다르므로 쓰기 전에 확인한다.

장단기 메모리를 여러 층 쌓거나, 양방향으로 두 개를 돌려 이어 붙이기도 한다. 한 자리를 계산하려면 직전 자리가 끝나야 하는 점은 순환 신경망과 같아서 자리를 병렬로 처리하지 못한다. 문장 순서를 한 칸씩 밟는 점도 같다. 자리를 한꺼번에 보고 섞는 [트랜스포머](./transformer.md)는 이 통로 대신 잔차 연결과 어텐션을 쓴다.

## 직접 풀어 보기

1. 통로 \(c_{t-1} = 3\), \(f = 0.5\), \(i = 0.5\), \(g = 0.6\), \(o = 1\)이다. \(c_t\)와 \(h_t\)를 구하라. (\(\tanh(1.8) \approx 0.947\))

2. \(f = 1\), \(i = 0\)으로 \(c = 2\)를 세 자리 유지하고, 마지막 자리에서만 \(o = 1\)로 연다. 세 자리의 \(h\)는? (\(\tanh(2) \approx 0.964\))

3. 한 층의 크기가 \(d = 3\)일 때(입력 길이도 3), 순환 신경망과 장단기 메모리의 바이어스 포함 파라미터 수를 각각 구하라.

<details>
<summary>정답</summary>

1. \(c_t = 0.5 \times 3 + 0.5 \times 0.6 = 1.5 + 0.3 = 1.8\). \(h_t = 1 \times \tanh(1.8) \approx 0.947\).

2. 앞 두 자리는 \(o = 0\)이라 \(h = 0\), 마지막 자리는 \(h = 1 \times \tanh(2) \approx 0.964\). 통로는 세 자리 내내 2다.

3. 순환 신경망은 \(d(d + d) + d = 3 \times 6 + 3 = 21\)개. 장단기 메모리는 이것의 네 배인 \(4 \times 21 = 84\)개다.

</details>

## 정리

장단기 메모리는 통로 \(c\)를 덧셈으로 갱신하고, 잊는 문 \(f\)와 넣는 문 \(i\)로 과거를 남길지, 새 내용을 넣을지 정한다. 한 스텝은 네 가지 값을 계산한 뒤 \(c_t = f_t c_{t-1} + i_t g_t\), \(h_t = o_t \tanh(c_t)\)로 끝난다. 통로를 지나는 기울기는 \(f\)만 곱해지므로 순환 신경망보다 훨씬 멀리 간다. 그래도 자리를 순서대로 밟아야 하는 한계는 남고, 이를 푸는 것이 [어텐션](./attention.md)이다.
