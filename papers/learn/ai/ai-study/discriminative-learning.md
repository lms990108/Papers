그림 하나가 3인지 8인지를 맞힐 때, 모델을 만드는 질문이 두 가지다.

하나는 “3이라면 어떤 픽셀이 검게 되고, 8이라면 어떤 픽셀이 검게 되는가”이다. 클래스마다 입력이 생기는 방식을 만든 뒤, 지금 그림이 어느 쪽에 더 맞는지를 본다. 이것을 생성 모델이라고 한다. 음성의 [은닉 마르코프 모델](./hmm.md)이 전통적으로 이쪽이다. 상태가 주어지면 그 상태가 소리를 어떻게 내는지를 확률로 적는다.

다른 질문은 “이 픽셀들이 주어졌을 때 3과 8을 어디서 가를 것인가”이다. 잉크가 어떻게 생기는지 전부는 필요 없고, 둘을 가르는 경계만 맞추면 된다. 입력 분포가 가우스인지도 가정하지 않는다. 이것을 판별 학습이라고 한다.

:::tip[한눈에 보기]
**정의**: 판별 학습(discriminative learning)은 입력이 어떻게 생겼는지가 아니라, 입력이 주어졌을 때 정답과 오답을 어떻게 가르는지를 직접 학습하는 방식이다.

- 정답의 벌점만 줄이면, 입력을 무시하고 출력을 전부 같게 만드는 붕괴가 손실의 최솟값이 될 수 있다.
- 정답 벌점은 내리고 오답 벌점은 올리는 손실이면 붕괴가 최솟값이 되지 않는다.
- 문자열에서는 정답 경로의 비용에서 모든 경로의 비용을 뺀 차이를 줄이며, 이 값은 0 이상이다.
- 다음 토큰의 교차엔트로피도 같은 형태이고, 소프트맥스의 나눗셈이 붕괴를 막는다.

이전에 알아야 할 것: [소프트맥스](./softmax.md), [RBF](./rbf.md), [은닉 마르코프 모델](./hmm.md). 다음에 이어지는 것: [다음 토큰](./next-token.md), [비터비](./viterbi.md), [전방 알고리즘](./forward-algorithm.md).
:::

## 생성과 판별

왼쪽은 클래스마다 그림이 어떻게 생겼는지를 만든다. 3의 구름과 8의 구름을 각각 그려 둔 뒤, 새 점이 어느 구름에 더 가까운지를 본다. 오른쪽은 구름의 모양은 두지 않고, 둘을 가르는 선만 맞춘다. 선에서 멀리 떨어진 3이 어떻게 생겼는지는 손실에 들어가지 않는다.

두 방식은 같은 질문 \(P(\text{클래스} \mid \text{입력})\)에 다른 길로 간다. 생성 쪽은 클래스별로 \(P(\text{입력} \mid \text{클래스})\)를 만들어 두고, 베이즈 정리로 \(P(\text{클래스} \mid \text{입력}) \propto P(\text{입력} \mid \text{클래스}) P(\text{클래스})\)를 계산한다. 판별 쪽은 왼쪽 항을 처음부터 직접 모델로 둔다. 예를 들어 3의 입력이 평균 \(-1\), 8의 입력이 평균 \(+1\)이고 분산이 같은 가우스라고 하면, 생성 모델이 계산한 사후확률은 입력의 일차식을 시그모이드에 넣은 모양이 된다. 판별 학습은 그 가우스를 거치지 않고 일차식의 계수를 바로 맞춘다. 같은 모양을 [로지스틱 회귀](./logistic-regression.md)가 쓴다. 클래스 입력의 모양이 가우스가 아니어도 경계만 맞으면 되므로, 가정이 틀렸을 때 생성 쪽보다 덜 흔들릴 수 있다. 대신 입력을 새로 만들어 내지는 못한다.

클래스 조건부 확률을 만드는 대신 정답 해석과 오답 해석의 비용 차이를 줄이면 판별 학습이 된다. 아래 절들이 그 차이가 왜 필요한지와 어떤 모양인지를 차례로 본다.

## 정답 벌점만 줄일 때

가장 단순한 손실은 정답 클래스의 벌점만 평균하는 것이다. 글자 인식에서 정답 클래스의 [RBF](./rbf.md) 거리만 줄이는 식이 그것이다. 많은 경우에는 된다. 빠진 것이 있다. 그 손실은 “정답을 맞게 읽어라”와 “무엇을 넣어도 출력을 작게 만들어라”를 구분하지 못한다.

기준 벡터까지 같이 학습하면 손실이 0이 되는 해가 있다. 모든 기준 벡터가 한 벡터로 모이고, 앞층은 그림을 무시하고 항상 그 벡터를 낸다. 정답이 3이든 8이든 거리는 0이다. 분류는 하지 않는다.

출력층이 시그모이드이고 손실이 정답 출력을 작게 만드는 것뿐이어도 비슷하다. 모든 출력을 동시에 작게 만드는 상수 함수가 그 손실의 최솟값이 될 수 있다. 맞혀서가 아니라, 출력을 전부 죽인 것이다.

이 붕괴를 작은 모델로 직접 본다. 입력 \(x\)는 3이 \(-1.2, -0.8\), 8이 \(0.8, 1.2\)이다. 앞층은 \(z = ax\)로 입력을 수 하나로 만들고, 기준은 \(p_0\)(3)과 \(p_1\)(8)이다. 클래스 \(c\)의 벌점은 RBF 거리의 제곱 \((z - p_c)^2\)이다. 두 손실을 같은 출발점 \(a = 1\), \(p_0 = -0.5\), \(p_1 = 0.5\)에서 경사하강법으로 줄인다. 하나는 정답 벌점만 쓰고, 하나는 정답 벌점에 \(\log \sum_c e^{-(z - p_c)^2}\)를 더한 것이다. 뒤의 항은 오답까지 포함한 모든 벌점의 합이다. 기울기는 수치 미분으로 구한다.

```python
import math

data = [(-1.2, 0), (-0.8, 0), (0.8, 1), (1.2, 1)]      # (픽셀 값 x, 클래스: 0=3, 1=8)

def dists(P, x):
    a, p0, p1 = P
    z = a * x                                           # 앞층: 입력을 1차원 특징으로
    return [(z - p0) ** 2, (z - p1) ** 2]               # RBF 거리 제곱

def loss(P, discriminative):
    total = 0.0
    for x, y in data:
        d = dists(P, x)
        total += d[y]                                   # 정답 벌점
        if discriminative:                              # 전체 벌점의 합 -log(sum exp(-d)) 를 빼는 것과 같다
            total += math.log(sum(math.exp(-v) for v in d))
    return total / len(data)

def train(discriminative, eps=0.05, steps=3000, h=1e-6):
    P = [1.0, -0.5, 0.5]
    for _ in range(steps):
        g = []
        for i in range(3):
            up = P[:]; up[i] += h
            dn = P[:]; dn[i] -= h
            g.append((loss(up, discriminative) - loss(dn, discriminative)) / (2 * h))
        P = [p - eps * gi for p, gi in zip(P, g)]
    return P

for name, flag in [("정답 벌점만", False), ("정답 - 전체", True)]:
    P = train(flag)
    gap = sum(abs(dists(P, x)[0] - dists(P, x)[1]) for x, _ in data) / len(data)
    print(f"{name}: a={P[0]:.4f} p0={P[1]:.4f} p1={P[2]:.4f} "
          f"손실={loss(P, flag):.4f} 두 거리의 차={gap:.4f}")
```

```text
정답 벌점만: a=0.0128 p0=-0.0131 p1=0.0131 손실=0.0000 두 거리의 차=0.0007
정답 - 전체: a=1.9228 p0=-1.2646 p1=1.2646 손실=0.0002 두 거리의 차=9.7265
```

정답 벌점만 줄인 쪽은 손실이 0.0000인데 \(a = 0.0128\)로 앞층이 입력을 거의 지웠고, 두 기준이 서로 \(\pm 0.013\)으로 겹쳤다. 정답 거리와 오답 거리의 차가 0.0007이라 3과 8을 거의 가르지 못한다. 손실이 0이라는 것은 맞혔다는 뜻이 아니다. 전체 항을 더한 쪽은 \(a\)가 1.92로 커지고 기준 둘이 \(\pm 1.26\)으로 벌어져서 두 거리의 차가 9.73이다. 손실은 0.0002로 역시 낮지만, 이쪽은 실제로 가르는 해다.

막는 방법은 두 가지다. 기준 벡터를 서로 다르게 고정해서, 모든 클래스가 동시에 거리 0이 될 수 없게 둔다. 또는 정답 벌점은 내리면서 오답 벌점은 올린다. 뒤가 판별 기준이다. 최대 사후확률(MAP)과, 은닉 마르코프 모델을 학습할 때의 최대 상호정보(MMI)가 이 형태다. 오답을 올려야 정답만 상대적으로 좋아지므로, 입력을 무시하는 상수 해가 손실의 최솟값이 되지 않는다. MMI는 정답 열의 확률을 가능한 모든 열의 확률의 합으로 나눈 값의 로그를 키운다. 분자만 키우는 것이 아니라 분모에 있는 오답까지 같이 본다는 점이 판별 기준이다.

## 정답과 모든 경로의 차

문자열에서는 올바른 해석의 비용과 모든 해석의 비용 차이가 손실이다.

\[
E = C_{\text{정답 경로}} - C_{\text{모든 경로}}
\]

정답 경로만 모아 둔 집합은 전체 경로의 부분집합이다. 그 안에서 고른 비용은 전체에서 고른 비용보다 작을 수 없으므로, 이 차이는 0 이상이다. 두 경로가 같으면 0이고, 더 싼 오답이 있으면 양수다. 그때 기울기는 오답 비용을 올리는 쪽에도 생긴다. 오답 항이 없으면 앞의 붕괴가 다시 열린다. 경로를 하나 고를 때의 버전과 경로를 전부 합칠 때의 버전은 [비터비](./viterbi.md)와 [전방 알고리즘](./forward-algorithm.md)에서 갈린다.

경로를 전부 합칠 때의 비용은 \(C = -\log \sum_k e^{-c_k}\)로 적는다. \(c_k\)는 경로 \(k\)의 비용이다. 비용이 작은 경로가 합에서 더 크게 반영된다. 이때 \(E\)는 정답 경로 집합 \(\mathcal{C}\)를 써서 이렇게 쓴다.

\[
E = -\log \frac{\sum_{k \in \mathcal{C}} e^{-c_k}}{\sum_{k} e^{-c_k}}
\]

분수는 모든 경로 가운데 정답 경로에 쏠린 몫이다. 그 몫의 음의 로그라서, 정답 쪽에 몰릴수록 \(E\)가 0에 가까워진다. 비용을 확률의 음의 로그로 읽으면 이것이 MMI에서 정답 열의 사후확률을 키우는 것과 같은 식이다.

경로가 넷이고 비용이 A 1.0, B 2.0, C 1.5, D 3.0이라고 하자. A와 B가 정답 해석에 속하고 C와 D는 오답이다. \(e^{-1} = 0.3679\), \(e^{-2} = 0.1353\), \(e^{-1.5} = 0.2231\), \(e^{-3} = 0.0498\)이다. 정답 경로의 합은 \(0.3679 + 0.1353 = 0.5032\), 전체 합은 \(0.5032 + 0.2231 + 0.0498 = 0.7762\)다. \(C_{\text{정답 경로}} = -\log 0.5032 \approx 0.687\), \(C_{\text{모든 경로}} = -\log 0.7762 \approx 0.253\)이고 \(E \approx 0.433\)이다.

비용 \(c_k\)에 대한 \(E\)의 기울기는 정답 경로이면 정답 경로 안에서의 몫을 더하고, 전체에서의 몫을 뺀다. 오답 경로는 전체에서의 몫을 뺄 뿐이다. 오답은 음수라서, 경사하강법이 그 경로의 비용을 올린다.

```python
import math

cost = {"A": 1.0, "B": 2.0, "C": 1.5, "D": 3.0}   # 경로별 비용
correct = {"A", "B"}                              # 정답 해석에 속한 경로

def soft(paths, c):
    """경로를 전부 합친 비용: -log(sum exp(-c))"""
    return -math.log(sum(math.exp(-c[k]) for k in paths))

def E(c):
    return soft(correct, c) - soft(c.keys(), c)

print(f"C_정답={soft(correct, cost):.4f} C_전체={soft(cost.keys(), cost):.4f} E={E(cost):.4f}")

Z_all = sum(math.exp(-v) for v in cost.values())
Z_cor = sum(math.exp(-cost[k]) for k in correct)
for k in cost:                                    # dE/dc_k = [k 정답] * q_k - p_k
    g = (math.exp(-cost[k]) / Z_cor if k in correct else 0.0) - math.exp(-cost[k]) / Z_all
    c2 = dict(cost); c2[k] += 1e-6
    c3 = dict(cost); c3[k] -= 1e-6
    print(k, f"기울기 {g:+.4f}  수치 {(E(c2) - E(c3)) / 2e-6:+.4f}")

only = {"A", "B"}                                 # 오답 경로가 없는 경우
print("오답 경로가 없으면 E =", round(soft(only, cost) - soft(only, cost), 4))
```

```text
C_정답=0.6867 C_전체=0.2534 E=0.4333
A 기울기 +0.2571  수치 +0.2571
B 기울기 +0.0946  수치 +0.0946
C 기울기 -0.2875  수치 -0.2875
D 기울기 -0.0641  수치 -0.0641
오답 경로가 없으면 E = 0.0
```

\(E\)는 0.4333으로 양수다. 정답 경로 A와 B의 기울기는 양수이고, 갱신은 기울기를 빼므로 이 비용들이 내려간다. 오답 경로 C와 D는 기울기가 음수라서 비용이 올라간다. 가장 싼 오답인 C가 가장 크게 올라간다(\(-0.2875\)). 비용 1.5로 정답 경로 B의 2.0보다 싸기 때문이다. 수치 미분과 네 자리까지 같다. 오답 경로가 아예 없으면 \(E = 0\)이고 기울기도 없다. 학습할 것이 없는 문제다.

## 다음 토큰

다음 토큰의 교차엔트로피로 언어 모델을 학습하는 일도 판별 학습이다. 맞히는 대상은 “이 문장이 어떻게 생겼는가” 전체가 아니라, 앞 토큰이 주어졌을 때 다음 토큰이 무엇인가이다.

소프트맥스는 로짓에 지수를 취한 뒤 합이 1이 되도록 나눈다. 정답 토큰의 확률이 오르면 나머지 토큰의 확률은 같이 내려간다. 모든 토큰의 점수를 동시에 올려도 나눗셈 때문에 분포는 그대로다. “출력을 전부 좋게” 만드는 상수 해가, 글자 인식에서처럼 손실의 구멍이 되지 않는다.

점수에 같은 수를 더해도 확률이 같다는 것은 계산으로 확인된다.

```python
import math

def softmax(s):
    e = [math.exp(v) for v in s]
    return [round(v / sum(e), 4) for v in e]

print(softmax([1, 0]), softmax([11, 10]), softmax([-9, -10]))
```

```text
[0.7311, 0.2689] [0.7311, 0.2689] [0.7311, 0.2689]
```

점수가 \([1,\ 0]\), \([11,\ 10]\), \([-9,\ -10]\)이어도 확률이 같다. 정답 점수를 올리려면 오답 점수와의 차이를 벌려야 한다. 이 손실은 위 \(E\)와 같은 모양이다. 정답 토큰의 비용을 \(-s_{\text{정답}}\), 모든 토큰의 합친 비용을 \(-\log \sum_j e^{s_j}\)로 두면 \(E = -s_{\text{정답}} + \log \sum_j e^{s_j}\)다.

선호 학습에서 나은 응답의 점수는 올리고 못한 응답의 점수는 내리는 손실도 같은 차이다. 정답만 당기면 입력을 무시하는 해가 생긴다는 점이, 글자 하나에서나 문장 하나에서나 같다.

## 자주 헷갈리는 점

판별 학습은 입력의 분포를 전혀 모델링하지 않는다고 생각하기 쉽지만, 정확히는 분포를 정답 학습의 대상으로 삼지 않는다는 뜻이다. 앞층이 입력에서 특징을 만들면서 입력의 구조를 간접적으로 쓰기는 한다. 위 코드의 \(a\)가 그렇다.

정답 벌점이 0이면 잘 맞힌 것이라고 생각하기 쉽지만, 위 코드에서 정답 벌점만 쓴 쪽은 손실이 0.0000인데 두 거리의 차가 0.0007이라 3과 8을 거의 가르지 못했다. 손실의 값이 아니라 정답과 오답 사이의 간격을 봐야 한다.

오답을 올리는 항이 필요 없는 경우가 많다고 생각하기 쉽지만, 기준 벡터를 학습하거나 출력이 시그모이드인 경우에는 붕괴가 실제로 일어난다. 소프트맥스를 쓰면 이 항이 분모에 이미 들어 있어서 따로 적지 않는다.

\(E\)가 음수가 될 수 있다고 생각하기 쉽지만, 정답 경로가 전체 경로의 부분집합이라 0 이상이다. 위 계산에서 0.4333이었고 오답 경로가 없으면 0이다.

생성 모델은 쓸모없다고 생각하기 쉽지만, 입력을 만들어 내거나 라벨이 없는 데이터를 쓸 때는 생성 쪽이 필요하다. 판별 학습은 가르는 일에 맞춘 선택이다.

## 직접 풀어 보기

**문제 1.** 경로 A(비용 1, 정답)와 C(비용 1, 오답) 둘뿐일 때 \(E\)는 얼마인가.

**문제 2.** 점수가 \([2,\ 0,\ 0]\)이고 정답이 첫 칸일 때 소프트맥스 손실 \(-\log p_1\)은 얼마인가. 모든 점수에 10을 더하면 달라지는가.

**문제 3.** 문제 1에서 오답 경로 C의 비용을 3으로 올리면 \(E\)는 얼마인가. 이 결과는 학습이 무엇을 하는 것인지 말해 준다.

**문제 1.** 정답 경로 합은 \(e^{-1}\), 전체 합은 \(2e^{-1}\)이므로 비율이 1/2이다. \(E = -\log(1/2) = \log 2 \approx 0.6931\)이다. 정답과 오답이 같은 비용이면 정답 쪽에 몰린 몫이 절반이다.

**문제 2.** \(p_1 = e^2 / (e^2 + 2) = 7.389 / 9.389 \approx 0.7870\)이다. 손실은 \(-\log 0.7870 \approx 0.2395\)다. 모든 점수에 10을 더하면 분자와 분모에 \(e^{10}\)이 같이 곱해져 약분되므로 달라지지 않는다.

**문제 3.** 전체 합이 \(e^{-1} + e^{-3}\), 정답 경로 합은 \(e^{-1}\)이다. 비율은 \(1 / (1 + e^{-2}) \approx 0.8808\)이고, \(E = \log(1 + e^{-2}) \approx 0.1269\)다. 오답 비용을 올리면 \(E\)가 0.6931에서 0.1269로 줄었다. 학습은 정답 비용을 낮추는 것만이 아니라 오답 비용을 올려서도 \(E\)를 줄인다.

## 정리

판별 학습은 입력이 어떻게 생겼는지가 아니라 정답과 오답을 가르는 선을 직접 맞춘다. 정답 벌점만 줄이면 입력을 무시하는 붕괴가 최솟값이 될 수 있으므로, 오답 벌점을 올리는 항이 필요하다. 문자열에서는 정답 경로와 모든 경로의 비용 차이가 그 항을 포함하고, 이 차이는 0 이상이다. 다음 토큰의 소프트맥스 교차엔트로피도 같은 구조다.

경로를 전부 합친 비용은 [전방 알고리즘](./forward-algorithm.md)으로, 하나만 고른 비용은 [비터비](./viterbi.md)로 계산한다. 언어 모델이 이 손실로 학습하는 모습은 [다음 토큰](./next-token.md)에서 이어진다.
