장단기 메모리(Long Short-Term Memory, LSTM)는 [순환 신경망](./rnn.md)에 과거를 보관하는 통로를 하나 더 달고, 그 통로를 여닫는 문 세 개를 둔 모델입니다.

지금 에이전트나 LLM을 만들 때 직접 쓰는 일은 거의 없는 배경 지식입니다. 트랜스포머 이전에 긴 글을 다루던 표준 구조였고, "과거를 남길지 지울지를 학습한 문으로 정한다"는 발상은 이후 모델에도 이어졌습니다. 순환 신경망이 긴 글을 못 기억하는 문제를 어떻게 줄였는지만 알면 됩니다.

## 왜 필요한가

[순환 신경망](./rnn.md)은 매 자리에서 상태 전체를 가중치와 tanh에 통과시켜 새로 씁니다. 과거가 한 자리 지날 때마다 한 번씩 변형되고 줄어든다는 뜻입니다. 가중치 곱이 0.5라면 다섯 자리 앞 token의 영향은 \(0.5^5 = 0.03125\)배가 됩니다. 학습 때 오차 신호도 같은 길로 거슬러 오므로, 열 자리 앞의 단어가 지금 정답과 관련 있다는 사실을 배우기 어렵습니다. 문서 앞에 나온 고객 이름을 열 단어 뒤에서 다시 써야 하는 경우가 이렇습니다.

필요한 것은 어떤 정보를 줄이지 않고 먼 자리까지 들고 가는 길입니다. 장단기 메모리는 상태와 별도로 통로를 하나 두고, 통로에서는 가중치를 곱하지 않습니다. 이전 값에 문 값을 곱하고 새 내용을 더하는 계산만 합니다. 문 값이 1이면 과거가 그대로 지나갑니다. 문 값은 학습으로 정해지므로, 어떤 정보를 오래 둘지는 모델이 정합니다. 1997년 Hochreiter와 Schmidhuber가 제안했습니다.

## 통로 갱신

순환 신경망은 상태 전체에 가중치를 곱해서, 곱할수록 앞 token의 흔적이 줄었습니다. 장단기 메모리는 통로 \(c\)를 따로 두고, 이전 값에 문을 곱한 것과 새 내용을 더한 것으로 갱신합니다.

\[
c_t = f_t\, c_{t-1} + i_t\, g_t
\]

문(gate)은 0과 1 사이의 수로, 값에 곱해서 그만큼만 통과시키는 장치입니다. 칸마다 문이 하나씩 있어서 칸별로 따로 여닫습니다. \(f\)는 잊는 문, \(i\)는 넣는 문입니다. \(g\)는 새로 넣을 내용으로, -1과 1 사이의 값입니다. 통로가 2일 때 문 값에 따라 \(c\)가 어떻게 바뀌는지 세 경우로 봅니다.

```text
f     i     g     c (이전 c = 2)
0.5   1     0     0.5 x 2 + 1 x 0 = 1     절반이 남습니다
1     0     -     1 x 2 + 0 = 2           새 token이 와도 그대로입니다
0     1     1     0 x 2 + 1 x 1 = 1       이전 값이 지워집니다
```

통로 밖으로 내보내는 값 \(h\)(순환 신경망의 상태에 해당)는 내보내는 문 \(o\)를 곱해 \(h = o \tanh(c)\)로 만듭니다. \(c = 2\)인데 \(o = 0\)이면 \(h = 0\)이라 통로 안에는 2가 있어도 밖으로 나가지 않습니다. 다음 자리에서 \(o = 1\)로 열면 \(h = \tanh(2) \approx 0.964\)가 나갑니다. 문 값은 직전 상태와 지금 token에서 계산되고, 학습으로 정해집니다.

네 자리를 이어서 보는 장난감 예입니다. 문 값을 직접 정했습니다. 통로는 0에서 시작합니다. 첫 자리에서 \(f = 0,\ i = 1,\ g = 1\)이면 \(c = 1\)이 저장됩니다. 둘째와 셋째 자리에서 \(f = 1,\ i = 0\)이면 새 token이 와도 \(c = 1\)이 그대로입니다. 넷째 자리에서 \(o = 1\)로 열면 \(h = \tanh(1) \approx 0.762\)가 나갑니다. 첫 token에서 넣은 내용이 두 자리를 건너 나온 것입니다. 실제 모델에서는 이런 문 값을 사람이 정하지 않고, 어느 자리에서 저장하고 언제 꺼낼지를 학습이 정합니다.

## 기억할 것 세 가지

### 기울기 소실이 없어진 것이 아니라 느려진 것입니다

통로를 따라 거슬러 가는 신호는 \(f\)만 곱해집니다. \(f = 0.5\)이면 스무 자리 뒤에 약 0.000001배로 사라집니다. 하지만 \(f\)를 0.9나 0.99로 학습할 수 있으면 같은 거리에서 0.12배, 0.82배가 남습니다. 필요한 정보는 \(f\)가 1 근처가 되도록 학습해서 멀리 보냅니다.

### 순서대로 계산해야 하는 한계는 그대로입니다

한 자리를 계산하려면 직전 자리가 끝나야 합니다. 병렬로 처리하지 못해서 큰 모델을 큰 글로 학습하기에 느렸습니다. 이 한계를 푼 것이 [어텐션](./attention.md)입니다. 어텐션은 모든 자리를 동시에 보고 섞습니다.

### 문은 켜짐/꺼짐 스위치가 아닙니다

문은 0과 1 사이의 연속된 수입니다. 완전히 닫히거나 열리는 일은 드물고, 0.8처럼 일부만 통과시킵니다. 통로 \(c\)와 숨은 상태 \(h\)도 다릅니다. \(c\)는 안에 쌓는 값이고, 다음 층이 읽는 것은 문을 거쳐 나온 \(h\)입니다.

문 \(f, i, o\)와 넣을 내용 \(g\)는 각자 가중치를 갖고, 직전 상태 \(h_{t-1}\)과 지금 token \(x_t\)에서 계산됩니다. \(\sigma\)는 시그모이드입니다.

\[
\begin{aligned}
f_t &= \sigma(W_f x_t + U_f h_{t-1} + b_f), \quad i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \\
g_t &= \tanh(W_g x_t + U_g h_{t-1} + b_g), \quad o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \\
c_t &= f_t c_{t-1} + i_t g_t, \quad h_t = o_t \tanh(c_t)
\end{aligned}
\]

- 순환 신경망의 식 한 줄이 네 줄이 되어 파라미터 수가 네 배입니다. 벡터 길이가 3일 때 순환 신경망은 바이어스까지 21개이고 장단기 메모리는 84개입니다.
- 1997년에 처음 나온 구조에는 잊는 문이 없었습니다. 잊는 문은 그 뒤에 추가되어 지금은 기본입니다.
- 문을 둘로 줄인 변형이 GRU(gated recurrent unit)입니다. 갱신 문 \(z\)로 이전 상태와 새 후보를 섞습니다. 이전 상태 1, 새 후보 0.5, \(z = 0.25\)이면 \(0.75 \times 1 + 0.25 \times 0.5 = 0.875\)입니다.
