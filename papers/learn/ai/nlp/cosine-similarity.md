코사인 유사도는 두 벡터가 같은 방향을 가리키는 정도를 -1에서 1 사이의 수로 나타냅니다. 길이는 보지 않습니다.

벡터 검색을 쓰면 이 값을 이미 만나고 있습니다.

- **RAG 검색 점수**: 질문 벡터와 청크 벡터의 코사인이 큰 순서로 청크를 가져옵니다. → [검색](../rag/retrieval.md), [벡터 인덱스](../rag/vector-index.md)
- **벡터 DB 설정**: 인덱스를 만들 때 거리 척도로 cosine, dot product, L2 중 하나를 고릅니다.
- **임계값 컷오프**: "점수 0.8 이상만 쓴다", "0.95 이상이면 같은 질문으로 보고 캐시 답을 쓴다" 같은 규칙에 씁니다.
- **중복 제거와 군집화**: 비슷한 문서끼리 묶을 때도 같은 값을 씁니다.

## 계산

두 벡터 \(x = [1,\ 2]\), \(y = [2,\ 1]\)입니다. 칸마다 곱해 더한 값(내적)을 두 길이의 곱으로 나눕니다.

\[
\cos(x, y) = \frac{x \cdot y}{\|x\|\,\|y\|}
\]

내적은 \(1 \times 2 + 2 \times 1 = 4\)입니다. 길이는 둘 다 \(\sqrt{5}\)라서 곱이 5입니다. 코사인은 \(4/5 = 0.8\)입니다.

\(x\)를 3배 키워 \([3,\ 6]\)으로 만들어도 내적은 12가 되고 길이의 곱은 \(3\sqrt{5} \times \sqrt{5} = 15\)가 되어 값은 \(12/15 = 0.8\)로 그대로입니다. 길이로 나누기 때문에 벡터를 몇 배로 키워도 방향만 남습니다. 같은 방향이면 1, 직각이면 0, 반대 방향이면 -1입니다.

끝의 점을 끌어서 방향과 길이를 따로 바꿔 보세요. 길이를 바꿔도 코사인은 그대로이고, 방향을 돌릴 때만 값이 변합니다.

## 기억할 것 세 가지

### 길이가 아니라 방향을 봅니다

내적만 쓰면 벡터가 긴 쪽이 이깁니다. 코사인은 길이를 지워서 길이 차이에 흔들리지 않습니다. 질문 \(q = [1,\ 0]\)에 대해 문서 A \([0.8,\ 0.6]\)과 문서 B \([3,\ 3]\)을 비교해 봅니다.

```text
문서          내적   코사인
A [0.8, 0.6]  0.8    0.8
B [3, 3]      3      0.707
```

내적은 B를, 코사인은 A를 1등으로 고릅니다. 많은 임베딩 API가 벡터를 길이 1로 맞춰서 돌려주는데, 이 경우에는 내적과 코사인의 순위가 같습니다. 직접 만든 벡터나 정규화되지 않은 모델에서는 둘이 다를 수 있습니다.

### 점수의 절대값은 모델마다 다릅니다

0.8이 "가깝다"인지는 임베딩 모델에 따라 다릅니다. 어떤 모델은 관련 없는 문장도 0.7 근처로 내고, 어떤 모델은 0.2 근처로 냅니다. 임계값은 쓰는 모델과 내 데이터로 직접 정해야 합니다. 모델을 바꾸면 임계값도 다시 정합니다.

### 닮은 것과 답이 있는 것은 다릅니다

코사인은 확률이 아니고 정답일 가능성도 아닙니다. 0.9가 나온 청크가 질문의 답을 담고 있다는 보장은 없습니다. "환불 가능합니다"와 "환불 불가합니다"는 단어 대부분이 같아서 높은 점수가 나옵니다. 높은 점수만 믿고 prompt에 넣으면 반대 내용을 근거로 쓰게 됩니다. 가져온 청크를 다시 순위 매기거나(reranking), 답이 근거에 있는지 확인하는 단계를 둡니다. → [근거 확인](../rag/grounding.md)

<summary>더 깊이: 정규화, 거리, 확인 코드</summary>

- 두 벡터를 먼저 길이 1로 줄이면(정규화) 분모가 1이라 내적이 곧 코사인입니다. 저장할 때 정규화해 두고 내적만 계산하면, 쌍마다 나눗셈과 제곱근을 하지 않아도 됩니다.
- 코사인 값 0.5는 사이각이 \(60^\circ\)라는 뜻입니다.
- 코사인 거리는 \(1 - \cos\)입니다. 같은 방향이면 0, 반대면 2입니다. 거리를 받는 도구에 유사도를 넣을 때 쓰는 변환입니다.
- 길이가 0인 벡터는 0으로 나누게 되어 코사인이 정의되지 않습니다. 내용이 빈 청크를 걸러 내야 하는 이유입니다.
- 길이가 신호일 때는 내적이 맞습니다. 길이가 중요도나 빈도를 뜻하는 경우입니다.
- [단어 주머니](./bag-of-words.md)처럼 횟수로 만든 벡터는 칸이 0 이상이라 코사인이 0과 1 사이입니다. 학습된 임베딩은 음수 칸이 있어서 -1까지 내려갑니다.

```python
import math

dot = lambda x, y: sum(p * q for p, q in zip(x, y))
cos = lambda x, y: dot(x, y) / math.sqrt(dot(x, x) * dot(y, y))

print(cos([1, 2], [2, 1]), cos([3, 6], [2, 1]))            # 0.8 0.8
q = [1, 0]
print(dot(q, [0.8, 0.6]), dot(q, [3, 3]))                   # 0.8 3
print(round(cos(q, [0.8, 0.6]), 3), round(cos(q, [3, 3]), 3))  # 0.8 0.707
```
