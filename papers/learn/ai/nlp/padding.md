리뷰 두 개를 한 번에 넣으려면 목록의 길이가 같아야 합니다. 곱하는 가중치 줄의 길이가 문장마다 달라지면, 같은 칸이 같은 단어를 가리키지 않습니다. “날씨 좋다”는 토큰이 둘이고, “오늘 날씨 정말 좋다”는 넷입니다. 짧은 쪽에 빈 칸을 붙여 넷으로 맞춥니다. 이 빈 칸을 **패딩**(padding)이라고 합니다. 빈 칸은 사전 안의 어떤 단어와도 겹치지 않는 별도의 표시로 둡니다. 아래 그림과 식에서는 그 표시를 0으로 적습니다.

\[
[\text{날씨},\ \text{좋다},\ 0,\ 0], \quad [\text{오늘},\ \text{날씨},\ \text{정말},\ \text{좋다}]
\]

:::tip[한눈에 보기]
패딩은 길이가 다른 문장을 한 묶음으로 만들기 위해 짧은 문장 뒤에 붙이는 빈 칸입니다. 빈 칸은 계산에서 반드시 빼야 합니다.

- 묶음의 길이는 가장 긴 문장에 맞추고, 짧은 문장에 빈 칸을 채웁니다.
- 어느 칸이 빈 칸인지는 1과 0의 마스크 목록으로 기억합니다.
- 손실의 평균과 어텐션의 비율에서 빈 칸을 빼지 않으면, 실제 단어가 받는 몫이 줄어듭니다.
- 너무 긴 문장은 자르고, 길이가 비슷한 문장끼리 묶으면 빈 칸이 줄어듭니다.

선수 지식은 [임베딩](./embedding.md), [토큰화](./tokenization.md)입니다. 다음으로 보면 좋은 글은 [어텐션](./attention.md), [순환 신경망](./rnn.md), [다음 토큰](./next-token.md)입니다.
:::

## 동기

문장을 하나씩 넣으면 길이가 달라도 상관없지만, 한 번에 여러 문장을 넣으면 계산을 행렬 하나로 묶을 수 있어 훨씬 빠릅니다. 행렬은 모든 행의 길이가 같아야 합니다. 그래서 문장 수만큼 행을 쌓은 직사각형을 만들고, 짧은 행의 모자라는 칸을 빈 칸으로 채웁니다. 직사각형의 가로는 가장 긴 문장의 길이입니다. 빈 칸은 계산이 지나가는 자리일 뿐이지 문장의 일부가 아닙니다.

사전이 이미 0번부터 번호를 쓰고 있으면 빈 칸을 0으로 적을 수 없습니다. [임베딩](./embedding.md)의 표에서 오늘이 0번이라, 빈 칸을 0으로 두면 오늘과 구별되지 않습니다. 그래서 실제로는 빈 칸 전용 번호를 하나 만듭니다. 사전의 맨 앞 0번을 빈 칸에 주고 단어 번호를 한 칸씩 미루는 구성이 흔합니다. 이 페이지에서 0으로 적은 것은 번호가 아니라 빈 칸이라는 표시로 읽습니다.

0을 진짜 단어처럼 다음 토큰 손실에 넣으면, 모델이 문장 끝에 0을 예측하도록 배웁니다. 그래서 0 자리의 손실은 평균에서 빼거나, [어텐션](./attention.md)이 그 자리를 보지 않게 가립니다. 뒤 토큰을 가리는 마스크와 같은 종류의 가림이고, 대상이 미래가 아니라 빈 칸입니다.

길이를 맞추는 다른 방법은 긴 문장을 자르는 것입니다. 넷보다 긴 리뷰는 앞의 네 토큰만 남깁니다. 잘린 뒤의 단어는 그 학습 단계에 없습니다. 패딩은 짧은 문장을 늘리고, 자르기는 긴 문장을 줄입니다. 한 묶음의 최대 길이는 사람이 정하는 구조입니다.

## 마스크

어느 칸이 빈 칸인지를 알려 주는 목록이 **마스크**(mask)입니다. 실제 단어가 있는 칸은 1, 빈 칸은 0으로 둡니다. 위의 두 문장은 마스크가 \([1,\ 1,\ 0,\ 0]\)과 \([1,\ 1,\ 1,\ 1]\)입니다. 이 마스크를 손실에 곱하면 빈 칸의 손실이 0이 되고, 어텐션의 점수에 쓰면 빈 칸의 비율이 0이 됩니다. 모양이 같은 목록이 문장마다 하나씩 따라다닌다고 보면 됩니다.

## 마스크와 손실

네 칸 중 둘은 0입니다. 자리마다 손실을 구해 넷으로 나누면, 나누는 수에 빈 칸이 들어갑니다. 날씨와 좋다의 손실이 각각 0.3이고, 0을 단어로 맞히지 못해 그 자리 손실이 1이라고 하면 평균은 \((0.3 + 0.3 + 1 + 1) / 4 = 0.65\)입니다. 0 자리를 빼면 나누는 수가 2이고 평균은 0.3입니다. 빈 칸을 넣은 평균은 실제 단어의 기울기를 \(1/4\)로 나누고, 뺀 평균은 \(1/2\)로 나눕니다. 같은 0.3이라도 빈 칸을 빼야 그 단어의 가중치가 두 배로 움직입니다.

마스크 \(m_i\)를 쓰면 빈 칸을 뺀 평균은 한 식입니다. 자리별 손실을 \(\ell_i\)라고 할 때 다음과 같습니다.

\[
\bar{\ell} = \frac{\sum_i m_i \ell_i}{\sum_i m_i}
\]

말로 읽으면, 마스크가 1인 자리의 손실만 더해서 그 개수로 나눈 것입니다. 첫 문장에서 \(m = [1,\ 1,\ 0,\ 0]\)이면 \((0.3 + 0.3) / 2 = 0.3\)입니다.

문장이 둘인 묶음으로 가 봅시다. 둘째 문장 “오늘 날씨 정말 좋다”의 자리별 손실이 \(0.2,\ 0.4,\ 0.6,\ 0.2\)라고 합시다. 합은 1.4입니다. 묶음 전체의 평균을 빈 칸을 넣고 내면 \((2.6 + 1.4) / 8 = 0.5\)입니다. 빈 칸을 빼면 \((0.6 + 1.4) / (2 + 4) = 2.0 / 6 \approx 0.333\)입니다. 빈 칸의 손실 1이 두 개나 섞이면 평균이 0.5까지 올라, 실제 단어의 손실 합인 2.0을 실제 단어 6개로 나눈 값 0.333과 차이가 납니다.

자르기의 손실도 숫자로 남습니다. “오늘 날씨 정말 좋다”를 두 칸만 남기면 `정말`과 `좋다`가 그 단계의 손실에 없습니다. 긍정인 이유가 좋다에 있어도, 그 학습에서는 날씨와 오늘만 봅니다. 최대 길이를 4로 두면 이 문장은 잘리지 않고, “날씨 좋다”만 0을 두 개 붙입니다. 묶음 안의 가장 긴 문장에 맞추면 자르기는 없고 패딩만 있습니다. 그 길이가 문장마다 바뀌면, 배치마다 가중치가 보는 칸 수가 달라집니다.

## 마스크와 어텐션

네 칸의 점수를 전부 0으로 두면, 소프트맥스는 칸마다 \(1/4 = 0.25\)입니다. 날씨와 좋다가 받는 비율의 합은 0.5입니다. 0 두 칸을 빼고 다시 나누면 각각 0.5이고 합은 1입니다. 빈 칸을 넣으면 실제 단어가 가져가던 0.5가 0.25로 줄어, 줄어든 만큼이 패딩으로 갑니다.

패딩 점수를 아주 작은 수로 두면 그 칸의 지수가 0에 가까워 비율도 0입니다. 남는 둘의 합이 다시 1이 됩니다. [어텐션](./attention.md)에서 자리를 섞을 때 이 처리를 합니다. 손실에서 0 자리를 빼는 일과, 어텐션에서 0 자리의 비율을 0으로 두는 일은 빈 칸을 계산에서 빼는 같은 목적입니다. 하나는 평균의 분모이고, 하나는 섞는 비율입니다.

점수가 0이 아닌 예도 봅시다. 네 칸의 점수가 \(2,\ 1,\ 0,\ 0\)이고 뒤 두 칸이 빈 칸이라고 합시다. \(e^{2} \approx 7.389\), \(e^{1} \approx 2.718\), \(e^{0} = 1\)입니다. 빈 칸을 넣으면 합이 \(7.389 + 2.718 + 1 + 1 = 12.107\)이라 비율이 \(0.610,\ 0.225,\ 0.083,\ 0.083\)입니다. 빈 칸이 약 \(0.165\)를 가져갑니다. 빈 칸의 지수를 0으로 두면 합이 \(10.107\)이고 비율이 \(0.731,\ 0.269,\ 0,\ 0\)입니다. 실제 단어 둘이 비율 전체를 나눠 가집니다.

## 파이썬으로 확인

```python
import math

PAD = "<pad>"
batch = [["날씨", "좋다"], ["오늘", "날씨", "정말", "좋다"]]
L = max(len(s) for s in batch)
padded = [s + [PAD] * (L - len(s)) for s in batch]
mask = [[0 if t == PAD else 1 for t in s] for s in padded]
print(padded)
print(mask)

loss = [[0.3, 0.3, 1.0, 1.0], [0.2, 0.4, 0.6, 0.2]]   # 자리별 손실
first = loss[0]
print("첫 문장 빈 칸 포함", round(sum(first) / 4, 3), " 뺀 평균", round(sum(l * m for l, m in zip(first, mask[0])) / sum(mask[0]), 3))
tot = sum(l * m for r, mr in zip(loss, mask) for l, m in zip(r, mr))
print("묶음 전체 빈 칸 포함", round(sum(map(sum, loss)) / 8, 3), " 뺀 평균", round(tot / sum(map(sum, mask)), 3))

def softmax(xs):
    es = [math.exp(x) for x in xs]
    return [e / sum(es) for e in es]

print("점수 0:", softmax([0, 0, 0, 0]))
print("가림 :", softmax([0, 0, -math.inf, -math.inf]))
print("점수 2,1,0,0:", [round(p, 3) for p in softmax([2, 1, 0, 0])])
print("가림        :", [round(p, 3) for p in softmax([2, 1, -math.inf, -math.inf])])
```

```text
[['날씨', '좋다', '<pad>', '<pad>'], ['오늘', '날씨', '정말', '좋다']]
[[1, 1, 0, 0], [1, 1, 1, 1]]
첫 문장 빈 칸 포함 0.65  뺀 평균 0.3
묶음 전체 빈 칸 포함 0.5  뺀 평균 0.333
점수 0: [0.25, 0.25, 0.25, 0.25]
가림 : [0.5, 0.5, 0.0, 0.0]
점수 2,1,0,0: [0.61, 0.225, 0.083, 0.083]
가림        : [0.731, 0.269, 0.0, 0.0]
```

점수를 \(-\infty\)로 두면 \(e^{-\infty} = 0\)이라 그 칸의 비율이 정확히 0이 됩니다. 실제 구현에서는 아주 큰 음수로 대신하는 경우가 많습니다.

## 패딩 비율

묶음의 가로를 가장 긴 문장에 맞추므로, 길이가 들쭉날쭉하면 빈 칸이 늘어 계산이 낭비됩니다. 문장 길이가 2, 4, 3, 7인 네 문장을 한 묶음으로 만들면 가로가 7이라 칸이 \(4 \times 7 = 28\)개이고, 실제 단어는 \(2+4+3+7 = 16\)개입니다. 빈 칸이 12개로 42.9%입니다. 길이가 비슷한 것끼리 \((2, 3)\)과 \((4, 7)\)로 나눠 두 묶음으로 만들면 칸이 \(2 \times 3 + 2 \times 7 = 20\)개이고 빈 칸이 4개, 20%로 줄어듭니다.

```python
lens = [2, 4, 3, 7]
def waste(groups):
    cells = sum(max(g) * len(g) for g in groups)
    return cells - sum(map(sum, groups)), cells
print(waste([lens]), waste([[2, 3], [4, 7]]))
```

```text
(12, 28) (4, 20)
```

각 쌍은 (빈 칸 수, 전체 칸 수)입니다. 길이가 비슷한 문장끼리 묶는 이 방법을 길이별 묶기라고 하며, 학습 때 흔히 씁니다.

## 패딩 위치

빈 칸을 문장 뒤에 붙이는 것이 가장 흔하지만 앞에 붙이기도 합니다. 앞에 붙이는 왼쪽 패딩은 모든 문장의 마지막 실제 단어가 같은 칸에 놓이므로, 마지막 단어 다음을 이어 쓰는 경우에 편합니다. 어느 쪽이든 마스크로 빈 칸을 알려 주는 일은 같습니다.

[순환 신경망](./rnn.md)은 칸을 차례로 읽으며 상태를 갱신하므로 빈 칸을 지나가면 상태가 한 번씩 더 갱신됩니다. “날씨 좋다 0 0”의 마지막 상태는 빈 칸 두 번을 더 거친 값이라, 마지막 실제 단어의 상태와 다릅니다. 그래서 문장 길이를 따로 기억해 두었다가 실제 마지막 칸의 상태를 꺼내거나, 빈 칸에서는 상태를 갱신하지 않습니다.

패딩 번호의 [임베딩](./embedding.md) 행은 손실과 어텐션에서 빠지는 자리에서 읽히므로, 입력 쪽 기울기를 받지 않습니다. 그 행을 영 목록으로 고정해 두는 설정을 많은 라이브러리가 제공합니다.

## 헷갈리기 쉬운 점

**패딩을 붙여도 마스크로 빼면 문장의 뜻은 바뀌지 않습니다.** 손실과 어텐션에서 마스크로 빼면 문장 하나만 넣은 결과와 같습니다. 마스크 없이 빈 칸을 단어처럼 쓰면 평균 손실이 0.5로 부풀고, 어텐션의 몫이 줄어듭니다.

**빈 칸의 번호가 꼭 0이어야 하는 것은 아닙니다.** 어떤 번호든 사전의 단어와 겹치지 않기만 하면 됩니다. 이 시리즈의 표에서 오늘이 0번이라 0을 그대로 쓰면 겹칩니다.

**가장 긴 문장에 맞추면 문장이 잘리지 않습니다.** 가장 긴 문장에 맞추면 아무것도 잘리지 않고 빈 칸만 늘어납니다. 자르기는 사람이 정한 최대 길이보다 긴 문장에서만 일어납니다.

**빈 칸이 많으면 결과는 같아도 계산이 낭비됩니다.** 위의 28칸 중 12칸이 빈 칸입니다. 결과는 같아도 시간과 메모리는 28칸 몫으로 듭니다.

## 연습 문제

1. 길이가 3, 5, 2인 세 문장을 한 묶음으로 만듭니다. 전체 칸 수와 빈 칸 수, 빈 칸의 비율을 구해 보세요.
2. 한 문장의 자리별 손실이 \(0.5,\ 0.1,\ 0.8,\ 0.8\)이고 뒤 두 칸이 빈 칸입니다. 빈 칸을 넣은 평균과 뺀 평균을 구해 보세요.
3. 어텐션 점수가 \([0,\ 1,\ 0,\ 0]\)이고 뒤 두 칸이 빈 칸입니다. 빈 칸을 넣었을 때와 가렸을 때의 비율을 구해 보세요. 단 \(e^{1} \approx 2.718\)입니다.

1. 가로는 5이므로 전체 \(3 \times 5 = 15\)칸입니다. 실제 단어는 \(3+5+2 = 10\)개라 빈 칸이 5개이고, 비율은 \(5/15 \approx 33.3\%\)입니다.

## 정리

패딩은 짧은 문장에 빈 칸을 붙여 한 묶음의 길이를 맞춥니다. 빈 칸은 단어가 아니므로 마스크로 표시해 손실의 평균과 어텐션의 비율에서 뺍니다. 빼지 않으면 손실 평균이 부풀고 실제 단어가 받을 비율이 줄어듭니다. 길이가 비슷한 문장끼리 묶으면 빈 칸이 줄고, 너무 긴 문장은 최대 길이에서 자릅니다. 빈 칸을 가린 어텐션이 쓰이는 블록은 [트랜스포머](./transformer.md)입니다.
