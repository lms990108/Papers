문장 전체에 레이블 하나를 붙이는 일은, 단어가 몇 번 나왔는지만으로 시작할 수 있습니다. 나온 횟수를 칸에 담은 목록을 **단어 주머니**(bag of words)라고 합니다. 순서는 목록에 없습니다. “날씨 좋다”와 “좋다 날씨”는 같은 주머니입니다.

[토큰화](./tokenization.md) 뒤의 단어 번호는 [임베딩](./embedding.md)의 표와 같이 둡시다. 오늘 0, 날씨 1, 좋다 2, 나쁘다 3입니다.

:::tip[한눈에 보기]
단어 주머니는 문장을 사전 크기 길이의 목록으로 바꾸고, 각 칸에 그 단어가 나온 횟수를 적은 것입니다.

- 길이가 다른 문장이 모두 같은 길이의 목록이 되어, 점수를 내는 한 줄짜리 신경망의 입력으로 쓸 수 있습니다.
- 점수는 칸마다 가중치를 곱해 더한 것입니다. 단어 하나가 점수를 얼마나 움직이는지가 가중치 하나에 담깁니다.
- 순서와 단어 사이의 곱은 버립니다. “날씨 좋다”와 “좋다 날씨”가 구별되지 않습니다.
- 횟수 대신 있는지 없는지, 문장 길이로 나눈 비율, 문서 사이의 빈도로 깎은 값(TF-IDF)을 쓰는 변형이 있습니다.

선수 지식은 [원-핫 인코딩](./one-hot.md), [토큰화](./tokenization.md)입니다. 다음으로 보면 좋은 글은 [TF-IDF](./tf-idf.md), [코사인 유사도](./cosine-similarity.md), [엔그램](./ngram.md)입니다.
:::

## 구성

“날씨 좋다”는 날씨 한 번, 좋다 한 번입니다. 횟수 목록은 \([0,\ 1,\ 1,\ 0]\)입니다. “날씨 나쁘다”는 \([0,\ 1,\ 0,\ 1]\)입니다. 이 목록이 신경망의 입력입니다. 픽셀 밝기 자리에 횟수가 들어갑니다.

만드는 순서는 세 단계입니다. 먼저 코퍼스에서 사전을 정합니다. 칸의 순서는 이 사전의 번호입니다. 다음에 문장을 [토큰화](./tokenization.md)하고, 마지막에 토큰마다 해당 번호의 칸에 1을 더합니다. 사전에 없는 토큰은 칸이 없어서 버려지거나, 칸 하나를 `[UNK]`로 따로 두어 거기에 셉니다. 문장 안의 단어를 [원-핫 인코딩](./one-hot.md)으로 바꿔 열마다 더한 것과 같은 결과입니다.

사전이 수만 개면 목록도 수만 칸이고, 한 문장에서 0이 아닌 칸은 문장의 단어 수보다 많을 수 없습니다. 그래서 실제로는 0이 아닌 칸만 저장합니다. 파이썬의 `Counter`가 그 모양입니다.

## 점수 예제

레이블이 불만인지 아닌지를 하나의 점수로 둡니다. 점수가 크면 불만 쪽에 가깝습니다. 칸마다 가중치를 곱해 더하면 [신경망](../deep-learning/neural-network.md)의 한 줄과 같습니다. 이 예는 가중치를 오늘 0, 날씨 0.2, 좋다 -1, 나쁘다 1로 둡니다.

\[
0 \times 0 + 0.2 \times 1 + (-1) \times 0 + 1 \times 1 = 1.2
\]

“날씨 나쁘다”의 점수는 1.2입니다. “날씨 좋다”는 \(0.2 \times 1 + (-1) \times 1 = -0.8\)입니다. 나쁘다가 있으면 점수가 올라가고, 좋다가 있으면 내려갑니다. 날씨는 양쪽 문장에 다 있어서, 이 가중치로는 불만을 거의 가리지 못합니다.

수로는 이렇게 씁니다. 횟수 목록이 \(x\), 가중치가 \(w\)이면 점수는 칸마다 곱해 더한 것입니다.

\[
s = w \cdot x
\]

레이블이 두 개면 이런 줄이 두 개입니다. 두 점수를 합이 1인 비율로 바꾸는 계산은 [소프트맥스](../machine-learning/softmax.md)입니다.

순서를 버리면 “나쁘다”가 “날씨”를 말하는지, 다른 단어를 말하는지를 점수가 보지 못합니다. 단어 사이의 곱도 없습니다. “날씨”와 “나쁘다”가 같이 있을 때만 불만으로 두고 싶어도, 주머니는 두 횟수를 따로 더할 뿐입니다. 여러 문서에 다 나오는 단어를 깎는 가중치는 [TF-IDF](./tf-idf.md)입니다. 그 자리를 보려면 단어를 순서대로 넣어야 하고, 그 계산은 [어텐션](./attention.md) 쪽에 있습니다.

## 중복 단어

“날씨 나쁘다 날씨”는 날씨가 둘이라 \([0,\ 2,\ 0,\ 1]\)입니다. 점수는 \(0.2 \times 2 + 1 \times 1 = 1.4\)입니다. “날씨 나쁘다”의 1.2보다 0.2가 더 큽니다. 날씨가 한 번 더 나온 것만으로 불만 점수가 올라갑니다. 순서를 “나쁘다 날씨 날씨”로 바꿔도 목록이 같아서 점수도 1.4입니다.

## 파이썬으로 확인

사전을 오늘, 날씨, 좋다, 나쁘다로 두고 앞의 문장들을 횟수 목록과 점수로 바꿉니다. 마지막 두 줄은 순서가 달라도 같은 목록이고, 사전에 없는 말(`정말`)은 버려진다는 것을 보입니다.

```python
from collections import Counter

vocab = ["오늘", "날씨", "좋다", "나쁘다"]
w = [0, 0.2, -1, 1]                       # 불만 점수의 가중치

def bow(text):
    c = Counter(text.split())
    return [c[v] for v in vocab]          # 사전에 없는 말은 버려진다

def score(x):
    return round(sum(wi * xi for wi, xi in zip(w, x)), 2)

for t in ["날씨 좋다", "좋다 날씨", "날씨 나쁘다", "날씨 나쁘다 날씨", "나쁘다 날씨 날씨"]:
    x = bow(t)
    print(t, x, score(x))
print(bow("날씨 좋다") == bow("좋다 날씨"))
print(bow("정말 날씨 좋다"))             # 정말은 사전에 없다
```

```text
날씨 좋다 [0, 1, 1, 0] -0.8
좋다 날씨 [0, 1, 1, 0] -0.8
날씨 나쁘다 [0, 1, 0, 1] 1.2
날씨 나쁘다 날씨 [0, 2, 0, 1] 1.4
나쁘다 날씨 날씨 [0, 2, 0, 1] 1.4
True
[0, 1, 1, 0]
```

점수 \(-0.8\), 1.2, 1.4가 본문 계산과 같습니다. “정말 날씨 좋다”는 `정말`을 잃고 “날씨 좋다”와 같은 \([0,\ 1,\ 1,\ 0]\)이 됩니다. 정말이 뜻을 바꾸는 말(“정말 나쁘다”)이어도 주머니에서는 흔적이 없습니다.

## 빈도 표현

칸에 적는 값은 횟수 말고도 있습니다. 있는지 없는지만 적는 이진(binary) 방식은 같은 단어가 여러 번 나와도 1입니다. 횟수를 문장의 단어 수로 나눈 비율은 긴 글과 짧은 글을 같은 크기로 맞춥니다. 문서 사이에서 흔한 단어를 깎는 값이 [TF-IDF](./tf-idf.md)입니다. 같은 “날씨 나쁘다 날씨”에 세 방식을 적용하고 앞의 가중치로 점수를 냅니다.

```python
from collections import Counter

w = [0, 0.2, -1, 1]
x = [0, 2, 0, 1]                           # "날씨 나쁘다 날씨"
binary = [min(c, 1) for c in x]            # 있다 없다만
rel = [c / sum(x) for c in x]              # 문장 길이로 나눈 비율
for name, v in [("횟수", x), ("이진", binary), ("비율", rel)]:
    print(name, [round(c, 3) for c in v], round(sum(wi * c for wi, c in zip(w, v)), 3))

def bigrams(toks):
    return list(zip(toks, toks[1:]))
a, b = "dog bites man".split(), "man bites dog".split()
print(Counter(a) == Counter(b))                      # 단어 주머니는 같다
print(Counter(bigrams(a)) == Counter(bigrams(b)))    # 2-그램 주머니는 다르다
```

```text
횟수 [0, 2, 0, 1] 1.4
이진 [0, 1, 0, 1] 1.2
비율 [0.0, 0.667, 0.0, 0.333] 0.467
True
False
```

같은 문장도 적는 방식에 따라 점수가 1.4, 1.2, 0.467로 달라집니다. 가중치는 그 방식에 맞춰 학습해야 합니다. 아래의 두 줄은 영어 예입니다. “dog bites man”과 “man bites dog”은 뜻이 반대인데 단어 주머니는 같습니다. 단어 둘씩 묶은 2-그램의 주머니는 다릅니다. 단어 묶음을 칸으로 쓰면 순서 정보가 조금 들어옵니다.

## 헷갈리기 쉬운 점

**단어 주머니는 문장의 뜻을 담지 않습니다.** 단어가 몇 번 나왔는지만 담습니다. “dog bites man”과 “man bites dog”이 같은 목록입니다. 부정도 약합니다. `좋다`와 `않다`의 가중치는 각각 더해질 뿐이라서, “좋지 않다”를 불만으로 읽게 하려고 `않다`의 가중치를 크게 키우면 “나쁘지 않다”까지 같이 불만 쪽으로 밀립니다.

**횟수가 크다고 중요한 단어는 아닙니다.** 흔한 단어일수록 횟수가 큽니다. 조사나 `날씨`처럼 모든 문장에 있는 말이 가장 큰 횟수를 가집니다. 이것을 바로잡는 것이 [불용어](./stopword.md)를 지우거나 [TF-IDF](./tf-idf.md)로 깎는 일입니다.

**사전이 커진다고 정확해지지는 않습니다.** 칸마다 가중치를 배울 자료가 필요합니다. 드물게 나오는 단어의 칸은 거의 배우지 못합니다. 어간을 모아 칸을 줄이는 [어간 추출](./stemming.md)이 이 문제를 줄입니다.

**주머니의 칸 순서는 점수와 무관합니다.** 칸 순서는 사전 번호일 뿐입니다. 칸 순서와 가중치 순서를 함께 바꾸면 점수는 같습니다. 문장 안의 단어 순서와 칸 순서는 다른 이야기입니다.

## 연습 문제

1. “나쁘다 날씨 나쁘다”의 횟수 목록과 점수를 구해 보세요. 가중치는 \([0,\ 0.2,\ -1,\ 1]\)입니다.
2. “날씨 좋다”의 횟수 목록은 \([0,\ 1,\ 1,\ 0]\)입니다. 같은 문장을 두 번 이어 쓴 “날씨 좋다 날씨 좋다”는 횟수 목록과 점수가 어떻게 되나요? 문장 길이로 나눈 비율을 쓰면 어떻게 되나요?
3. “정말 날씨 좋다”를 사전 오늘, 날씨, 좋다, 나쁘다로 주머니를 만들면 어떤 목록이 되나요? 이 문장은 “날씨 좋다”와 어떻게 구별되나요?

<details>
<summary>정답</summary>

1. 날씨 1번, 나쁘다 2번이므로 \([0,\ 1,\ 0,\ 2]\)입니다. 점수는 \(0.2 \times 1 + 1 \times 2 = 2.2\)입니다.
2. 두 번 이으면 횟수 목록은 \([0,\ 2,\ 2,\ 0]\)이고 점수는 \(0.4 - 2 = -1.6\)으로, 원래 \(-0.8\)의 두 배입니다. 비율을 쓰면 원래도 이어 쓴 것도 \([0,\ 0.5,\ 0.5,\ 0]\)이라 점수가 같고, 값은 \(0.1 - 0.5 = -0.4\)입니다.
3. `정말`이 사전에 없어 버려지므로 \([0,\ 1,\ 1,\ 0]\)입니다. “날씨 좋다”와 같은 목록이라 구별되지 않습니다.

</details>

## 정리

단어 주머니는 문장을 사전 크기 길이의 횟수 목록으로 바꿔서, 길이가 다른 문장을 같은 모양의 입력으로 만듭니다. 점수는 칸마다 가중치를 곱해 더한 것이고, 순서와 단어 사이의 곱은 없습니다. 횟수 대신 이진 값이나 비율을 쓸 수 있고, 문서 사이의 빈도로 깎는 것이 [TF-IDF](./tf-idf.md)입니다. 두 주머니가 얼마나 비슷한지는 [코사인 유사도](./cosine-similarity.md)로 잽니다.
