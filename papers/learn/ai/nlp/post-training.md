post-training은 [다음 token](./next-token.md)으로 사전 학습을 마친 모델을, 사람이 원하는 답을 내도록 한 번 더 맞추는 단계입니다. 사전 학습만 한 base 모델은 글을 이을 뿐이라 질문에 답하는 형식을 모릅니다.

에이전트를 만들 때 이 단계는 모델 이름과 선택지로 나타납니다.

- **base, instruct, reasoning 모델**: 같은 사전 학습 모델에 SFT, 선호 학습, 보상 학습을 얼마나 했는지가 다릅니다.
- **tool use와 지시 따르기**: 도구를 부르는 형식과 system prompt를 따르는 습관은 대부분 이 단계에서 생깁니다.
- **fine-tuning**: 자기 서비스에 맞춰 직접 후속 학습을 할지 정할 때 LoRA가 선택지로 나옵니다.

## 왜 필요한가

사전 학습한 모델에 "프랑스의 수도는?"만 넣으면 답 대신 "독일의 수도는? 이탈리아의 수도는?"처럼 질문을 이어 쓴 글이 나올 수 있습니다. 사전 학습은 글에서 다음에 올 만한 token을 맞히는 훈련이고, 학습한 글에는 질문 뒤에 또 다른 질문이 오는 경우가 흔하기 때문입니다. 지시를 따르는 법, 도구를 부르는 형식, 거절해야 할 요청을 가리는 법은 사전 학습의 목표에 들어 있지 않습니다.

단순한 방법은 두 가지입니다. 첫째는 prompt 앞에 "질문: ... 답: ..." 예시를 붙여 답을 이어 쓰게 유도하는 것입니다. 되기는 하지만 요청마다 예시 token을 들여야 하고, 모델이 형식을 벗어나는 일을 막지 못합니다. 둘째는 사람이 쓴 질문과 답으로 한 번 더 학습하는 것(SFT)입니다. 답하는 형식은 배우지만 모범 답안을 직접 쓰는 일은 비싸고, 좋은 답이 여러 개인 요청에서 어느 쪽이 더 나은지를 직접 가르치기는 어렵습니다. 사람에게는 답을 직접 쓰는 것보다 두 답 중 나은 쪽을 고르는 일이 훨씬 쉽습니다.

post-training은 사전 학습이 끝난 모델을 한 번 더 학습해 이 한계를 풉니다. SFT로 답하는 형식을, 사람이 고른 쪽으로 기울이는 선호 학습으로 더 나은 방향을 배웁니다. 정답을 검산할 수 있는 과제에는 보상으로 학습하는 방법도 씁니다. 처음부터 다시 배우는 것이 아니라 이미 글을 읽고 쓰는 모델을 조금 고치는 일이라, 데이터 양은 사전 학습보다 훨씬 적습니다. 오차의 식은 [다음 token](./next-token.md)과 같은 \(-\log p\)이고, 어떤 데이터의 어느 구간에 쓰느냐가 다릅니다. 이 단계를 거치기 전의 모델이 [LLM](./llm.md)에서 본 base 모델입니다.

## 계산

SFT(supervised fine-tuning)는 질문과 답을 이어 붙여 학습하되, 오차를 답 구간에만 둡니다. 질문 "별점은"이 3 token이고 답 "4"가 1 token이며 각 token의 정답 비율이 0.5라고 합시다.

```text
구간        token 수   오차 (각 0.693)
질문          3         2.079
답            1         0.693
```

질문까지 합치면 2.772 중 질문이 대부분입니다. 답 구간에만 오차를 두면 0.693만 남습니다. 질문을 받아 적는 일에 학습을 쓰지 않고, 답을 내는 일에 쓰게 하려는 것입니다. 오차의 식은 다음 token과 같은 \(-\log p\)입니다.

선호 학습의 하나인 DPO는 같은 질문의 두 답, 사람이 고른 답과 버린 답으로 학습하며, 고른 답을 버린 답보다 얼마나 더 끌어올렸는지를 오차로 삼습니다. 구체적으로는 학습 중인 모델의 logprob에서 SFT가 끝난 기준 모델의 logprob을 뺀 차이를 두 답에서 구하고, 고른 쪽 차이에서 버린 쪽 차이를 뺀 간격이 클수록 오차가 줄어듭니다. 간격이 0이면 오차가 0.693이고, 0.4이면 0.513입니다. 고른 답의 확률을 올리기만 하는 것이 아니라, 기준 모델에서 고른 답과 버린 답이 벌어진 정도를 봅니다.

## messages는 어떤 모양으로 들어가는가

API에 넘기는 messages(system, user, assistant)는 그대로 모델에 들어가지 않습니다. SFT 때 쓴 형식의 token 열로 바뀌어 들어가며, 역할을 구분하는 특수 token은 모델마다 다르고 이 형식을 chat template이라고 부릅니다. 아래는 설명용 모양입니다.

```text
[system] 한 줄로 답하세요.
[user] 별점은?
[assistant] 4
```

SFT에서 오차를 두는 곳이 마지막 `[assistant]` 뒤의 답 구간입니다. 도구를 부를 때 이름과 인자를 정해진 형식으로 쓰는 것도 이 단계에서 같은 방식으로 배운 습관입니다. 오픈 모델을 직접 서빙할 때 template이 그 모델의 것과 다르면 학습 때 보지 못한 형식이 되어 답이 나빠질 수 있습니다.

## 기억할 것 네 가지

### SFT는 형식을, 선호 학습은 방향을 가르칩니다

SFT는 질문과 답의 짝을 보여 주며 답하는 형식을 익힙니다. DPO나 RLHF 같은 선호 학습은 여러 답 중 사람이 더 낫다고 한 쪽으로 기울게 합니다. 사람의 선호로 보상 모델(답에 점수를 매기는 모델)을 만들고 그 점수를 높이도록 학습시키는 방식을 RLHF, 그 선호를 사람 대신 다른 모델이 매기는 방식을 RLAIF라고 합니다.

### 새 지식은 fine-tuning보다 prompt와 RAG가 먼저입니다

fine-tuning으로 사실을 넣는 것은 비용이 들고 갱신이 어렵습니다. 최신 정보나 사내 문서는 prompt나 [RAG](../rag/index.md)로 넣고, fine-tuning은 말투, 출력 형식, 특정 과제의 일관성처럼 prompt로 안정되지 않는 동작을 고칠 때 고려하는 것이 보통입니다. 이 구분은 일반적인 권장이고, 과제에 따라 달라질 수 있습니다.

### LoRA는 일부만 학습해 비용을 줄입니다

LoRA(low-rank adaptation)는 원래 가중치 행렬을 얼려 두고, 폭이 좁은 두 행렬의 곱만 더해 학습하는 방법입니다. \(4 \times 4\) 행렬이면 16칸 대신 \(4 + 4 = 8\)칸을 학습합니다. 이 크기에서는 효과가 작지만 한 변이 4,096이고 폭이 8이면 학습하는 칸은 \(2 \times 4096 \times 8 = 65{,}536\)개로, 원래 \(4096^2 = 16{,}777{,}216\)개의 약 0.4%입니다. 원래 모델은 그대로라 어댑터(새로 학습한 두 행렬) 파일만 저장하고 갈아 끼울 수 있습니다. 얼린 가중치를 4비트로 두면 QLoRA이고, 이렇게 일부만 학습하는 방식을 통틀어 PEFT라고 합니다.

### 보상으로 학습하면 보상의 허점을 씁니다

정답을 검산할 수 있는 문제(수학, 코드의 테스트 통과)를 보상으로 쓰는 방식을 RLVR이라 하고, 추론에 강한 모델의 학습에 쓰인다고 알려져 있습니다. 보상이 현실의 목표와 어긋나면 모델은 그 틈을 파고듭니다. 에이전트를 평가하는 기준을 만들 때도 같은 일이 생깁니다. 테스트를 통과하기만 하면 점수를 주는 평가는 테스트를 속이는 풀이도 통과시킵니다.

<summary>더 깊이: DPO 식, GRPO, distillation</summary>

- DPO의 오차는 다음과 같습니다. \(y_w\)가 고른 답, \(y_l\)이 버린 답, \(\pi_{\mathrm{ref}}\)가 기준 모델, \(\beta\)가 세기입니다.

\[
E = -\log \sigma\!\left(\beta \left[(\log \pi(y_w) - \log \pi_{\mathrm{ref}}(y_w)) - (\log \pi(y_l) - \log \pi_{\mathrm{ref}}(y_l))\right]\right)
\]

- 간격 0.4, \(\beta = 1\)이면 \(\sigma(0.4) \approx 0.599\)이고 \(-\log 0.599 \approx 0.513\)입니다.
- GRPO는 같은 질문에 답을 여러 개 뽑아 보상을 매기고, 평균과의 차이를 표준편차로 나눈 값(우위)이 양수인 답의 확률을 올립니다. 보상이 \(1, 0, 0, 1\)이면 평균이 0.5이고 평균을 뺀 값은 \(0.5, -0.5, -0.5, 0.5\)입니다(여기에 표준편차를 나눠 크기를 맞춥니다). 네 답의 보상이 같으면 우위가 모두 0이라 그 배치에서는 배울 것이 없습니다.
- distillation은 큰 모델의 다음 token 분포를 작은 모델이 따라 하게 하는 학습입니다. rejection sampling은 후보를 여러 개 뽑아 보상이 높은 것만 SFT의 답으로 쓰는 방식입니다.
- 중간 단계마다 보상을 주는 방식을 PRM(process reward model)이라고 합니다.
