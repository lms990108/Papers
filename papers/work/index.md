title: 경력기술서
---

백엔드 개발 경력을 회사별로 정리했다. 고객사와 내부 시스템 이름은 적지 않았다.

## 포티투마루 (2026.09 ~ 현재)

- 역할: 백엔드 개발(설계, 구현, 성능 측정, 연동 검증, 납품 형태 확정)
- 개요: 고객사의 정형 데이터(DB)와 파일(NAS)을 검색 서비스가 쓸 수 있는 형태로 넘기는 수집·전송 파이프라인 담당
- 주요 업무
  - 정형 데이터 dump 규칙 설계: Silver의 중복을 세 유형으로 나눠 세고, `(데이터셋, 업무 키, 본문)` 기준 최신 1건 유지로 확정
  - 검색 문서 생성: JSON 본문을 스키마 라벨로 풀어 검색용 title과 description 생성
  - 연동 검증: 레거시 커넥터에 얹어 더미 DB로 end-to-end 검증하고 수집 건수를 SQL로 대조
  - NAS 파일 게이트웨이: `sendfile` 전송 방식을 측정으로 비교하고, FastAPI와 nginx(`X-Accel-Redirect`) 구성으로 납품
- 성과
  - 동일 본문 중복을 최대 20건에서 1건으로 줄이고, 서로 다른 항목은 잃지 않도록 규칙 설계
  - 전송 방식 비교로 CPU 사용량 약 4~10배 절감 확인(개발 환경, 1GB). 실제 회선(약 9MB/s)에서 8.78GB를 약 17분에 전송
  - 실제 회선에서는 회선 대역이 먼저 차서 큰 파일 속도가 전송 방식과 무관함을 측정으로 확인
  - 전송 방식에 따른 차이는 작은 파일이 많고 코어가 하나일 때만 나타남
- 기술: SQL, MariaDB, Python, FastAPI, Go, nginx, Linux, 메달리온 아키텍처(Silver/Gold)

## 위지온 (2025.12 ~ 2026.08)

- 역할: 백엔드 개발 및 운영(운영개발실 선임연구원)
- 개요: PG 솔루션을 유지보수하고 신규 서비스의 백오피스를 개발하며, 결제 이후의 정산 데이터를 운영
- 주요 업무
  - 정산 서비스 운영·유지보수: 문의·보정 요청 시 로그와 대사 데이터로 값이 달라진 단계를 추적
  - 정산 미반영 건 처리: 사유 확인과 보정(배치 재요청, 쿼리), 후속 정산과 통계 재확인
  - 백오피스 개발: 신규 서비스 백오피스와 API 구현
  - 쿼리 컨벤션 도구: MyBatis XML과 SQL 자동 포맷터 개발, 수정할 쿼리에만 적용
- 성과
  - 포맷터로 정리한 쿼리 2만 줄 이상, 형식 확인 대신 로직 검토에 집중
- 기술: Java, MyBatis, SQL, TypeScript

## 잇잇 (2024.12 ~ 2025.10)

- 역할: 백엔드 개발 및 운영
- 개요: 축제 푸드트럭 앱 결제 서비스 Eat It을 만들어 운영했고, 이후 축제 커뮤니티와 결제를 합친 Pamp로 리브랜딩하며 고도화
- 주요 업무
  - 회원제 전환: 유저 도메인 설계, OIDC 소셜 로그인 구현
  - 결제 정합성: 주문 Snapshot 대조와 유니크 키 기반 멱등성
  - 주문 전달 구조: WebSocket을 폴링(Outbox, 커서 기반 페이징)으로 전환
  - 배포 자동화: GitHub Actions와 ECR로 ECS 배포를 자동화하고 CI에 Redis 컨테이너 추가
  - Pamp 리브랜딩: 도메인 중심 ERD, 헥사고날 구조, 토스페이먼츠·알림톡 연동, 슬로우 쿼리 개선
- 성과
  - 두 차례 축제 행사에서 1만 건 이상 결제를 장애 없이 처리, 결제 대금 1억 원 이상
  - 배포 소요 시간 약 20분에서 6~8분으로 단축
  - 테스트 환경에서 초 단위였던 조회 응답 시간을 1/10 이하로 단축, 유닛 테스트 커버리지 70% 이상 유지
- 기술: Java, Spring Boot, MySQL, Redis, AWS(ECS, ECR, RDS, ElastiCache, Lambda), QueryDSL, Liquibase, GitHub Actions
