### 고객사 데이터 수집·처리

- 역할: 설계, 구현, 성능 측정, 연동 검증, 납품 형태 확정
- 개요: 고객사의 정형 데이터(DB)와 파일(NAS)을 검색 서비스가 쓸 수 있는 형태로 넘기는 수집·전송 파이프라인 담당
- 주요 기여
  - 정형 데이터: 이력이 쌓이는 Silver 층에서 검색용 JSON을 만드는 규칙 설계(최신본 선별, 중복 정리, 검색용 제목·설명 생성)
  - 기존 레거시 커넥터에 얹어 전체·증분 수집을 로컬에서 end-to-end로 검증
  - 파일: NAS를 마운트할 수 없는 환경에서 대용량 파일을 보내는 게이트웨이 구축. 전송 방식을 측정으로 비교해 납품 구성 확정
- 성과
  - 동일 본문 중복을 최대 20건에서 1건으로 줄이고, 서로 다른 항목은 잃지 않도록 규칙 설계
  - 전송 방식 비교로 CPU 사용량 약 4~10배 절감 확인(개발 환경). 실제 회선(약 9MB/s)에서 8.78GB 전송 약 17분 확인
  - 수집 건수를 SQL로 대조해 연동 결과 검증
- 기술: SQL, MariaDB, Python, FastAPI, Go, nginx, Linux, 메달리온 아키텍처(Silver/Gold)
